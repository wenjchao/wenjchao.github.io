# Arrhythmia

## 摘要
Afib（CHA₂DS₂-VASc >2 抗凝、LA 大小與病生理、rate vs rhythm control）、緩脈放 pacemaker、SVT 類 RFCA、VT 放 ICD、抗心律不整藥四大類；附 19 張圖解。

## 內文
1. **<u>Atrial fibrillation</u>**

   [[Arrhythmia/CHA2DS2-VASc|摘要]]
   1. Pathophysiology:
      1. Left atrium enlargement
         - LA dimensions: 4cm normal, 5cm 50% a-fib, 6cm 100% a-fib
      2. Left atrium ischemia
      ⇒ remodeling: Ca2+ channel remodeling, scar formation
      ⇒ permanent A-fib
   2. Afib rate control / Afib-RVR emergency：
      1. CCB + beta blocker (if no HF)
      2. second line: amiodarone（小心會跳回來）、digoxin
         1. amiodarone 注意毒性（一天的量有上限）
      3. 只有 LA 小的才考慮 rhythm control（不然撐不久）
         - 如果能 rhythm control，長期來看還是讓他 rhythm control 比較好
2. Bradycardia（SSS、AV block）：**<u>Pacemaker</u>**
3. Atrial Tachy、AVNRT、AVRT、A-Flutter：**<u>RCFA</u>**（用心導管燒掉） > Anti-arrhythmics
4. VT：**<u>ICD</u>** > RFCA、Anti-arrhythmics
5. **<u>Anti-arrhythmics</u>**
   1. Class 1: Na: lido**cain**e, pro**cain**amide
   2. Class 2: beta blocker ⇒ -olol
   3. Class 3: K: amiodarone (混class 1234)
   4. Class 4: Ca: 即 CCB ⇒ Dilitazem, Verapamil
