# 理想氣體的粒子擴散

## 內文
如下圖，粒子濃度在往 -x 方向越來越高，往 +x 方向越來越低，即 $\frac{d\rho_{n}(x)}{dx} < 0$

![](圖片/截圖_2024-03-30_晚上11.22.16.png)

1. 理想氣體為什麼會擴散？因為粒子本來就會自由運動，貌似是從濃度高擴散到濃度低，其實只是平均分佈而已
2. 在 x = 0 處取一個平面，則此平面分別會遇到從左邊過來的粒子以及從右邊過來的粒子
3. 如何知道左邊過來的粒子數 & 右邊過來的粒子數？
   ⇒ 單位時間穿越某個截面的粒子通量為 $J_n = \rho_{n} \overline{\vert v_{ x}\vert}$，其中 $\overline{\vert v_{ x}\vert}$ 為 x 方向分子速率的平均
   ⇒ 單位時間從左往右穿越某個截面的粒子通量為 $J = \frac{1}{2}\rho_{n} v_{mean}$
4. 假設在平均自由路徑 $\lambda$ 內的分子都可以自由抵達 x = 0 這個平面，而距離 $\lambda$ 以外的分子就無法抵達
   ⇒ 左邊過來的粒子通量 $J_L$ 與 右邊過來的粒子通量 $J_R$ 即為 $\begin{cases} J_{L,n} = \frac{1}{2}\rho_{n}(-\lambda)\overline{\vert v_{ x}\vert}\\ J_{R,n} = \frac{1}{2}\rho_{n}(\lambda)\overline{\vert v_{ x}\vert} \end{cases}$
5. 假設 $\lambda << 1$，因此根據泰勒展開，$\begin{cases} \rho_{n}(-\lambda) = \rho_{n}(0) -\lambda \frac{\partial \rho_n(0)}{\partial x} \\ \rho_{n}(\lambda) = \rho_{n}(0) +\lambda \frac{\partial \rho_n(0)}{\partial x} \end{cases}$
6. 可以算出淨粒子通量 $J_{n} =J_{L,n} - J_{R,n} = \frac{1}{2}[\rho_{n}(-\lambda) - \rho_{n}(\lambda)]\overline{\vert v_{ x}\vert} =- \lambda \overline{\vert v_{ x}\vert} \frac{\partial \rho_n(0)}{\partial x}$
   對照 Fick’s law： $J_n = -D \frac{\partial \rho_n}{\partial x}$ ，可以發現
   $$
   D =  \lambda  \overline{\vert  v_{ x}\vert} = \frac{2(kT)^\frac{3}{2}}{\pi m\sigma P}
   $$
   1. $\lambda = \frac{kT}{\sigma P}$ 為平均自由路徑
   2. $\overline{\vert v_{ x}\vert} = (\frac{2kT}{\pi m})^\frac{1}{2}$為 x 方向分子速率 ${\vert v_{ x}\vert}$ 的平均
