# 理想氣體的熱容

## 內文
1. 因為沒有位能、共價鍵能，因此 $U = \frac{?}{2}nRT$、$H = U + nRT$ 只與溫度有關（理想氣體仍可以為多原子分子，有旋轉動能、振動動能）
2. $C_{V, m} = [\frac {\partial U_m}{\partial T}]_V = \frac{?}{2}R$ ， $C_{P, m} = [\frac {\partial H_m}{\partial T}]_V = C_{V, m} + R$（注意都不需定壓 / 定容）
3. 絕熱程序中的理想氣體

   [[理想氣體的熱容/圖示：絕熱程序可以視為定溫程序 + 定容程序的組合|摘要]]
   - 在定溫程序中內能 U 不變，在定容程序中 $d U = C_V d T$
   - $dw = -PdV = \frac{nRT}{V}dV$
   - 因為絕熱，所以 $dq = 0$
   1. $\Delta U = w + q$ ⇒ $-\int \frac{nRdV}{V} = \int \frac{C_V dT}{T}$ ⇒ $\frac{C_V}{nR}\ln(\frac{T_1}{T_2}) = \ln(\frac{V_2}{V_1})$
      令 $c=\frac{C_V}{nR}$ ⇒ $V_1T_1^c = V_2T_2^c$
   2. 同理，因為 $\frac{P_1V_1}{P_2V_2} = \frac{T_1}{T_2}$，令 $\gamma = \frac{1+c}{c} = \frac{C_{P,m}}{C_{V,m}}$ ⇒ $P_1 V_1^\gamma = P_2 V_2^\gamma$
