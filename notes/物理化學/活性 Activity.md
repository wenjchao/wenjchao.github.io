# 活性 Activity

## 內文
對於理想氣體而言，其化學位能可以表示為 $\mu_g = \mu_g^{\minuso} + RT\ln(\frac{P}{P^{\minuso}})$

然而若是要擴大此式的使用範圍，則需要把 $\frac{P}{P^{\minuso}}$ 用更通用的 a (activity) 來替代

因此新方程式寫成 $\mu_{A} = \mu_{A}^{\minuso} + RT\ln(a_A)$

- 注意：為了因應不同的標準狀態 $^{\minuso}$ ，$\mu_{A}^{\minuso}$ 的定義是會改變的

1. 純物質的理想氣體：$a_A =\frac{P_A}{P^{\minuso}}$
   若令標準狀態 ${P^{\minuso}}= 1\ bar$
   - $a_A$ 即為分壓 $P_A$
   - $\mu_{A}^{\minuso}$ 為 ${P^{\minuso}}$下的化學位能
2. 純物質的理想固體、理想液體： $a_A = 1$
3. 理想溶液（拉午耳定律）：$a_A = \frac{P_A}{P^＊} = x_A$ ，即莫耳分率
   - $\mu_{A}^{\minuso}$ 即為飽合蒸氣壓 $P^*$ 下的化學位能 $\mu_{g,A}^*$
4. 理想溶液（重量莫耳濃度）：$a_A = \frac{c_A}{c^{\minuso}}$
   若令標準狀態 $c^{\minuso} = 1 \ mol/kg$
   - $a_A$ 即為重量莫耳濃度 $c_A$
   - $\mu_{A}^{\minuso}$ 為 $c^{\minuso}$下的化學位能
   - 也可以令 $c^{\minuso} = 1 \ mol/dm^3$ ，這樣 $c_A$ 就變成容積莫耳濃度
