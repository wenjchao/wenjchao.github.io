# 理想溶液中的離子運動（電傳導）

## 內文
對於溶液而言，其導電能力的參數如下

1. 電導 $G = \frac{I}{V}$ 為導體的導電能力
2. 導電度 $\sigma = G\frac{l}{A}$ 為某材料（ex: 濃度固定的溶液）的導電能力
3. 溶質的莫耳導電度 $\Lambda_m = \frac{\sigma}{c}$ 即為溶質的導電能力（ex: $\ce{NaCl}$ ）
4. 雖然分母已經除以濃度了，但還是不夠單純：
   1. 有些溶液解離度不是 100%（解離度和濃度有關）
   2. 離子之間有靜電作用力（靜電作用力和離子濃度有關）
   3. 有些點電解質解離後會有很多離子 （ex: $\ce{CaCl_2}$ 解離會有三個離子）
5. 解決方案：
   1. 假設它是強電解質
   2. 用超級稀薄的溶液：定義超級稀薄溶液的莫耳導電度為 $\Lambda_m^{\minuso}$
      - Kohlrausch’s law：$\Lambda_m = \Lambda_m^{\minuso} - Kc^{\frac{1}{2}}$ ，即濃度越高，$\Lambda_m$ 越低
   3. 把 $\Lambda_m^{\minuso}$ 再拆成 $\Lambda_m^{\minuso} = \sum \nu_j\lambda_j^{\minuso}$
      1. $\nu_j$ 為解離出的離子數量 ex: $\ce{CaCl_2}$ 的 $\nu_{\ce{Ca}}= 1$，$\nu_{\ce{Cl}}= 2$
      2. $\lambda_j^{\minuso}$ 為一顆 j 離子的莫耳導電度 （在超級稀薄的環境下）

一顆離子在溶液中，會有哪些因素影響導電度？

1. 在電場中，一顆離子的受力 $F = qE$ ，其中 $q$ 為帶電量， $E$ 為電場
   因為溶液中阻力很大，會很快到達終端速度，平衡時溶液給離子的阻力 = 電場施予的力
2. 根據 Stokes law，粒子在流體中的速度 $v = \frac{F}{6\pi \eta R}$，其中 $\eta$ 為黏度，$R$ 為粒子半徑
   ⇒ 電場中一顆離子的速度 $v_{dri} = \frac{F}{6\pi \eta R} = \frac{q}{6\pi \eta R} E$ 稱為 **<u>漂移速度 drift velocity</u>**
3. 定義 **<u>mobility</u>** $\mu$ 代表此離子行動的容易程度，即 $v_{dri} = \mu E$，則可以寫出 $\mu = \frac{q}{6\pi \eta R}$
   - 因為 $D = \frac{kT}{6\pi \eta R}$ ，因此 $D = \frac{kT}{q}\mu$ ，稱為 **<u>Einstein relation</u>**
4. 對於某離子 j 運動所產生的電流，在溶液中的電流通量 $J_{e,j} ＝ q_jJ_n = q_j\rho_{n,j} v_{dri}$
   1. $q_j$ 為離子 j 的帶電量
   2. $\rho_{n,j} = N_Ac \nu_j$，$c$ 為整個分子的容積莫耳濃度，$\nu_j$ 為一個分子所解離出的離子 j 數量
   3. $v_{dri} = \mu E$
5. 而同時根據歐姆定律
   1. 對於整個分子而言 $J_e = \sigma E = \Lambda_m cE = \sum_j J_{e,j}$
   2. 對於離子 j 而言，$J_{e,j} = \nu_j\lambda_j cE$
6. 以上兩式皆為溶液中的電流密度通量，因此應該相等：$J_{e,j} ＝ q_j\rho_{n,j} v_{dri} = \nu_j\lambda_j^{\minuso} cE$
   ⇒ $q_jN_Ac \nu_j \mu_j E = \nu_j\lambda_j^{\minuso} c E$
   ⇒ $\lambda_j^{\minuso} = q_jN_A \mu_j$ ，其中 $q_jN_A = z_j\mathcal F$
   1. $z_j$ 為離子所帶電荷數 (ex: $z_{\ce{Ca}} = 2$，$z_{\ce{Cl}} = -1$)
   2. $\mathcal F = N_A * e = 96485$ 為法拉第常數
7. 代回最原始的式子：
   $$
   \Lambda_m^{\minuso} = \sum \nu_j\lambda_j^{\minuso} =  \sum  \nu_jz_j\mu_j\mathcal F  = \frac{D\mathcal F^2}{RT}\sum  \nu_jz_j^2
   $$
   - 根據 Einstein relation
   - 此式稱為 **<u>Nernst-</u><u>Einstein equation</u>**，即離子的莫耳導電度與帶電量、擴散係數有關
