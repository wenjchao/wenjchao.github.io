# 理想溶液中的粒子擴散

## 內文
1. 擴散可以想像成是因為濃度梯度形成 chemical potential，粒子在此場中被做功
2. 因為此溶液對溶質 A 粒子做的功為非膨脹功，所以由 Gibbs energy 提供：
   $dw = n_AdG_m = n_Ad\mu$
   - 其中 $\mu = \mu^{\minuso} + RT\ln(a_A)$ （見 <u>活性 Activity</u>）
3. 對於 $n_A$ mole 溶質而言，其受力$F = -\frac{dw}{dx} = -n_A\frac{\partial \mu}{\partial x} = -n_A\frac{\partial [RT\ln(a_A)]}{\partial x} = -\frac{n_ART}{a_A}\frac{\partial a_A}{\partial x}$
   設其為理想溶液，則 $a_A = c_A = \frac{\rho_n}{N_A} = \frac{n_A}{V}$ ⇒ $F = -\frac{n_ART}{c_A}\frac{\partial c_A}{\partial x}$
   ⇒ 一顆粒子的受力為 $F = -\frac{kT}{\rho_n}\frac{\partial \rho_n}{\partial x}$
4. 粒子通量為 $J_n = \rho_n v_{dif}$
   1. 根據 Stokes law，粒子在流體中的速度 $v = \frac{F}{6\pi \eta R}$，其中 $\eta$ 為黏度，$R$ 為粒子半徑
      $v_{dif}$ 即為 **<u>擴散速度 diffusion velocity</u>** ，即分子往擴散方向運動的平均速度
   2. $\rho_n = N_Ac_A$，其中 $c_A$ 為容積莫耳濃度
5. 綜合各式，$J_n = \rho_n v_{dif}= \frac{\rho_nF}{6\pi \eta R} = -\frac{\rho_nkT}{6\pi \eta R\rho_n}\frac{\partial \rho_n}{\partial x} = -\frac{kT}{6\pi \eta R}\frac{\partial \rho_n}{\partial x}$
   對比 Fick’s first law $J_n = -D\frac{\partial \rho_n}{\partial x}$ 可以發現
   $$
   D =  \frac{kT}{6\pi \eta R}
   $$
   - 稱為 **<u>Stokes-Einstein equation</u>**
   - 可以發現擴散係數與黏度成反比，與溫度成正比
   - 亦可發現 $v_{dif} = \frac{DF}{kT}$
