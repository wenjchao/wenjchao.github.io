# 反應速率公式與種類

## 內文
1. 對於化學反應 $\ce{aA + bB -> cC + dD}$ 而言，其反應速率定義為
   $v = -\frac{1}{a}\frac{d[A]}{dt}= -\frac{1}{b}\frac{d[B]}{dt} = \frac{1}{c}\frac{d[C]}{dt}= \frac{1}{d}\frac{d[D]}{dt} = \frac{1}{\nu_J}\frac{d[J]}{dt}$
2. 同時定義 $\xi$ 為反應量，即經過反應後，任一化合物 J 的數量變化 $\Delta n_J = \nu_J \xi$
   若只進行一點點反應，則可以寫成 $dn_J = \nu_J d\xi$
   顯然 $v = \frac{1}{V} \frac{d\xi}{dt}$ （因為 $[J] =\frac{n_J}{V}$）
   - 目前都是討論勻相反應，即只有一個相(phase)。如果是非勻相反應 ex: 某固體與某液體反應，則在分母的那個體積 V 要改成表面積 A
3. 反應速率與濃度的關係：
   > 對於反應 $\ce{A → bB + cC + …}$ 而言
   1. 如果 $v =k_r[A]$，則稱為 **<u>first order reaction</u>**
      因為 $v = -\frac{d[A]}{dt} = k_r[A]$ ⇒ $\frac{1}{[A]}d[A] = -k_r dt$ ⇒ 兩邊同時積分
      1. $ln [A]-\ln [A]_0 = -k_rt$ （[A] 取 log 為直線）
      2. $[A] = [A]_0e^{-k_rt} =[A]_0 e^{-t/\tau}$ （[A] 為 exponential decay）
      3. $\frac{t_{1/2}}{\ln(2)} = \tau = \frac{1}{k_r}$
   2. 如果 $v = k_r[A]^2$，則稱為 **<u>second order reaction</u>**
      因為 $v = -\frac{d[A]}{dt} = k_r[A]^2$ ⇒ $\frac{1}{[A]^2}d[A] = -k_r dt$ ⇒ 兩邊同時積分
      1. $\frac{1}{[A]} - \frac{1}{[A]_0} = k_rt$ （[A] 取倒數為直線）
      2. $[A] = \frac{1}{1+k[A]_0t} [A]_0$
      3. $t_{1/2} = \frac{1}{k_r[A]_0}$
   3. 如果 $v = k_r[A]^n$ ，則稱為 **<u>nth order reaction</u>**
      1. $t_{1/2} = \frac{2^{n-1}-1}{(n-1)k_r[A]_0^{n-1}}$
   > 對於反應 $\ce{A + B -> cC + dD + …}$ 而言
   1. 如果 $v= k_r[A][B]$，則稱為 **<u>A 的 first order reaction、B 的 first order reaction、整體的 second order reaction</u>**
      因為 $\begin{cases} v = -\frac{d[A]}{dt} = k_r[A][B]\\ v = -\frac{d[B]}{dt} = k_r[A][B] \end{cases}$ ⇒ 設 $\begin{cases} [A] = [A]_0 - x\\ [B] = [B]_0 - x \end{cases}$
      ⇒ $\frac{dx}{dt} = k_r([A]_0 - x)([B]_0 - x)$ ⇒ $\frac{dx}{([A]_0 - x)([B]_0 - x)} = k_rdt$
      這邊使用積分技巧：把通分的式子變成還沒通分的樣子
      ⇒ $\frac{dx}{([B]_0 - x)} - \frac{dx}{([A]_0 - x)} = ([A]_0 - [B]_0)k_rdt$
      ⇒ $\ln([A]_0 - x) - \ln([B]_0 - x) +C = ([A]_0 - [B]_0)k_rdt$
      ⇒ $\ln [A] - \ln [B] +C = ([A]_0 - [B]_0)k_rdt$
      ⇒ $\ln \frac{[A] }{[B] }+C = ([A]_0 - [B]_0)k_rdt$，$t =0$ 代入發現 $C = -\ln \frac{[A]_0 }{[B]_0 }$
      ⇒ $\ln \frac{[A]/[A]_0 }{[B]/[B]_0 } = ([A]_0 - [B]_0)k_rdt$
      即反應物濃度的比值取對數，會和反應速率常數成正比
   2. 如果 $v= k[A]^m[B]^n$，則稱為 **<u>A 的 mth order reaction、B 的 nth order reaction、整體的 (m+n)th order reaction</u>**
