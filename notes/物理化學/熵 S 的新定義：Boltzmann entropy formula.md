# 熵 S 的新定義：Boltzmann entropy formula

## 內文
1. 在古典熱學定義中，兩系統 A 與 B 合併後的 entropy $S_{A+B} = S_A + S_B$ （因為 entropy 是 extensive quantity）
2. 假設 A 與 B 皆是 Einstein solids，則 $\Omega_{A+B} = \Omega_{A} \Omega_{B}$
3. $S(\Omega_{A+B}) = S(\Omega_{A} \Omega_{B}) = S(\Omega_{A}) + S(\Omega_{B})$
   兩邊對 $\Omega_A$ 求導：$\Omega_{B} S'(\Omega_{A} \Omega_{B}) = S'(\Omega_{A})$
   兩邊同乘以 $\Omega_A$：$\Omega_{A}\Omega_{B} S'(\Omega_{A}\Omega_{B}) = \Omega_{A} S'(\Omega_{A})$
   發現對任意系統 X 而言，$\Omega_{X} S'(\Omega_{X})$ 均為常數，設為 k
   $S'(\Omega_{X})= \frac{1}{\Omega_{X}} k$ ⇒ $S = k \ln{\Omega} + C$，又因為當 $\Omega = 1$ 時 $S = 0$
   因此 $S = k \ln{\Omega}$ （可以視為定義）
4. 熵增加的原動力：物質與能量隨機擴散（甚至可以計算熵產生率）
