# Einstein solid

## 內文
1. 一群 n 個不同硬幣，如果已知某 macrostate 為 [m 個正面， n-m 個反面]，則總共有 $\Omega = C^n_m$ 個 microstates
2. 一群 n 個不同的 oscillators，如果已知某 macrostate 有 q 個相同的能量要分配，則總共有 $\Omega = C^{n+q-1}_{q}$ 個 microstates
   - 證明：如果 q = 8 個能量要分給 n = 4 個 oscillators，則可以寫成 $C^{11}_3 = C^{11}_8$
