# 熱力學第二定律：所有反應的 $\Delta S_{total} ≥ 0$﻿ （因為在這個宇宙中所有反應都是自發的）

## 內文
1. 因為 $w_{env} ≤ w_{sys}$ ，且只有在可逆程序時等號才會成立 ($w_{env} = w_{sys} =w_{rev}$，見 <u>功 w</u> )
   ⇒ $q_{env} ≥ q_{sys}$ ，且只有在可逆程序時等號才會成立 ($q_{env} = q_{sys} =q_{rev}$ )
2. $w_{sys} - w_{env} = q_{env} - q_{sys}$ ，即消失的功都會變成熱，跑到外界耗散掉
   - 這些耗散掉的熱是有可能跑回系統中，但那就不算在 dU 以及 dq 裡面（畢竟回來了）
3. Clausius inequality：$d S_{total} = d S_{sys} + d S_{env} = d S_{sys} - \frac{dq_{env}}{T} ≥ 0$
   ⇒ $d S_{sys} ≥ \frac{dq_{env}}{T}$
   - 因為 dq 以熱量轉移進系統為正，熱量轉移出系統為負，因此 $d S_{env} = - \frac{dq_{env}}{T}$
   - 因為 $S_{sys}$ 簡稱為 S ，$q_{env}$ 簡稱為 q，因此 Clausius inequality 可以寫成 $d S≥ \frac{dq}{T}$
