# High-Troponin rapid algorithm for suspected Acute Coronary Syndrome (0/1/3 hour)

## 摘要
0 小時很低就 rule out、很高就 rule in；1 小時看變化量；仍不確定的 3 小時再抽。一定要用 hs-cTn，各醫院閾值不同；附流程圖與 2020 ESC 連結。

## 內文
1. 0 hour(initial) Troponin, rule out if very low, rule in if high(>99%)，剩下繼續觀察
2. 1 hour Troponin, rule out if no elevation，rule in if elevation (3~4 ng/l 一定算elevation)
3. 真的很不確定的人，3 hours再抽一次
4. [[hs-Troponin 0-1-3 小時流程/流程圖|扁平]]

- 此流程一定要用 hs-cTn（High-sensitive cardiac troponin T or I），注意每家醫院 assay 的 high、low、very low、1h**Δ** 的值都不一樣
- 參考 2020 ESC guideline：[https://academic.oup.com/eurheartj/article/42/14/1289/5898842](https://academic.oup.com/eurheartj/article/42/14/1289/5898842)
