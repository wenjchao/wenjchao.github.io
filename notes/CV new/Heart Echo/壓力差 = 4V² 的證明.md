# Transvalvular pressure gradient = 4V² 的證明

## 摘要
用 Bernoulli 方程式推導 ΔP = ½ρv²，代入 1 mmHg = 133.3 Pa、ρ = 1060 kg/m³ 得到 4v²。

## 內文
$\tfrac{1}{2} \rho v_\text{ lv}^2 + \rho g z + p_\text{ lv} = \tfrac{1}{2} \rho v_\text{ aorta}^2 + \rho g z + p_\text{ aorta}$

⇒ $\tfrac{1}{2} \rho v_\text{ lv}^2 + p_\text{ lv} = \tfrac{1}{2} \rho v_\text{ aorta}^2 + p_\text{ aorta}$

⇒ $p_\text{ lv} - p_\text{ aorta} = \tfrac{1}{2} \rho v_\text{ aorta}^2 -\tfrac{1}{2} \rho v_\text{ lv}^2$

**⇒** **<u>Aortic valve pressure gradient</u>**$=\Delta p = \tfrac{1}{2} \rho v_\text{ aorta}^2$

又 1 mm-Hg = 133.3 Pa, $\rho_\text{ blood}$ = 1060 kg / m^3

**<u>Pressure gradient</u>** $=\Delta p = \tfrac{1}{2}*\tfrac{1060}{133.3}* v_\text{ aorta}^2 = 4 v^2$
