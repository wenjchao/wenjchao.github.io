# 藥膏與滴劑

## 摘要
口內膏（Kenalog、四聯軟膏）、耳滴劑（Odicon 油性、Serene 水性，含衛教）、眼用藥、紅疹濕疹（倍達舒）、痔瘡用藥。

## 內文
1. oral ulcer：
   - Kenalog（triamcinolone，類固醇）：口內膏，適用於病灶偏內
   - 四聯親水軟膏：Betamethasone + Gentamicin + Tolnaftate（抗真菌） + Iodochlorhydroxyquin（抗真菌），適用於病灶偏外
2. 耳朵：
   1. Odicon（油性）：
      1. 抗黴菌效果較佳，用於otomycosis
      2. 如果耳屎硬或耳屎這次夾不掉，先回去點Odicon，三天後再來夾，回診前一小時記得要再點一次以軟化耳屎
   2. Serene（水性）：用於單純外耳炎
   3. 耳滴劑衛教：每次使用前搖一搖，每天點三次(早中晚)，每次三滴，滴完要側躺十分鐘，讓其自然流出再擦乾淨，不要用棉花棒伸進去擦
3. 鼻血、尿布疹：四聯小
4. 眼睛：
   1. Serene（Dexamethasone + Neomycin）：1.00\*3天\*TIDX
   2. Sinomin (Sulfamethoxazole，抗生素)
   3. 人工淚液
5. 紅疹、濕疹：倍達舒（Clobetasol Propionate，類固醇）1.00\*3天\*TIDX
6. Hemorrhoid：
   1. Benazone 藥膏 （複方藥膏）
   2. Xylmol oint（複方藥膏）
   3. Faktu 塞劑
   4. Transamine 粉 + Bosmin 紗（值班用，問泰禕）
