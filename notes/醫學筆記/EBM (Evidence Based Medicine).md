# EBM (Evidence Based Medicine)

## 內文
1. 問問題：想問怎樣的臨床問題？越具體越好

2. 檢索：在 Pubmed / Medline / Embase 資訊檢索時，用 PICO 檢索法：
   1. P： Patient，這是怎樣的病人？什麼診斷？什麼背景？
   2. I：Intervention，想用什麼藥？什麼術式？
   3. C：Control，跟誰比較？Placebo？
   4. O：Outcome，想知道什麼結果？Life expectancy？Life quality？

3. 篩選文章：用哪些資料庫、Search syntax、Mesh tab / Emtree、Filters、剔除文章原因
