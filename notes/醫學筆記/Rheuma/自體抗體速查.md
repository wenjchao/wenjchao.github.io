# 自體抗體速查

## 內文
### 自體抗體與對應疾病

ANA 可 (+)，各病再看專一抗體。

| 抗體 | 對應疾病 | 備註 |
|---|---|---|
| ANA | [[SLE (polyarthritis)]]（敏感）；其他 CTD 也常 (+) | 篩檢用，(+) 不等於 SLE |
| anti-dsDNA、anti-Sm | SLE（專一） | anti-dsDNA level 與活動度相關（nephritis、vasculitis） |
| anti-histone | [[Drug-induced lupus]] | anti-Sm、anti-dsDNA 常 (−)；相關藥物見疾病正文 |
| anti-ribosomal P | SLE CNS involvement | — |
| anti-phospholipid | [[Antiphospholipid syndrome\|APS]] | 常與 SLE 一起；抗凝限制見疾病正文 |
| anti-Ro/SSA、anti-La/SSB | [[Sjogren's syndrome (polyarthritis)\|Sjogren]]；母體有 → [[Neonatal lupus]] | AV block、hepatitis |
| anti-CCP | [[Rheumatoid arthritis (polyarthritis)\|RA]] | 專一；與關節破壞程度相關 |
| RF（anti-Fc of IgG） | RA | 不專一；與關節外表現、預後相關 |
| anti-centromere | [[Systemic sclerosis\|Limited SSc]]（CREST） | — |
| anti-Scl-70 | Diffuse SSc | ILD |
| anti-RNA polymerase III | Diffuse SSc | renal crisis（最強關聯）、cancer |
| anti-U1 RNP | [[Mixed connective tissue disease\|MCTD]] | — |
| anti-Jo-1 | [[Myositis]]＋ILD | — |
| anti-Mi-2 | Dermatomyositis | — |
| anti-PM/Scl | Polymyositis＋SSc overlap | — |
| c-ANCA（anti-PR3） | [[Vasculitis\|GPA]]（Wegener） | — |
| p-ANCA（anti-MPO） | EGPA（Churg-Strauss）、MPA | — |

完整判讀見各疾病正文。

### 補體

Low C3／C4 → [[SLE (polyarthritis)]] 活動期。
