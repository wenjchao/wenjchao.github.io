# Lupus nephritis：proteinuria 與 urinary casts

## 內文
### 表現與分級

表現：proteinuria、urinary casts。

### 分級、病理與治療

| 分級 | 病變 | 治療 |
|---|---|---|
| Class I：minimal mesangial | Immune complex 沉積，可由 immunofluorescence 偵測 | 不需治療 |
| Class II：mesangial proliferative | 任意程度的 mesangial hypercellularity，或 mesangial matrix expansion<br>伴 immune deposits，可由 light microscopy 偵測 | 不需治療 |
| Class III：focal（< 50%） | Active／inactive、focal、segmental／global endo／extracapillary glomerulonephritis，侵犯 < 50% 全部 glomeruli<br>可呈 active（A）、chronic inactive（C）或 active＋chronic（A/C）lesions | AZA（輕度）→ MMF（重度）→ methylprednisolone＋cyclophosphamide（超嚴重）→ rituximab |
| Class IV：diffuse（≥ 50%〔待核對〕） | Active／inactive、diffuse、segmental／global endo／extracapillary glomerulonephritis，侵犯 ≥ 50% 全部 glomeruli<br>常見 diffuse subendothelial immune deposits，可伴或不伴 mesangial alterations<br>可呈 A、C 或 A/C lesions | AZA（輕度）→ MMF（重度）→ methylprednisolone＋cyclophosphamide（超嚴重）→ rituximab |
| Class V：membranous（MN） | Global／segmental subepithelial immune deposition，或其形態後續變化，可由 light、immunofluorescence 或 electron microscopy 偵測<br>可伴或不伴 mesangial alterations<br>可合併 Class III／IV，也可呈 advanced sclerosis | MMF／cyclosporin A |
| Class VI：advanced sclerosis | 90% glomeruli 為 global sclerosis；terminal prognosis<br>Sclerosis（不再發炎） | 所有治療均無效 |

Class IV 的病灶分型：

- IV-S（diffuse segmental）：≥ 50% **受侵犯的** glomeruli 為 segmental lesions。
- IV-G（diffuse global）：≥ 50% **受侵犯的** glomeruli 為 global lesions。

原筆記將 Class III／IV 的病變合記為 DPGN／MPGN。
Class IV 比例待核對：原文字表為 **> 50%**，原圖為 **≥ 50%**；上表按原圖呈現。
