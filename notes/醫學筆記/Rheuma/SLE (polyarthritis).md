# SLE (polyarthritis)

## 內文
### 機制與流病

1. Gene：HLA-DR2／DR3
2. Immune complex 沉積（[[Hypersensitivity 四型|Type III]]）

### 全身表現

1. Fever
2. [[Cutaneous lupus|膠囊]]
3. 關節（> 90%）：MCP、PIP；non-erosive、無 deformity
4. CNS：seizure、psychosis、personality／behavior change（與 anti-ribosomal P 相關）
5. 血液：leukopenia、hemolytic anemia、thrombocytopenia
6. [[Lupus nephritis|膠囊]]
7. 漿膜：pleuritis、pericarditis（endocarditis 不算 serositis，不在 criteria 內）

### 診斷、classification criteria 與活動度

1. ANA：sensitive
2. anti-Sm、anti-dsDNA：specific；anti-dsDNA level 與 disease activity 相關（vasculitis、nephritis）
3. low C3／C4
4. 其他抗體對應的表現（總表見 [[自體抗體速查]]）
   - anti-phospholipid → [[Antiphospholipid syndrome|APS]]
   - anti-histone → [[Drug-induced lupus]]
   - anti-ribosomal P → CNS
   - anti-Ro/SSA、anti-La/SSB → [[Neonatal lupus]]

[[SLE 分類標準（EULAR／ACR）|2019 EULAR／ACR classification criteria]] ：fever、skin、joint、CNS、hema、renal、serositis，以及 anti-phospholipid ab、low C3／C4、anti-Sm／anti-dsDNA。



### 治療

1. Hydroxychloroquine：所有病人；輕度皮膚、關節表現可用
2. 輕症：NSAID；較重：low-dose glucocorticoid
3. Organ-threatening／life-threatening（RPGN、hemolysis、systemic vasculitis）：induction → maintenance
   1. Induction：high-dose glucocorticoid＋cyclophosphamide／MMF
   2. Maintenance：cyclophosphamide 換成 MMF／AZA
4. 器官別選藥：[[免疫抑制劑]]

### 預後

Cardiovascular disease：SLE 最常見死因（atherosclerosis → coronary artery disease）。
