# 眼部侵犯：uveitis 與 conjunctivitis

## 內文
### 依症狀定位

Rheuma 病人眼睛必查。

| 症狀 | 定位 |
|---|---|
| 眼窩痛、紅眼、畏光、視力模糊 | Anterior uveitis（iritis） |
| 有黑影 | Posterior uveitis（vitritis、choroiditis、retinitis） |
| 紅眼、眼睛癢想揉、分泌物 | Conjunctivitis |

### 對應疾病與急迫性

| 疾病 | 眼部侵犯 |
|---|---|
| [[SLE (polyarthritis)]] | 偏 posterior uveitis |
| HLA-B27 相關關節炎：[[Spondyloarthritis (oligoarthritis)]] | 偏 anterior uveitis |
| [[Vasculitis\|Behcet]] | Uveitis |
| JIA oligoarthritis 型 | Uveitis |
| [[Vasculitis\|GCA]] | 眼部血管受累 → **急症** |
