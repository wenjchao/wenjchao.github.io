# Systemic sclerosis（scleroderma，SSc）

## 內文
### 機制

- noninflammatory vasculopathy＋inflammatory fibrosis（TGF-β）
- 幾乎必有 Raynaud phenomenon：

[[Raynaud phenomenon]]

### 表現

1. 皮膚：變厚變硬、平順光滑，先 edematous → fibrosis，從手指腳趾往軀幹
2. 手指：limited range of motion
3. 臉：mask-like（loss of expression、皺紋變淺、嘴巴變小）
4. 食道（CREST 的 E）：下 2/3 smooth muscle atrophy 與 fibrosis（對比 myositis：上 1/3）
   - → esophageal dysmotility、LES pressure 下降
   - → dysphagia、GERD、heartburn
   - → aspiration、Barrett esophagus、stricture

### 分型

| | Limited SSc（CREST） | Diffuse SSc |
|---|---|---|
| 抗體 | anti-centromere | anti-Scl-70（ILD）、anti-RNA polymerase III（renal crisis） |
| Raynaud 到皮膚硬化 | 數年 | 數週至數月 |
| 皮膚範圍 | 四肢、臉、脖子（軀幹沒有） | 全身 |
| 標誌 | CREST：Calcinosis cutis（皮下鈣結晶）、Raynaud phenomenon、Esophageal hypomotility、Sclerodactyly（硬指症）、Telangiectasia（皮膚微血管擴張） | ILD → cyclophosphamide；scleroderma renal crisis |
| 肺 | pulmonary hypertension（10%） | interstitial lung disease |
| 預後 | 除 pulmonary HTN 外均不錯 | 差，最常死於 ILD |

2. ILD：cyclophosphamide
3. Raynaud：CCB
