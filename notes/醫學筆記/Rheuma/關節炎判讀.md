# 關節炎判讀

## 內文

### 關節分布


| 疾病 | 關節數與對稱性 | 位置、辨別線索與例外 |
|---|---|---|
| [[Crystal arthritis (monoarthritis)\|Gout]] | Initially asymmetrical monoarthritis | MCP（thumb）、knee、MTP（big toe） |
| [[Crystal arthritis (monoarthritis)\|Pseudogout]] | Asymmetrical monoarthritis（rarely oligoarthritis） | Knees and wrist joints |
| [[Septic arthritis (monoarthritis)\|Septic arthritis]] | Asymmetric monoarthritis | Gonococcal 可為多關節，完整表現見各論 |
| [[Osteoarthritis (monoarthritis)\|OA]] | 原主頁與 OA 標題：monoarthritis（asymmetric）<br>原圖：asymmetrical polyarthritis<br>**差異待核對，尚未統一** | Predominantly weight-bearing joints<br>Spares wrist and MCP |
| Lyme disease、trauma | Asymmetric monoarthritis | （待補 by claude） |
| [[Spondyloarthritis (oligoarthritis)\|SpA]] | Asymmetric oligoarthritis | 肌腱附著處開始發炎的疾病群 |
| [[Spondyloarthritis (oligoarthritis)\|Psoriatic arthritis]] | Asymmetrical polyarthritis or oligoarthritis | DIP、spinal involvement、large joints |
| [[關節炎判讀/JIA（juvenile idiopathic arthritis）\|JIA]] | Oligoarthritis 型 | ANA (+)、uveitis |
| [[關節炎判讀/JIA（juvenile idiopathic arthritis）\|JIA]] | Polyarthritis 型 | RF (+) |
| [[Rheumatoid arthritis (polyarthritis)\|RA]] | Symmetrical polyarthritis | Wrists、MCP、PIP；spares DIP and first CMC<br>Erosive、可有 deformity |
| [[SLE (polyarthritis)\|SLE]] | Symmetric polyarthritis | MCP／PIP；non-erosive |
| [[Sjogren's syndrome (polyarthritis)\|Sjogren]] | Symmetric polyarthritis | MCP／PIP；non-erosive |

- SLE、RA、Sjogren：共同為對稱 MCP／PIP，ANA 可 (+)。
- 三病之中，RA 為 erosive、可有 deformity；SLE、Sjogren 為 non-erosive。

| | Inflammatory arthritis（gout、所有 oligo／polyarthritis） | Osteoarthritis |

| 晨僵 | > 1 hour | < 30 min |
| 活動與疼痛 | 活動後改善 | 活動中／後疼痛、休息緩解 |
