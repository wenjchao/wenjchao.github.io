# 醫學筆記寫作注意

## 內文
### 三種頁面
1. **A 臨床系統**：按系統分（Rheuma、CV、Nephro…），寫疾病本身與 guideline。
2. **B 臨床症狀與處置**：按症狀／任務分，寫 workup、鑑別診斷、急診與病房的緊急處置。例：Transfusion reaction、Urticaria 的處置。
3. **C 基礎醫學**：按機制分（免疫學、生理…），寫原理與機制，**只提及疾病、不展開**（展開留給 A）；**看到治療步驟／劑量就抽去 B**——那是處置、不是機制。

### 誰引用誰（六條邊）
一塊知識只住一處，別頁要用就引用。判準是「對方對我重不重要」：

1. A→B：疾病引用自己的症狀與處置（尤其急診、鑑別）。
2. A→C：疾病引用自己的機制。
3. B→A：症狀引用背後的疾病與 guideline（用疾病視角幫流程背書）。
4. B→C：症狀引用相關機制。
5. C→A：機制引用系統內的疾病（只點名、不展開）。
6. C→B：機制引用它在臨床會遇到的情境。

### 一份正本、到處引用
1. 同一塊知識只寫一次，放它本質所屬的頁；別處用引用拉過來，不複製、不各寫一份。
2. 引用**視如己出**：不要標「這段借自別科」。該引用就引用，讀起來是一個整體。
3. 沒寫或不確定的，留「（… 待補 by claude）」占位，**不自己編醫學內容**進筆記。
4. **兩份共用一大塊 → 抽共用塊、別合併兩者**：兩個實體各留自己獨特的部分，共用的判讀／處置／機制抽成一份正本、兩邊都引用。例：AIHA 與輸血溶血共用「溶血判讀」；各種過敏共用「Anaphylaxis 急救」——抽成正本，別把實體硬併成一個檔。

### 看本質，不看科名
內容住哪看本質，不是它現在掛哪科。例：腎移植抗排斥的本質是移植免疫；廖士程「傾聽與情緒調節」是醫病溝通、不是精神疾病。一份內容被多科需要，就抽成正本讓大家引用。

### 頁面內怎麼排（以 C 頁為例）
A／B／C 決定知識的正本放在哪裡；單篇的閱讀順序，依讀者理解所需的順序安排。相關疾病、功能與應用可接在機制旁，例如 CD40L 缺陷接在 class switching 後面，讓讀者用剛理解的機制推想疾病表現。

### 因果、機制與精簡

**筆記是給人讀懂、記住，之後能回想起來的。** 人一次能處理的資訊有限。十件彼此無關的事，需要分別記憶；如果事情之間有因果，寫清楚第一件事如何導致第二件、第二件為何接到第三件，讀者就能從起點沿著邏輯回想，減少必須各自硬背的項目。白話也是為了讓讀者直接理解內容，少花力氣解讀句子。

1. **先建立能一路跟下去的主線。** 依主題選擇主角與順序，例如細胞的歷程、疾病如何發生，或一個現象如何形成。先交代當下的狀態，再說什麼使它改變，以及改變後會怎樣。標題讓讀者知道走到哪裡；其他細胞、分子或構造在主線需要它時再引入。

2. **把前後兩件事接起來的原因寫出來。** 每寫一個結果，都檢查讀者是否已知道它為何發生。只列「A → B → C」，若讀者仍不懂 A 如何造成 B，就補上必要的中間步驟。
   - 例如，從「B cell 內吞物質」接到「內吞物是否含蛋白質」：含蛋白質，才可分解出能載入 MHC II 的 peptide；只有 LPS、單純多醣，則無法由這些成分產生 peptide。先交代這個分岔，再沿各自條件說明如何取得足夠的活化訊號，讀者才能理解後續反應為何不同，以及接上 carrier protein 為何會改變反應。
   - 「促進、抑制、支持」可以概括已解釋的作用；第一次說明時，交代誰作用於誰、使什麼改變，以接通前後。**讀者能理解整個過程，就可以概括中間步驟；展開到哪一層，取決於這篇筆記要理解什麼。** 更深入的分子細節可另頁展開。

3. **把分岔、並行與循環的關係說清楚。** 條件從哪裡開始不同，就在那裡交代不同去向；反覆發生的過程要說明如何回到前一步，以及為何還需再做一次。**編號既可表示時序，也可整理平行的數件事**；它提供固定位置，關係由內文交代。需要並列整理時可以保留編號，寫清楚哪些可交錯發生、哪些是不同主角的去向即可。
   - **在分岔處交代不同條件，重要分類可與條件放在同一行。** 例如「含蛋白質（T-dependent）／只有 LPS、單純莢膜多醣（T-independent）」，再解釋各自的機制。分類名稱提供記憶錨點，不能代替原因；若先講完其中一種反應，才補充另一種條件，讀者就得回頭重組整段邏輯。
   - 循環可以概括成：「進 GC 後，B cell 在增殖過程中進行 **SHM，接著重新與抗原、Tfh 互動，重複此過程來篩選與抗原結合力強的 BCR**。」一次交代突變、互動、循環與篩選目的。
   - **有先後、同時出現或彼此相關，不等於有因果。** 無法由同一機制推出的知識可以並列比較；不為了串成故事而編造原因。資料不足的環節標為待補。

4. **讓一個機制承接多個結果。** 同一機制再次出現時，指出這次沿用哪個過程、哪個條件改變，幫助讀者用已理解的內容推想新結果。功能、疾病與例外能由機制接起來時，就放在相應位置說明；避免每次都變成一條新的背誦規則。

5. **用白話與具體動作，減少解讀負擔。** 名詞第一次出現時，除必要的全名，也要說清楚當下的身分與作用。一句先講清楚一件事，讓讀者知道誰結合、分解、分泌或改變了什麼。保留專業用詞，也保留理解所需的「因為、因此、如果」；不為縮短字數一律換成箭頭，或省去主詞與條件。

6. **給內容可辨認、可回想的錨點。** 一段文字即使有因果，也需要讓讀者一眼找出重點，並知道細節屬於哪裡。
   - **編號提供位置，粗體短句提示要記什麼，縮排表示歸屬。** 需要提示大項重點時，可用名詞加上具體作用，例如「Class switching：保留抗原辨認能力，改變抗體作用」。條件、疾病與引用收在相應項目下，避免散成沒有歸屬的段落。
   - **短標籤用來幫助比較、排序或辨認歸屬。** 句子本來就清楚，就直接寫；避免先加一個概括標籤，再重講一次。不必每段套同一組欄位，也不必每句都編號。
   - 真正成對的資訊可用對稱子項或小表格，例如「variable region 保留／constant region 改接」。循環則保留步驟，明寫回到哪一步。反覆使用同一組關鍵詞，幫助讀者沿著它們回想。
   - **以實際閱讀畫面判斷層級是否清楚。** 小標題若看起來與內文相同，就用編號、粗體與縮排建立結構。先讓既有項目能容納細節，再考慮增加標題或層級。

7. **精簡以讀者少花力氣理解、回想為準。** 刪重複與無助於理解的包裝，保留接通因果的句子、必要條件與例子。少寫幾個字卻讓讀者自行補出中間過程，反而增加負擔。主線留下理解下一步所需的解釋，延伸細節另放；表格方便比較與複習，不能取代尚未講清楚的機制。

寫完後，沿著讀者的順序再讀一次：**知道前面的事，是否就能理解後面為何發生？忘記一個結果時，能否沿著文中的關係把它想回來？** 原本能由機制接起來的內容若仍只能逐項硬背，先找缺少的連接與說明；無法推導的名稱、數值或獨立事實，則清楚分組，方便記憶與查閱。

修改既有筆記前，先指出原文哪裡造成理解或記憶困難；**優先做能解決問題的局部修改，保留原本已經有效的句子與結構。**

### 縮寫與用詞（讀者是醫學系）
1. 縮寫第一次出現補**英文**全名、不翻中文：LAD1（leukocyte adhesion deficiency）、HSCT（hematopoietic stem cell transplant）。
2. 純英文名詞（functional asplenia、engraftment…）直接用、不加註；普遍熟知的（CMV、TB、SLE…）也不加。
3. **醫學專有名詞使用英文，動作與因果用白話中文說明。** 例如用 germinal center、class switching、variable region、constant region，避免換成讀者不熟悉的中文譯名。同一名詞前後一致；白話說明要讓人理解它的作用，不必另記一套譯名。
