### 自體抗體與對應疾病

| 抗體 | 對應疾病 | 備註 |
|---|---|---|
| ANA | SLE（敏感）；其他 CTD 也常 (+) | 篩檢用，(+) 不等於 SLE |
| anti-dsDNA | SLE（專一） | level 與 disease activity 相關（nephritis、vasculitis） |
| anti-Sm | SLE（專一） | — |
| anti-histone | Drug-induced lupus | anti-Sm、anti-dsDNA 常 (−)；藥物重點 hydralazine、procainamide |
| anti-ribosomal P | SLE CNS involvement | — |
| anti-phospholipid | Antiphospholipid syndrome（APS） | 常與 SLE 一起；triple positive 不可用 DOAC |
| anti-Ro/SSA、anti-La/SSB | Sjogren；母體有 → neonatal lupus（AV block、hepatitis） | — |
| anti-CCP | RA | 專一；與關節破壞程度相關 |
| RF（anti-Fc of IgG） | RA | 不專一；與關節外表現、預後相關；seronegative spondyloarthropathy 的「seronegative」＝ RF (−) |
| anti-centromere | Limited SSc（CREST） | — |
| anti-Scl-70 | Diffuse SSc | ILD、renal crisis |
| anti-U1 RNP | MCTD | — |
| anti-Jo-1 | Myositis＋ILD | — |
| anti-Mi-2 | Dermatomyositis | — |
| anti-PM/Scl | Polymyositis＋SSc overlap | — |
| c-ANCA（anti-PR3） | GPA（Wegener） | — |
| p-ANCA（anti-MPO） | EGPA（Churg-Strauss）、MPA | — |
| low C3／C4 | SLE 活動期 | — |

（待補 by claude：anti-GBM、anti-AChR 等他科抗體要不要收進來）
