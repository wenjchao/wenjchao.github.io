# Hypersensitivity

## 內文
### Type 1: Mast cell + IgE ⇒ vasoactive

1. urticaria & anaphylactic shock (& transfusion-related allergic / anaphylactic reaction)
   1. urticaria ⇒ anti-histamine (H1 > H2)
   2. anaphylactic shock ⇒ epinephine + 輸液
   3. urticaria vasculitis ⇒ steroid, colchicine, hydroxychoroquine
   4. chronic urticaria ⇒ anti-histamine, hydroxychoroquine, cyclosporine, anti-IgE(omalizumab)
2. Asthma
3. food / bee allergy

### Type 2: antibody → attack

1. Autoimmune hemolytic anemia
2. erythroblastosis fetalis
3. Goodpasture syndrome
4. **<u>rheumatic fever</u>**

### Type 3: antibody → immune complex

1. Polyarteritis nodosa
2. immune complex glomerulonephritis
3. SLE
4. rheumatoid arthritis

### Type 4: cell-mediated

1. TB skin tests
2. transplant rejection
3. **<u>allergic contact dermatitis</u>**
