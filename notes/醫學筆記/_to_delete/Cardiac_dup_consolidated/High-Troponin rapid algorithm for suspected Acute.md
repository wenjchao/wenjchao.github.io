# High-Troponin rapid algorithm for suspected Acute Coronary Syndrome (0/1 hour)

## 內文

[[High-Troponin rapid algorithm for suspected Acute/第一步先 Evaluate patients through Symptoms, Vital|摘要]]

⇒ **Rapid algorithm:**

1. 0 hour(initial) Troponin, rule out if very low, rule in if high(>99%)，剩下繼續觀察
2. 1 hour Troponin, rule out if no elevation，rule in if elevation (3~4ng/l 一定算elevation)
3. 真的很不確定的人，3 hours再抽一次
4. [[High-Troponin rapid algorithm for suspected Acute/圖|扁平]]
