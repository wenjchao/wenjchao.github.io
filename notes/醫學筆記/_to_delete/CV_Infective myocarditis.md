# Infective myocarditis

## 內文
1. 小孩子為主
2. viral infection 為主，其他 infection 偶爾會有。可能直接感染心肌或是免疫反應攻擊心肌
3. 病程：common cold → chest pain → weak, chillness, pale → tachycardia, hypotension → arrhythmia / dilated cardiomyopathy → ECMO / transplant
   - 病程變化很快，精神還很好的時候 Vital sign 就有變化了
   - 小孩不會抱怨胸痛、喘，可能一出事就 shock，所以要很注意兒童急診 ABC：pallor, cold sweating, jugular vein engorgement, hepatomegaly
4. 檢查：CXR, ECG, Troponin, NT-proBNP, SvO2(看 heart failure 程度)
