# Meningitis: 經不起拖延，當作抗藥性感染

## 內文
1. ㄧ、二代 cepha 進不去 BBB（就算 meningitis 發炎）
2. S. pneumonia, H. influenza, N. meningitides, K.P. ⇒ 3rd Cepha(可升級Mepem) + Vanco
3. 老人、immunocompromise ⇒ 多 cover **<u>Listeria</u>** ⇒ 上面 + Ampicillin
4. 新生兒：<u>GBS</u>, <u>E.coli</u>, **<u>Listeria</u>**（陰道菌）⇒ 還是 3rd Cepha + Ampicillin ± Vanco (Cepha 可換 Gentamicin)
5. [[Meningitis 經不起拖延，當作抗藥性感染/CSF lab data：Glucose (只會變少)、WBC (& type，只會變多)|扁平]]

- **meningeal sign** (畏光、噁心嘔吐、脖子僵硬)⇒ <u>meningitis</u> / <u>SAH</u> / <u>migraine</u>
