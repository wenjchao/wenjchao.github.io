# Connective tissue disease

## 摘要
- 共通：ANA (+)、多系統侵犯 → 用專一抗體分病。
- 差別：主攻的組織不同 → 表現不同。
- 易混的組合：
  1. 對稱多關節炎：SLE、RA、Sjogren
  2. 皮膚＋食道＋ILD：SSc、DM／PM
- 跨病共用的病灶：ILD、PHTN、Raynaud、neonatal lupus。

## 內文
### 對稱多關節炎：SLE、RA、Sjogren

- 相同：對稱 MCP／PIP、ANA 可 (+)
- 不同：主攻的組織
  - SLE：沉積
  - RA：滑膜
  - Sjogren：外分泌腺

| | [[SLE]] | [[Rheumatoid arthritis\|RA]] | [[Sjogren's syndrome\|Sjogren]] |
|---|---|---|---|
| 主攻 | immune complex 沉積（Type III）→ 沉積到哪就發炎到哪 | 滑膜炎（RF：Type III）→ 軟骨流失 | 外分泌腺淋巴球浸潤 |
| 關節 | non-erosive | erosive、deformity | non-erosive |
| 抗體、HLA | anti-dsDNA、anti-Sm（專一）、low C3／C4；DR2／DR3 | anti-CCP（專一）、RF；DR1／DR4 | anti-Ro/SSA、anti-La/SSB |
| 皮膚 | [[Cutaneous lupus\|malar／subacute／discoid]]（光敏）、alopecia、oral ulcer | nodule（granuloma） | — |
| 肺 | pleuritis（漿膜） | ILD、nodule | ILD |
| 腎 | [[Lupus nephritis\|lupus nephritis]]（腎絲球） | — | RTA type 1（腎小管） |
| 血液 | 血球低下、[[Antiphospholipid syndrome\|APS]] | Felty（neutropenia） | MALT lymphoma |
| 特有 | CNS、pericarditis；死因 CV | vasculitis | sicca |
| 治療 | hydroxychloroquine 全員 → 依器官升階 | MTX 首選 | 人工淚液；關節 hydroxychloroquine／MTX |

### 皮膚＋食道＋ILD：SSc、DM／PM

- 相同
  - 皮膚、食道、ILD 都侵犯
  - 抗體對應到器官
- 不同
  - 主攻的組織：SSc 血管與纖維化；DM／PM 肌肉
  - Steroid：SSc 禁用；DM／PM 首選

| | [[Systemic sclerosis\|SSc]] | [[Myositis\|DM／PM]] |
|---|---|---|
| 主攻 | 血管病變（不發炎）＋纖維化（TGF-β） | 肌肉發炎（DM perimysial CD4、PM endomysial CD8） |
| 皮膚 | 硬化（末端 → 軀幹）、CREST | heliotrope、Gottron（DM） |
| 食道 | 下 1/3（平滑肌纖維化） | 上 1/3（骨骼肌） |
| 手、肌力 | 手指 ROM ↓（皮膚硬） | 近端對稱無力、CK ↑ |
| Raynaud | 幾乎必有、先行 | — |
| 抗體 → 器官 | anti-centromere → limited、PHTN；anti-Scl-70 → diffuse、ILD、renal crisis | anti-Jo-1 → ILD；anti-Mi-2 → DM |
| 急症、風險 | renal crisis → ACEi | DM → 癌症（breast、lung）survey |
| Steroid | 禁用（誘發 renal crisis） | 首選 → AZA／MMF／MTX → IVIG |

### 同一病灶、跨好幾個病

| 病灶 | 出現在 | 意義 |
|---|---|---|
| [[Interstitial Lung Disease ⇒ Fibrotic Lung Diseases\|ILD]] | RA、Sjogren、SSc diffuse、DM／PM（anti-Jo-1） | 同一種藥：steroid＋cyclophosphamide；MTX 禁用（[[免疫抑制劑]]） |
| PHTN | SSc limited、MCTD | MCTD 最常見死因；limited SSc 預後唯一的問題 |
| [[Raynaud phenomenon\|Raynaud]] | SSc（主攻過程本身）；SLE、Sjogren、MCTD（伴隨） | 甲摺鏡分 primary／secondary；保溫、CCB |
| non-erosive arthritis | SLE、Sjogren | 與 RA 的 erosion 區分 |
| neonatal lupus | 母體 anti-Ro/SSA、anti-La/SSB（SLE、Sjogren） | AV block、hepatitis |

### Overlap 與變體

1. [[Mixed connective tissue disease|MCTD]]：anti-U1 RNP → 以上全部的 overlap
   - Raynaud（90%）、arthritis、myositis、GERD
   - 死因：PHTN
2. Drug-induced lupus：hydralazine、procainamide
   - anti-histone (+)
   - anti-dsDNA、anti-Sm 常 (−)
