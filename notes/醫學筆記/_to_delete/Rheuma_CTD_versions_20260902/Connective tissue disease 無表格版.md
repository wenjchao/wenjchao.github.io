# Connective tissue disease 無表格版

## 摘要
共通：ANA (+)、多系統侵犯 → 專一抗體分病 → 各病主攻一種過程：沉積（SLE）、滑膜（RA）、外分泌腺（Sjogren）、血管與纖維化（SSc）、肌肉（DM／PM）、overlap（MCTD）→ 同一器官的病灶跟著過程走。

## 內文
### 主攻什麼，就長什麼樣

1. [[SLE]]：immune complex 沉積（Type III）→ 沉積到哪就發炎到哪——皮膚（光敏）、關節（non-erosive）、腎絲球（nephritis）、漿膜（pleuritis／pericarditis）、CNS；另有血球低下、APS。標記：ANA（敏感）、anti-dsDNA／anti-Sm（專一）、low C3／C4。
2. [[Rheumatoid arthritis|RA]]：滑膜炎 → 軟骨流失 → 對稱 MCP／PIP、erosive；關節外：nodule（granuloma）、vasculitis、ILD、Felty。標記：anti-CCP（專一）、RF。
3. [[Sjogren's syndrome|Sjogren]]：外分泌腺淋巴球浸潤 → sicca；B-cell lymphoma（MALT）；non-erosive arthritis、ILD、RTA type 1。標記：anti-Ro/SSA、anti-La/SSB。
4. [[Systemic sclerosis|SSc]]：noninflammatory vasculopathy → Raynaud 先行、PHTN、renal crisis；fibrosis（TGF-β）→ 皮膚硬化（末端 → 軀幹）、ILD、食道下 1/3。標記：anti-centromere（limited）、anti-Scl-70（diffuse）。
5. [[Myositis|DM／PM]]：肌肉發炎（DM perimysial CD4、PM endomysial CD8）→ 近端對稱無力、CK ↑、食道上 1/3；DM 另有皮疹（heliotrope、Gottron）與癌症。標記：anti-Jo-1（ILD）、anti-Mi-2（DM）。
6. [[Mixed connective tissue disease|MCTD]]：以上的 overlap → Raynaud（90%）、arthritis、myositis、GERD；死因 PHTN。標記：anti-U1 RNP。

### 同一器官、不同過程

1. 腎：沉積 → 腎絲球 → SLE [[Lupus nephritis|lupus nephritis]]；血管 → 腎動脈阻塞 → renin → SSc renal crisis（ACEi、禁 steroid）；腎小管 → Sjogren RTA type 1。
2. 肺：漿膜 → SLE pleuritis；間質纖維化 → [[Interstitial Lung Disease ⇒ Fibrotic Lung Diseases|ILD]]（RA、Sjogren、SSc diffuse、DM／PM anti-Jo-1）；肺血管 → PHTN（SSc limited、MCTD）。
3. 食道：平滑肌纖維化 → 下 1/3（SSc）；骨骼肌發炎 → 上 1/3（DM／PM）。
4. 關節：滑膜是主攻 → erosive（RA）；滑膜是旁觀 → non-erosive（SLE、Sjogren）。
5. 血管：vasculopathy（不發炎）→ [[Raynaud phenomenon|Raynaud]]（SSc 幾乎必有；SLE、Sjogren、MCTD 也有）；vasculitis（發炎）→ RA、SLE。
6. 皮膚：UV 誘發 → photosensitive rash（SLE，[[Cutaneous lupus|cutaneous lupus]]）；纖維化 → 硬化（SSc）；肌炎伴隨 → heliotrope、Gottron（DM）；granuloma → nodule（RA）。

### 共用的其他

1. 母體 anti-Ro/SSA、anti-La/SSB（SLE、Sjogren）→ 經胎盤 → neonatal lupus（AV block、hepatitis）。
2. [[Antiphospholipid syndrome|APS]] 常與 SLE 併存；drug-induced lupus（hydralazine、procainamide）→ anti-histone。
3. 治療：同一器官用同一種藥（[[免疫抑制劑]]）；SSc 禁 steroid。
