# Hallucinations: 開放式問題為主

## 內文
內容：3C

1. Commanding：聲音叫我去…
2. Commenting：聲音批評我…
3. Conversing：聲音互相聊天

影響：ABCD

1. Affect：聲音影響心情
2. Behavior：聲音說什麼就做什麼(commanding ⇒ B)？會和聲音講話(Conversing ⇒ B)？
3. Cognition：害我無法專心、影響效率(Conversing ⇒ C)
4. Drive：一直罵我害我吃不下睡不著(commenting ⇒ D)

其他需注意事項：

1. 視幻覺內容：溫馨⇒dementia, 恐怖⇒delirium
2. 聞到味道不要先問嗅幻覺，先問居家環境（一週洗幾次澡？）
3. 心情不好時才有聲音⇒mood disorder with psychotic feature / 心情平順時也有聲音⇒schizoaffective disorder
4. substance use
