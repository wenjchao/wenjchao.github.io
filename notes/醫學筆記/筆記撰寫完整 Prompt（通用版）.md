# 筆記撰寫完整 Prompt（通用版）

## 內文

**任務：依指定 reference，寫出讀得懂、記得住的筆記**

請依「本次任務設定」與使用者當次指示，實際完成筆記、必要模組、圖片、引用與驗收，不只提出大綱或建議。最重要的判準依序是：**1. 好不好懂；2. 好不好記。先懂，才能記。**

這是一份可跨主題、跨 reference 格式使用的完整寫作指令。主題、輸出位置與來源由當次任務決定，不預設 First Aid、免疫學、特定細胞、某一本書或某一個模型。預設讀者是有基礎背景、正在學習與記憶新內容的醫學生，使用繁體中文解釋動作與因果，保留英文醫學名詞；其他領域依指定讀者與術語調整。

請讀完全文再動筆，尤其是 **24 個負面案例、兩份完整章節的前後對照、讀者驗證與驗收方法**。不能只讀原則、擷取一個成功段落，或把本文縮成幾條抽象規則後執行。要複製的是寫作判斷，不是某篇的固定標題或版面。

## 零、先遵守檔案與 reference 的界線

這些限制適用於全文、子 agent、圖片、引用、索引與驗收；優先於下文及示範材料中的重整、去重、補足因果等做法。

1. **不要更改現有檔案。** 執行開始前已存在的筆記、子模組、圖片、目錄、索引與寫作規則，一律唯讀。不得覆寫、搬移、改名、刪除、加連結、刪摘要、抽走共用內容或順手勘誤。備份不等於獲得修改授權。「一份正本」「引用要完整」「修到好懂」都不能成為改動既有檔案的理由。
   - 只寫本次新建的目標筆記、必要新模組、新圖片與工作紀錄；新增路徑須先確認不存在。若指定目標已存在，另存有明確名稱的新稿，保留原檔。
   - 本 Prompt 本身不授權任何既有檔案修改。只有使用者在當次任務明確指定例外檔案及改動時，才執行該項例外；使用者已在對話中明確授權的改動直接記入例外，不必再要求填表或重複確認。例如只要求在目錄加一個入口，不能推成准許重寫目錄或被引用的筆記。
   - 既有檔案有錯誤、缺漏或重複時，只記錄位置與問題；不要直接修正。驗收需要重建索引時，在獨立預覽副本中進行，不能因此覆寫正式索引。
2. **不要新增核准 reference 以外的知識內容。** 第一節「本次任務設定」中的核准 reference 是知識內容來源清單；未列入的教材、論文、網頁、模型知識、既有筆記、示範與先前對話，不能自行變成補充來源。即使外部資料可信、已附 citation，或有助於理解，也不能直接加入。
   - 可以在核准 reference 集合內跨章、跨檔找相關資料、重排、改寫為白話、整理比較與圖示；每個新增的定義、機制、條件、例外與疾病關聯，都須有 reference 支持。
   - 「幫讀者接通因果」不允許憑自己的領域知識補出 reference 沒交代的中間步驟。寫作示範教的是方法，示範中的知識細節及其外部來源不自動獲准使用。
   - 圖片、圖說、比較表與全文嵌入也遵守相同邊界。不能用引用外部資料或既有模組的方式，將 reference 外內容帶進新稿。
3. **Knowledge gap 留在所屬位置，標明待補。** 仿照 [血液腫瘤.md](</Users/wenj/Courses/wenjchao.github.io/notes/醫學筆記/Hema/血液腫瘤.md>)：依實際執行者使用 `（待補 by {執行者}：此處尚缺的具體問題）`，例如 `（待補 by codex：……）` 或 `（待補 by claude：……）`；不需要解釋缺項時可省略冒號後的文字。`{執行者}` 必須換成實際名稱，不能留成未填參數。歷史案例中的原標記則保留。
   - 保留 reference 已交代的內容，只在缺的關係、條件或比較格標記；不要把已知內容全部抹成待補。
   - 例如 `EGF：〔依 reference 寫出已知作用〕。（待補 by codex：它如何接到此處修復工作的具體關係）`。方括號是本例的填寫提示，不能原樣貼入正文，也不能憑記憶把缺項填滿。
   - 不先寫一段 reference 外的答案，再加「待補」當作保留它的理由；也不能刪掉外部網址卻保留其新增事實。
   - 有具體待補標記可以交付。誠實保留缺口，比擅自補成看似完整的機制更符合本任務。

工作紀錄先列出：核准 reference、允許新增的檔案／位置、使用者明示的既有檔案例外（未指定就是沒有）。子 agent 必須收到同一份界線，不能藉分工擴大範圍。

## 二、最重要的判準：先懂，才能記

使用者明確要求：

> 重要的是 1. 好不好懂 2. 好不好記。要先懂才能記。不要讓它變得緊湊而因此不白話；文字一樣可以很白話，但是在更好讀的情形下更好記。

請依此判斷每項編輯：

- **不把緊湊、字少或資訊密度當作目標。** 可以使用完整句子、必要條件與例子，讓讀者直接理解。
- **資訊多本身不代表好。** 不因為能補某個分子，就無限展開細節；展開到讀者能理解這個主題、接得上下一步為止。
- **核准 reference 中的相關知識要完整涵蓋。** 完整性看新主文、新子模組與符合來源界線的唯讀引用合起來是否有交代，不要求把每一項都寫進同一頁；reference 沒提供的連接標為待補，不以完整性要求擴大來源。
- **未另行指定時，不設字數上限，也不以篇幅切檔。** 不套用通用規則中的 1500 字限制；篇幅本身不是本任務的品質問題。
- **未另行指定時，新筆記與新模組不寫摘要。** 不因通用規則提到摘要而新增摘要，也不要在各節末尾反覆重述剛講過的內容。不能為遵守此條去刪除既有檔案的摘要。能建立起始狀態或接通下一步的引言、過渡句可以保留。
- **保留必要的「因為、因此、如果」。** 通用規則要求刪的是冗餘連接詞；不能把接通理解的原因一併刪掉。

若材料間有衝突，以上使用者明確要求優先。不要再把任務理解成「把資料壓縮、排整齊」。

## 三、先決定讀者要跟著誰、理解什麼

每篇先想清楚：讀者讀完要能理解、分辨或運用什麼？過程類內容才進一步問：從什麼狀態開始、什麼使狀態改變、改變後會怎樣。概念分類、公式、數值或獨立事實，則依定義、分類依據、適用條件、變項關係或比較建立主線，不硬補一套事件順序。

依主題選擇主線，例如細胞的發育與活化、病原進入後的反應、某種功能如何完成，或一個現象如何形成。其他細胞、分子與構造，在理解它們的作用時再引入。

針對細胞，可以自問它在哪裡、遇到什麼、如何辨認、受到哪些訊號影響、對誰做了什麼、結果如何，以及怎樣停止或受到抑制。這些是幫助規劃的問題，**不要求每篇都套用相同欄位或全部變成標題**。

歷史成功稿的主線可供參考；它們示範選擇順序的理由，不是本次固定章節：

- **先天免疫**：局部辨認刺激、招募細胞與蛋白質、依目標的位置與大小清除、連接 T cell 並受到回饋、刺激消退或持續後的走向。其中多項可同時發生，要把並行關係說清楚。
- **Complement**：先理解切開 C3／C5 的作用，再理解放大與不同入口，接著看調控、缺陷與功能檢驗。從共同作用開始，有助讀者理解前面的路徑在完成什麼；不必照分子編號或原書順序敘述。

不要為了串成故事製造假因果。獨立事實、名稱和數值可以分組比較，不必勉強從同一個機制推導。

## 四、讓編號、粗體與縮排呈現真實關係

**編號提供位置，粗體短句提示要記什麼，縮排表示細節屬於哪裡。**

1. **主項有可辨認的主角與動作。** 例如「與 lysosome 融合，讓酵素與 ROS 清除病原」，比只寫「Lysosome」更能提示此步的意義。
2. **項目內可以保留完整白話段落。** 不需要把每句切成 bullet，也不需要把段落壓成名詞與箭頭。
3. **同層內容的關係要清楚。** 編號可以表示先後，也可以提供平行項目的固定位置；關係由文字說明。不能把結果、造成結果的方法、疾病例子混列成同一種分類。
4. **分支從條件不同的地方開始。** 條件與分類名稱盡量一起出現，再各自解釋結果。不要先說完一種反應，最後才補另一種條件，讓讀者回頭重組。
5. **補充跟著所屬項目。** 受體細節歸辨認，酵素缺陷歸該反應，圖與圖說歸所解釋的過程，疾病與引用歸能解釋它的機制。表格放在某項後面時，實際畫面也必須看得出它屬於該項。
6. **單篇列點不超過三層，並檢查展開後的畫面。** 優先讓現有項目容納細節，避免一小段內容套很多層標題。
7. **粗體要幫助回想。** 選短而具體的作用、條件或決定性關聯；不要把整頁名詞都加粗，也不要每段先加空泛標籤再重講一次。

只有大標題，下面聚集許多無歸屬段落，仍然不合格。把這些段落各加一個圓點，也沒有解決關係問題。這項檢查要涵蓋每一節及每個子模組，不能只修第一節。

## 五、用白話補上理解所需的連接

### 名詞第一次出現，要有身分與作用

英文全名只能解開縮寫，不能代替理解；全名本身也須有核准 reference 支持，不能憑記憶展開。其他領域同樣要解釋名詞在本題的身分與作用。讀者應知道它是細胞、被辨認的物質、受體、細胞內蛋白、分泌訊號，還是酵素複合體；需要時交代所在位置。

例如 PRR、PAMP、DAMP、TLR、NF-κB 不能一次堆成一句話，便視為已經解釋。可先用 LPS 被 TLR4 辨認的具體例子，交代訊號如何進入細胞、NF-κB 如何改變基因轉錄，再把「被辨認的成分／辨認者／後續訊號」對上。PAMP 與 DAMP 則用來源比較。圖中的縮寫也要考慮出場順序。

每個「促進、抑制、支持」都檢查：讀者是否知道誰作用於誰，使什麼改變？若不知道，先在核准 reference 內找必要的中間動作；沒有交代就保留已知作用，於缺口標 `（待補 by {執行者}：尚缺的具體關係）`，不自行編入答案。若已理解，就可以概括，不必再次展開整套分子細節。

### 以相同條件比較不同對象

共同條件先交代，再對稱說明各對象的原因與結果。完整的 MHC I／CD8／NK 歷史失敗稿與使用者選定文字，見第十節案例。

若同一句「促進辨認」在不同細胞上意義不同，必須在核准 reference 內核對作用對象；仍不能確定就標出待補問題，不靠排版或 reference 外的補充消除疑點。

### 循環交代回到哪裡、為什麼重複

以 SHM 為例，需要讓讀者理解突變後重新與抗原、Tfh 互動，並透過反覆過程篩選結合力較強的 BCR。不必每一輪重講全部細胞移動與分子名稱。

以補體放大為例，要交代 C3b 協助組成更多能切 C3 的複合體，再產生更多 C3b；不能寫得像 C3b 自己增殖。

## 六、比較要真的能比較

- 有多個可比較面向時，優先考慮表格，例如 CD4／CD8、細胞分泌物、補體路徑、調控蛋白或檢驗結果。
- 表格可以在初次閱讀時建立理解，不限於最後複習。表內若已把機制講清楚，不必再在表外重寫一次。
- 每欄固定回答同一問題。標題是位置，就不要某列填位置、另一列填殺傷目標；標題是相關介質，就不要填疾病例子。
- 同一格可以有白話解釋，也可以分行區分不同作用對象。表格不等於只能放縮寫。
- 當條件、結果或作用對象不同，用對稱項目或固定欄位比較。無法共用同一比較問題時，調整分組，別把所有資料塞進一張混雜大表。
- 已有效的表格應保留。不要為了增加敘事，把本來容易比較的資訊拆散成許多段落；也不要為填滿空格編造知識內容。

1. **先盤點全部核准來源，確認實際閱讀範圍。** 建立檔案或來源清單，記錄格式、版本／日期、章節或頁數等可核對資訊。區分「列出檔案」「定位相關內容」「實際讀過」；三者不能互相冒充。文字擷取與關鍵字搜尋可用於定位、核對與查缺漏，不能代替逐段、逐頁讀原文及圖表。
2. **依來源格式閱讀，不把所有 reference 當成 PDF。**
   - **書籍／PDF**：確認版次、主要章節、印刷書頁與 PDF 頁碼對應；讀相關文字、圖表、圖說、註腳與頁間接續。低清文字擷取若錯列或漏字，要回看原頁與同一核准來源的相關頁。
   - **投影片／簡報**：使用原始投影片編號，盤點一般頁、隱藏頁、備註及內嵌圖表、物件、影音。若指定全部 slides，就完整閱讀全部頁面，包括重複頁及隱藏頁。注意動畫、遮罩或轉檔可能讓圖看似空白；先檢查原始物件與可取得的呈現，不能立即判定 reference 缺圖，也不能自己猜箭頭。
   - **文件／網頁／圖片／資料表**：依原有段落、標題、圖表與註腳閱讀；定位可使用文件章節、頁碼、網址與存取日期、圖號、工作表或資料範圍。來源內連向其他網站或引用其他文獻，不代表那些外部來源自動獲准使用。
   - **影音**：記錄實際閱讀的畫面、時間範圍、字幕或音軌。只看取樣影格、未解讀音軌，就明寫這項限制，不能宣稱完整理解影音內容。必要資訊無法取得時，在對應位置標明具體待補。
3. **多版本逐一讀、逐一比較。** 使用者提供多份或要求所有版本時，不假設最新版包含全部舊內容，也不因檔名相近就略過。保留各自定位，記錄重複、新增、刪除、改述與互相矛盾之處。相同事實可以合併呈現，但來源去向須保留；版本差異無法由核准 reference 解決時，說清楚差異與待補，不憑常識選一版當定論。
4. **在核准來源集合內查找跨章、跨檔的相關內容。** 先讀主要部分，再用目錄、索引、全文搜尋與相關概念找其他必要內容。例如免疫學可能需要核對同一核准書籍的發炎、血球或屏障章節；其他主題按其實際關聯查找。不能將命中頁清單當成已完整閱讀的證據，也不能自動擴展到未核准的書、版本或網頁。
5. **建立內容去向表，放在工作紀錄而非教學正文。** 至少記錄「來源與確切定位、具體知識內容及適用的動作／對象／條件／限制、放入哪份筆記與哪一節、處理狀態」。定位與內容欄依來源及主題調整，不強迫每種來源填 PDF 頁碼，也不為分類、公式或數值編出機制。不能只記「MHC：已保留」，而漏掉它呈現什麼、由誰辨認。原文的例外、限制、比較、數值、圖與註腳也要有去向。
6. **涵蓋 reference 中所有與目標主題相關的資訊。** 整理到本次允許寫入的主文或子模組；既有正本只能依第零、九節處理。不能以「不夠核心」為由漏掉使用者要求的相關內容；也不要為證明完整，把整個來源庫的無關內容塞進主文。已閱讀但超出主題的部分記錄理由。多處重複同一內容可合併，仍須保留各處有意義的條件與差異。
7. **reference 沒寫的必要連接，標待補。** 先查其他核准來源；仍找不到，就保留已交代的部分，用 `（待補 by {執行者}：reference 尚未交代的具體問題）` 標在所屬位置。不要自行加入原始研究、教材、官方資料、指南或模型記憶的答案；附 citation 也不等於獲准擴大 reference。只標理解本次主題所需的真正缺口，不把所有未提及的延伸主題都列成待辦。
8. **不自行修補看不清的字或可疑機制。** 重新檢視原始頁面、圖、投影片物件與核准來源中的相關內容；未能確認就標待補。調高輸出解析度不能補回原檔細節，也不能用另一版或其他教材的內容冒充指定來源原意。
9. **保留名稱、數量與因果的強度。** 核對縮寫、複合體名稱、圖中箭頭、軸名、單位、作用對象、條件及例外；區分比例與絕對數量、發生時機與持續時間、觀察到的狀態與推測的歷程、相關與因果。不同用語或來源互相衝突時，只寫有支持的內容，不能憑記憶改圖或補出結論。疑點位於未授權修改的既有筆記時，只記錄位置。
10. **區分來源中的機制、描述、推論與應用建議。** 機制筆記不能擅自變成現行臨床建議；臨床或處置筆記可整理核准 reference 已載、屬本次範圍的內容，但不可自行增加新 guideline、治療步驟、劑量或未支持的判準。不要把連到既有頁面說成已查證該頁全部內容。
11. **來源核對要能區分已知與缺口。** 每項新增事實都應能追溯到核准 reference 的確切依據；來源不足者記錄「待補」及正文位置，不能只因外部網站有答案就改成「已補齊」。誠實說明無法取得或未完整讀取的部分，不用總頁數掩蓋限制。

## 八、圖片是理解的一部分

在有空間關係、路徑匯合、循環、跨膜作用、細胞互動、時間變化或其他不易只靠文字理解的地方，主動判斷是否需要圖。圖的數量由理解需求決定，不預設固定張數。

- 檢查核准 reference 是否有適用圖，可以擷取相關部分並保留來源；不自行找未核准的網站或教材圖片加入。若使用者另核准圖片來源，依核准範圍使用，並避免從圖說帶入未核准的額外知識。
- 可以依 reference 另製示意圖，但作用者、方向、位置、條件及圖說均須有 reference 支持，清楚標示是整理繪製。缺少的路徑或標示留待補，不能憑知識畫完整。新圖片使用新檔名，不覆蓋既有圖片。
- 圖放在解釋它的內容旁。圖說告訴讀者從哪裡看、箭頭或不同區域表示什麼，以及哪些命名需要注意；陌生縮寫要在讀者需要時有身分與作用。
- 保留來源與適用定位，例如書頁／PDF 頁碼、原投影片編號、圖號或時間碼。不要用一張特定例子的圖，暗示它代表所有受體或所有反應。
- 實際確認字看得清楚、裁切沒有漏掉圖例、單位、來源中重要條件或相接路徑，讀者能追蹤方向。預設顯示太小時，確認能在實際檢視器放大並讀清楚；僅輸出高解析度檔案不等於畫面可讀。
- 轉換結果空白、被遮住或缺字時，先核對原始檔的圖片、向量物件與其他可取得內容；圖確實無法辨讀才保留缺口，不猜出一張看似合理的圖。
- 一張整合圖和一張局部機制圖可以各有用途，不必為了「不重複」刪掉其中一張；也不必讓每個段落都配裝飾性圖片。

不要把「某版本有一個壞段落」推論成整個版本都不好，也不要學成禁用某個符號或固定少寫幾句。每次都判斷：**讀者在哪裡失去理解或位置？修改補回了哪個關係？是否犧牲了原本有效的部分？**

### 案例 1：把資料壓得很密，讀者仍不知道每一句在回答什麼

**使用者在寫作規則中明列的壞例子（S01）：**

> 兩層：先天（快、廣、無記憶）擋前線；後天（慢、專一、有記憶）精準清除，再分體液（B／抗體）與細胞（T）。失衡兩個方向：太強 → 自體免疫、過敏；太弱 → 免疫缺損 → 感染。治療＝反向調控：壓下（免疫抑制）／放出（腫瘤免疫）。

**失敗點**：先後混入防禦分工、分類、失衡與治療；「兩層」「兩個方向」只在數東西，沒有說清楚分類的意義。分號與括號把不同理解任務擠在一起。讀者要自己拆解，再記住它們的歸屬。

**改寫方向**：若這一頁要比較功能、失衡與人為調控，就分別以有意義的主項呈現；若這一頁要解釋先天免疫，就先沿感染時的反應展開，不把全套免疫學塞進開頭。本次還明確不要摘要，因此不能把這段修短一點就放回摘要。

**不要矯枉過正**：數字、箭頭、括號本身沒有錯。能清楚指向同一件事的短因果可以保留。問題是用符號把幾種不同關係縫成一句，讓讀者自行解碼。

### 案例 2：把白話誤寫成擬人故事，還產生錯誤直覺

**使用者明列的其他壞例子（S01）：**

> 先天免疫第一時間就到：快、不挑對象、打完不記得。

> 病原進來，免疫系統分兩批出手。

同一組負例還使用「見誰擋誰」「B 細胞派抗體出去打」「T 細胞自己上場」「疫苗用的就是這個記性」。

**失敗點**：看似口語，卻沒有交代真正動作。「不挑對象」會掩蓋先天辨認仍有特定受體與條件；「分兩批」容易讓人以為先天結束，後天才開始。「T 細胞自己上場」也沒有分清 helper T cell 與 cytotoxic T cell 的作用。

**現行稿的處理（S03）**：使用「局部細胞辨認刺激」「使內皮增加黏附分子」「清除受感染細胞」「活化的 T cell 以 cytokines 增強其他細胞的工作」。它仍然白話，但讀者知道誰作用於誰、改變了什麼。

**不要矯枉過正**：不要改成生澀的中文術語堆疊。保留英文醫學名詞，動作使用清楚的中文。也不是所有比喻一律禁止；若比喻省不了理解，或暗示錯誤機制，就不用。

### 案例 3：英文全名都補了，名詞的身分仍沒有建立

**歷史原文（S02，第 13–15 行）：**

> 辨認入侵或損傷：PRR（pattern recognition receptor）辨認病原或受損細胞的共同成分。TLR（Toll-like receptor）是其中一類；收到訊號後可活化 NF-κB（nuclear factor κB），使細胞產生促發炎 cytokines。
>
> PAMP（pathogen-associated molecular pattern）來自病原，例如細菌 LPS（lipopolysaccharide）、flagellin、病毒核酸。
>
> DAMP（damage-associated molecular pattern）來自受損細胞，例如 mitochondrial DNA、histones、heat shock proteins。

使用者當時明確說，這段完全看不懂。

**失敗點**：一次引入五種抽象名詞，沒有先讓讀者知道誰在細胞外、誰是受體、誰在細胞內，也沒有解釋「活化 NF-κB」如何接到「製造 cytokines」。知道英文全名仍然可能完全不懂。

**教學改寫：**

1. **先說被辨認的是什麼**：LPS 是 gram-negative bacteria 外膜的成分。
2. **再說誰辨認它**：macrophage 表面的 TLR4 與協助蛋白辨認 LPS，將訊號傳進細胞。
3. **接上細胞內發生的改變**：NF-κB 是 transcription factor；活化後可進入細胞核，增加相關基因轉錄，使細胞製造、分泌促發炎 cytokines。
4. **有具體例子後，再對上概念**：LPS 是 PAMP 的例子；TLR4 屬於 TLR，而 TLR 是 PRR 的一類。DAMP 則從受損自身細胞而來，與 PAMP 依來源比較。

完整章節的排列見下一節示範 A。這些句子需要圖顯示位置，不能把圖中的縮寫當成已經解釋。

**不要矯枉過正**：NF-κB 已在這個位置講清楚，後文就能概括為「增加 cytokine 製造」。不必每次再重講所有細胞內訊號，也不必把整套 TLR 訊號蛋白加入主文。

### 案例 4：細胞功能表有資料，卻還沒教會讀者這些細胞在做什麼

**歷史原文（S02，第三節表格）：**

| 細胞 | 舊稿的主要說明 |
|---|---|
| Dendritic cell | 吞噬、處理抗原，將抗原呈現給 T cell，連接後天免疫。 |
| NK cell | 使病毒感染細胞及腫瘤細胞發生 apoptosis。 |
| Eosinophil | 以 major basic protein 等顆粒成分對抗 helminths。 |

**失敗點**：這張表能查功能名稱，但尚未解釋作用。讀者仍會問：DC 吞進去後怎麼讓 T cell 看見？NK 如何辨認該清除的細胞，又如何引發 apoptosis？為什麼 eosinophil 要把顆粒釋放到外面？

**教學改寫方向，依 S03 及相關模組整理：**

- **DC**：局部攝入抗原，移向引流 lymph node；將蛋白質分解成 peptide，用 MHC 呈現，配合共刺激啟動相應的 naive T cell。把「從局部到 T cell」中間缺的動作接起來。
- **NK**：病毒已利用宿主細胞複製，因此清除對象是受感染的自身細胞。先說它如何整合活化、抑制或抗體提供的辨認訊號，再說顆粒如何引發目標細胞 apoptosis。
- **Eosinophil**：大型 helminth 難以整個吞入，因此可將顆粒釋到細胞外、損傷寄生蟲表面；IL-5 如何增強細胞作用、抗體如何協助辨認，分別放在對應位置。

**不要矯枉過正**：保留好用的比較表。若表內已能充分解釋共同問題，就不需要表外再寫一次。要避免的是只有功能標籤，卻以為讀者已學會機制。

### 案例 6：已經有 bullet，不代表同層的東西真能並列

**歷史原文節錄（S05，吞噬後如何殺菌，第 32–34 行；省略縮寫全名與末尾延伸引用）：**

> - Catalase、glutathione peroxidase 可移除 H₂O₂。
> - Glutathione peroxidase 使用還原型 GSH，使它變成氧化型 GSSG；glutathione reductase 再利用 NADPH 將 GSSG 還原為 GSH。
> - G6PD 參與 pentose phosphate／HMP shunt，提供 NADPH。

**失敗點**：列點已存在，但三項分別是清除反應、材料再生、材料來源。若讀者把它們記成「三種清除方式」，便失去彼此關係。

**現行稿的安排（S06）：**

1. **移除 H₂O₂**：說明清除反應與 GSH 的使用。
2. **把 GSSG 還原成 GSH，繼續清除氧化物**：說明 NADPH 參與再生，並明說回到前面的清除反應。
3. **由 HMP shunt 提供 NADPH**：交代供應，連回生成 ROS 與再生 GSH 的不同用途。

**不要矯枉過正**：不是必須把第二、三項無限往內縮排。編號仍可提供固定位置；但標題與文字必須說出清除、再生、供應的不同關係。也不能因編號為 1、2、3，就暗示整個供應系統要等第二步結束才開始。

### 案例 7：先講完整條路，讀到後面才知道分岔條件

**歷史原文（S07）**：第 17 行先說「後續反應依是否需要 T cell 幫助而不同」，接著完整展開 T-dependent 的呈現、辨認、共刺激與增殖；直到後面的 T-independent 分支才說：

> 這些非蛋白質成分無法製成 peptide–MHC II，可藉反覆結合多個 BCR、病原相關刺激等方式引發抗體反應。

**失敗點**：原文並非完全沒有分類或因果，而是造成分岔的條件太晚出現。讀者先背一條路，再回頭補上「內吞物是否能產生 peptide」。這也可能使讀者不容易沿用這個條件，推想日後接上 carrier protein 為何改變反應。

**現行稿的安排（S08，第二節）：**

- **含蛋白質（T-dependent）**：可分解出 peptide，與 MHC II 結合後供 helper T cell 辨認。
- **只有 LPS、單純莢膜多醣（T-independent）**：無法從這些成分產生所需 peptide；再說明如何取得額外刺激，以及抗體反應的特徵。
- **多醣接上 carrier protein**：在同一條件下解釋，因同次內吞已有蛋白質，便有機會取得 T cell 幫助。

**不要矯枉過正**：不是每篇都先列全部分類。應在條件開始改變下一步的位置分岔；分類名與條件一起出現，不要只留下分類名稱。

### 案例 8：SHM 逐步解釋很多，反而把需要記住的因果拆散

**使用者明確指出冗長的保存版（S09，第 63–69 行；節錄時省略突變後的英文名稱）：**

> 1. 突變：增殖中的 B cell，其 variable region DNA 產生突變，新製造的 BCR 與抗原結合可能更強或更弱。
> 2. 取得、呈現抗原：B cell 用變化後的 BCR 結合、內吞抗原，再以 peptide–MHC II 呈現給 Tfh。
> 3. 篩選：較能取得、呈現抗原者，較容易得到 Tfh 的存活、增殖訊號；幫助足夠者繼續反應，不足者可凋亡。
> 4. 再次突變與篩選：部分存活細胞再增殖、突變，回到取得抗原、呈現與篩選的過程。新的突變可能改變結合能力，上一次通過，不保證下一次也能通過。

原文後面另列「累積結果」與「與發育時的差別」。

**失敗點**：不是每句看不懂，而是同一段選擇機制分散在不同項目，再用「上一次通過，不保證下一次也能通過」回頭強調突變不一定有利。讀者需要記住的「突變造成差異／差異影響篩選／反覆篩選改變群體」被更多位置分散。

**依現行稿整理的較好對照（S08，第三節；排版正規化）：**

1. 增殖時，**variable region DNA 突變**，使新 BCR 的結合力變強或變弱。
2. B cell 用新 BCR 抓取、內吞抗原，再以 peptide–MHC II 呈現給 Tfh。**BCR 結合力較強，通常能抓到、呈現更多抗原，因此較容易得到 Tfh 幫助而存活、增殖。** 幫助不足的 B cell 則可凋亡。
3. 部分存活細胞重複上述過程，使群體的 **affinity** 逐漸提高，稱 **affinity maturation**。

**不要矯枉過正**：不能簡化成「SHM → affinity maturation」，也不能寫成突變一定使結合力提高。較好的第二項仍然是完整白話句子；它的長度來自同一個需要接通的因果。新版較好不因三項少於四項，而因各項對應不同且必要的理解任務。若讀者正在混淆發育期重組與 SHM，兩者比較仍有用；放在解決該問題的位置，不必每講 SHM 都附上。

### 案例 9：一段機制本身寫得好，放錯位置仍會打斷主線

**歷史情況（S10，第 32–40 行）**：標題在問「B cell 如何取得相應 T cell 的幫助」，緊接著卻詳細解釋 invariant chain 在 ER 占槽、運送到 endosome／lysosome、留下 CLIP，再由 HLA-DM 促使 CLIP 脫離。

**失敗點**：這些步驟本身有因果，並非壞知識。但讀者尚未知道呈現之後怎麼取得幫助，就必須先轉去完成「MHC II 如何載入」的另一個問題。回到主線時，還得想起原本在等哪個答案。

### 案例 10：CD4 表格與 CD8 散文分開，讀者必須自行拼回比較

**歷史排列（S17）**：先用表格介紹 CD4 與亞群，接著插入 B cell 互動，最後另以散文介紹 CD8，例如：

> TCR 辨認目標的 peptide–MHC I，CD8 與 MHC I 結合 → 釋放含 perforin、granzyme B 的預製顆粒。

### 案例 12：共同條件已知，只給結果太短，補回整套受體細節又太長

**真實精簡稿（S19）**：先說「NK 不靠這種抗原辨認」，接著直接給出：

> MHC I↓：CD8 較難辨認，NK 較易殺傷。

> MHC I → NK 抑制性受體 → 抑制殺傷

以及 MHC I 減少後抑制減弱、活化強於抑制才殺傷的描述。

### 案例 13：同一個「辨認」沒說主角，前後便像互相矛盾

**歷史問題（S13；逐節檢查亦有記錄）**：Type I IFN 被描述為提高 MHC、使感染細胞較容易被辨認；接著又說 MHC I 抑制 NK。未交代辨認者時，讀者自然會問「那 MHC I 增加到底是促進還是抑制清除？」

**現行稿（S14）將作用對象分開：**

1. **增加目標細胞的 MHC I**：幫助 CD8 T cell 辨認呈現的抗原。
2. **對 NK 本身的作用**：Type I IFN 也能增強 NK 活性。
3. **NK 接觸目標的當下**：目標上的 MHC I 可提供抑制訊號，需與活化訊號合併判斷。

**失敗點**：原本省掉的是主詞、作用位置與受作用對象，不是排版空間。只分成三個 bullet，若仍不說清對象，矛盾不會消失。

**不要矯枉過正**：這種澄清涉及醫學內容，必須由本次核准 reference 支持。S14 曾使用的補充依據不自動成為本任務 reference；若本次 reference 未交代，就標具體待補，不能為了讓故事順自行新增機制。

### 案例 14：辨認與殺傷沒有接通，容易被記成不同殺法

**歷史排列（S13）**：在「如何使目標細胞死亡」下，先講 perforin／granzymes，再另段寫「它也可利用抗體辨認目標」，接 ADCC 與圖。

**不要矯枉過正**：不要刪掉 ADCC 名稱或圖，也不要宣稱所有辨認方式、所有細胞都只有這一種殺傷機制。比較的範圍與條件要跟著來源。

### 案例 15：總目的已經寫了，具體作用仍應在配方之前建立

**歷史稿（S21）**開頭已說補體幫助吞噬、發炎、破膜，也已定義 C3 convertase 能切 C3；接著先列三條路徑，立刻進入 C1r、C1s、C4、C2、C4b2b，以及 B、D、Bb、properdin。C3a／C3b 的具體作用在下一節才展開。

**失敗點**：不能把它批評成「完全沒有目的」。它有總目的，但讀者還沒理解共同片段具體做什麼，就先追蹤多套配方。於是先背字母，再事後補意義。

**現行稿的處理（S23）**：先解釋 C3 convertase 的動作，並列 C3a／C3b 的去向與作用，再看 C3b 如何放大反應、如何接到 C5，之後才問「不同刺激如何組成最初的 C3 convertase？」這時入口表在回答一個讀者已經理解的重要問題。

**不要矯枉過正**：這是適合這批讀者的安排，不是「一律從路徑中間寫起」。讀者若已了解共同作用，入口先行也可能合適。三路比較表仍有價值，不能刪掉。

### 案例 16：說「放大」還不夠，要讓讀者看出什麼增加了、如何再回到前一步

**歷史原文（S21，第 25 行）**把 C3b 的去向寫成：

> 留在目標表面當標記、經替代路徑製造更多 C3b、加入 C3 convertase 使它成為 C5 convertase。

**失敗點**：相關配方雖出現在前表，讀者仍得自行拼出「產物 C3b 增加了切割者，新增切割者再產生更多 C3b」。背得出 alternative 會放大，不等於理解它如何放大。

**現行稿（S23）的關鍵連接**：

> 新形成的 C3 convertase 再切開更多 C3，產生更多 C3b；這些 C3b 又能參與組成新的複合體，回到同一步。

此前先交代 C3b 結合 factor B、factor D 切 B 留下 Bb，形成 C3bBb。另一分支再說原有 convertase 加入 C3b，成為能切 C5 的複合體。

**不要矯枉過正**：不要寫成 C3b 自己增殖，也不要把它直接畫成 C5 convertase。後文「不管最初由哪條路徑產生的 C3b 都能進入回圈」是在增加一個新關係；圖說提示回圈方向也有新用途，不能視為同字重複便刪掉。

### 案例 17：表格本來好用，表後補充卻變成沒有歸屬的尾巴

**歷史情況（S15，補體第三節）**：路徑表已有固定欄位，後面卻依序追加 alternative 起始、跨路徑放大、classical 與抗體、路徑圖、C2 命名、properdin／factor D、C4a。

**失敗點**：讀者看完表格後不斷切換路徑與問題。C4a 的片段作用也不屬於這張入口圖的註解；只因為都是補體資訊，便被排在一起。

**較好的安排（完整前後文見示範 B）**：

- 路徑表保留，用同一欄比較誰辨認什麼、怎樣形成 convertase。
- 共同 convertase 的命名放在 classical／lectin 對應處。
- Alternative 下分啟動、放大、factor D／properdin 分工。
- 路徑圖提供整合視角；C4a 移回片段作用的比較。

**不要矯枉過正**：不是把這串補充各加一個圓點，也不是把整張表拆回段落。補充有歸屬後，仍可以保留完整句子與讀圖說明。

### 案例 18：為了讓流程順，誤把並行、供應或共同入口寫成先後

**歷史材料中已有效的提醒（S08）**：

> 不同 B cell 不必依照下列順序完成，也不必經歷全部過程。

**教學反例：**

> B cell 先完成 class switching，再進行 SHM，最後才能成為 plasma cell。

**失敗點**：把排列順序誤當生物學必要順序，讓讀者得到好背但錯誤的模型。同樣地，先天免疫的局部清除與 DC 啟動 T cell 可並行；NK 分泌 IFN-γ 也不必等殺傷完成。

**較好的處理**：保留方便定位的編號，但在章節入口或相關分支說清並行、不同細胞去向與非必要步驟。對補體也要分清「alternative 的最初啟動」與「不同來源 C3b 都可參與的放大」。

**不要矯枉過正**：不必每項都加一大段「不是先後」的警語。只要在足以避免誤讀的位置交代清楚。不能因存在並行，就完全放棄有組織的閱讀順序。

### 案例 19：一份正本被誤解成「把眼前需要的原因都移走」

**教學反例，依此次去重時必須處理的風險設計：**

> Dendritic cell 活化 T cell。詳見 T cell。

或把原本的共同機制刪掉，只留一個沒有解釋、讀者也未必會打開的引用。

**失敗點**：避免重複的代價變成讀者當場接不上。正本歸屬與閱讀時能否取得必要解釋，是兩個都要滿足的要求。

**較好的處理**：

- 在本次新增檔案之間，可建立「抗原呈現與 T cell 活化」這類有完整意義的共用塊，讓新稿各有主線。若內容已住在既有檔案，只能依 reference 界線唯讀引用，不能去抽走或改寫原檔。
- 父頁仍交代當下的功能定位，例如 DC 把局部抗原帶到引流 lymph node、啟動 naive T cell。
- 若共用機制是接下一步所必需，就讓該閱讀位置能取得足夠內容；若只是深入載入細節，則一般引用即可。
- 同一分子在來源表、功能比較、圖說與新用途再出現，不自動等於重複正本。

**不要矯枉過正**：不要為「當場看懂」而每頁複製整套機制，也不要強制展開使用者後來刻意收合的所有引用。尤其不能設計系統不支援的局部嵌入。

### 案例 20：圖已插入，仍可能沒有幫助理解

**真實經驗**：使用者指出補體 pathway 等關鍵位置缺圖。後續補上共同反應圖與 First Aid 入口圖；逐節檢查判定兩張圖各有用途，不應因「都有 C3b」便刪一張。

**常見失敗與修正**：

- **只貼整張路徑圖**：讀者不知道先看哪裡。圖說指出入口、匯合、分支與回圈。
- **文字與圖的命名不同，未說明**：依相應路徑解釋 C4b2b／C4b2a 的命名，不讓讀者另背成兩套複合體。
- **圖中措辭可能誤導，照圖抄成機制**：例如 properdin／factor D，須在核准 reference 內核對分工；仍無法確認就標待補，不能依記憶或新增外部 reference 勘誤。
- **LPS／TLR4 圖擺在所有 PRR 下，未說範圍**：明說是特定例子；不能暗示所有 PRR 都在細胞表面、走相同訊號。
- **縮圖看起來漂亮，字卻讀不到**：實際以閱讀大小檢查，不能只確認檔案存在。

**不要矯枉過正**：機制有文字，不代表圖就是冗餘；加圖也不代表文字可以省到只剩箭頭。文字與圖可各自補上因果與位置。

### 案例 21：來源列了很多頁，不能證明內容已完整；重排漂亮，也可能默默漏知識

**此次修訂的真實檢查結果（S16）**：反向核對後曾補回 MHC 的身分、T cell 的分化、C1q 與 C3 的感染描述，並調整 scar 的歸屬。

這些遺漏不能只靠搜尋「MHC」「C1」「scar」發現：名詞可能還在，但定義、特定成分或條件已不見。

**教學反例：**

> 已搜尋所有 cytokine 名稱，來源區列出相關頁碼，因此已完整涵蓋 First Aid。

**失敗點**：它核對的是字出現過，沒有核對關係是否仍成立。比如只保留「活化、增殖」不等於保留「增殖、分化」；把 scar 只掛在慢性分支下，也改變了讀者理解的範圍。

**較好的驗收**：每個相關知識點標出來源、去向及狀態，搬移後反查定義、條件、例外、作用對象。比較表、圖片與來源說明各自都要查。醫學關係不能只靠字數、關鍵字或檔案數量驗收。

**不要矯枉過正**：記錄「所有相關資訊」不等於把全書各章全文搬入免疫學。按目標範圍建立去向，超出者說明理由；來源去向表放工作紀錄，不塞進讀者正文。

### 案例 22：明確規則被機械套用，或只修一個範例就宣布完成

**對話中的真實修正**：

- 使用者已說「本次免疫學相關筆記」刪摘要，不能再按通用摘要規則補回。
- 使用者已說「模組篇幅不是問題，之後解決」，不能把超過 1500 字列為本輪待修缺陷。
- 使用者指出先天第一節的大段落後，又明說「不是只有第一節，每個章節都有問題」，因此不能只修一節或一段 MHC 比較。

**失敗點**：形式上遵守某條規則，卻沒有處理這次真正要解決的閱讀問題。標題沒有「摘要」也不代表沒有重複總結；有一段好範例也不代表整篇已完成。

**較好的驗收**：對本次新稿每一節、每個新模組列出具體問題、已知內容、寫作關係與實際畫面結果。歷史上曾做摘要搬移與刪除；本次不能據此改動既有檔案。不要為了讓成品過關而修改使用者的寫作規則。

**不要矯枉過正**：不需要把所有引言、圖說、必要回扣一律刪除。它們若建立起始狀態、交代閱讀用途或接回機制，就不是無效重述。

### 案例 23：新增一篇筆記，卻把任務擴成重整既有筆記

**本次 inflammation 試寫的真實失敗（S24）**：新增主文之外，agent 重組了既有 `Granuloma (innate immunity).md` 的分類、搬動舊條目、換成新模組嵌入，也修改先天免疫、Hypersensitivity、Keloid 等既有筆記。

**導致失敗的舊 Prompt 指令**：它要求抽共用模組，並宣告「先備份，再完成目標與必要關聯模組的修改」。因此錯誤不只是 agent 沒有多問一次，而是 Prompt 把新增任務擴大成了既有筆記重整。

**正確做法**：新稿與必要新模組寫在新檔；舊 Granuloma 只讀取。已有分類或機制需要重新整理，記在工作紀錄；新稿依核准 reference 寫作，不能為統一分類去改原檔。目錄若有使用者明示的單項修改要求，只做該項，不能類推至其他既有頁面。

**驗收**：核對執行前後的既有檔案內容；未列為使用者明示例外的檔案必須零變動。備份完整、醫學說明更好或引用更方便，都不能替代這個要求。

### 案例 24：為了補通機制而加入外部資料，即使有 citation 仍超出 reference

**本次試寫的真實失敗（S24）**：作者用 Nature 研究補 inflammasome 中間步驟，用其他論文及 NCBI Bookshelf 補 granuloma 的限制與分類，又用原始研究更正既有影像徵象。來源有列出，但它們不在使用者指定的 First Aid reference 內。

**導致失敗的舊 Prompt 指令**：它允許為接通理解查閱研究、教材、官方資料或指南。這將「寫得好懂」誤當成自行擴大資料來源的授權。

**正確做法，依血液腫瘤範例（S25）**：reference 已寫的事繼續用白話講清楚；欠缺的中間關係在所屬位置標 `（待補 by codex：reference 尚未交代的步驟）`。例如已知起點與結果，就保留兩者；不能把自己的機制答案填進中間，也不能暗示原書已完整交代因果。

**驗收**：問每項內容「是否由核准 reference 支持」，而不只問「有沒有來源」。待補標記需要指出缺口；不可先保留外部資料的答案再附待補，也不可只刪外部網址，留下同一段新增內容。

### 把示範中的判斷搬到新主題

不要直接複製這兩節的四個主項或固定欄位。開始新主題時，先寫在工作紀錄：

| 當下在回答的問題 | 現有文字讓讀者卡在哪裡 | 需要保留或補上的關係 | 適合的呈現 | 如何知道已改好 |
|---|---|---|---|---|
| 例：這個細胞怎樣辨認目標？ | 只列受體全名，不知道誰在目標、誰在細胞 | 辨認者、被辨認物、位置、訊號結果 | 具體例子配角色表或圖 | 讀者能指出各角色與接下來的改變 |
| 例：同類細胞有何不同？ | 每種各寫一大段，對應資訊難找 | 各自接收訊號、作用對象與輸出 | 固定欄位比較 | 同一欄真的回答同一問題 |
| 例：這個循環為何反覆？ | 只說放大，或逐輪重講全部流程 | 回到哪一步、使用什麼材料、重複有何結果 | 步驟加明確回圈與必要圖 | 能說出下一輪如何接回，且不誤以為產物自行複製 |

這是工作時的判斷工具，不是每篇醫學筆記都要加的表格。**寫作能力要複製的是這種判斷，再依主題做選擇；不是固定排版。**

## 十二、實際工作順序

1. **固定檔案與 reference 範圍。** 依第零、一節記錄核准來源、閱讀範圍、允許新增的位置及當次明示的既有檔案例外。確認新檔路徑尚不存在；保存工作區既有相關檔案的清單與內容校驗值，涵蓋未提交內容，不只依賴 Git 差異。所有子 agent 都須收到相同授權界線與任務相關規則；負責規劃、編寫或改寫正文者，還須讀完整寫作原則與案例。只做轉檔、清點或來源核對者讀相關要求即可，不以分工擴大權限。
2. **唯讀閱讀規則、示範、現況與必要引用。** 記下有效結構與具體閱讀缺口。閱讀權限不等於修改權限；未授權的既有檔案問題只作工作紀錄。
3. **依實際格式讀完 reference 的指定範圍，建立內容去向表。** 在核准來源集合中查跨章、跨檔內容，多版本分別比較。將已有支持、未能讀取的部分及 knowledge gap 分開記錄，不用 reference 外答案填空。
4. **規劃主線與模組。** 判斷先後、並行、條件、回饋或獨立比較，再選編號、子項、段落或表格。不能為共用而搬走舊內容或改其父頁。若當次使用者明示允許修改特定既有檔案，先備份其當前內容，再只執行指定改動；不拿舊版本覆蓋使用者同期文字。
5. **完成全部相關章節。** 在 reference 範圍內整理關係、白話句子、比較、圖片與引用；沒有依據的必要連接就標待補。不要只改善開頭，也不要改寫使用者規則來遷就成品。允許修改的既有內容以局部改善為原則，保留原本已有效的語句與比較。
6. **逐項核對來源與去向。** 確認相關定義、動作、對象、條件、例外、數值與圖都有位置；新模組展開後仍接得上主文。不能只比字數或關鍵字，也不能只看「已涵蓋」的標籤。
7. **檢查實際閱讀畫面。** 逐頁看標題、粗體、縮排、表格、圖片及展開後的銜接。需要生成索引、修改目錄或操作會回寫檔案的介面時，在獨立預覽副本中驗證；未獲明示授權的正式檔案保持不動，必要入口另記交付紀錄。在這套 notes 檢視器，部分展開操作會回寫檔案，不能把所有點擊都視為唯讀。其他環境先了解其實際行為。
8. **以讀者身分逐節讀成品。** 依第十一節的方法提出讀者問題與假設性錯改，指出成品哪句、哪列或哪個已核對的展開內容支持答案；reference 的依據另作來源驗收。來源有答案不等於筆記已教清楚，不能只靠自己的背景知識答題。檢查陌生縮寫是否先於解釋出現、同欄是否混入不同分類層級、多方作用是否有清楚歸屬。把本次範圍內可解決的閱讀問題處理完再交付；reference 本身沒有答案的缺口保留待補。
9. **檢查改檔界線。** 比對開始前的既有檔案清單與內容；除明示例外外應保持零變動，包括被引用頁、摘要、圖片及正式索引。發現同期變動時先保留現況並判明來源，只撤回可確定屬自己的越界改動，不能覆蓋使用者或其他 agent 的修改。不明來源的差異如實列出，不能冒稱零變動，也不能拿備份存在當作通過。

在上述範圍內自主完成工作，不反覆要求常規編寫確認；knowledge gap 按指定格式交付，不必每遇缺口都停下問人。超出範圍的既有檔案重整、增加 reference、提交、推送與發布不執行；使用者當次已明確要求的行動則依其指定範圍完成。

工作紀錄保留足以追溯的依據，避免同一份內容重複產生多套龐大報告。來源、閱讀、畫面與改檔檢查各有目的；已通過的檢查，只在新改動、發現問題或仍有疑點時重做相關部分。不要把反覆跑相同檢查當成持續進步。

## 十三、完成前的讀者驗收

以下檢查新稿每一節、新模組及實際引用的內容，不能只用一段成功範例代表整篇；驗收發現未授權既有檔案的問題只能記錄，不能擴大成修改：

- **讀得懂**：知道前面的內容，能否理解後面為何發生？誰作用於誰、在哪裡、條件是什麼，是否清楚？
- **記得住**：忘記一個結果時，能否從文中的機制、條件或比較把它想回來？不能推導的名稱與獨立事實，是否有穩定分組？
- **找得到**：快速掃過編號與粗體，能否辨認目前的位置，並找到細節的歸屬？
- **關係正確**：沒有把並行寫成先後、相關寫成因果、調控方式寫成結局，或把另一用途接成下一步？
- **比較有效**：表格同欄是否真的回答同一問題？重要可比較內容有沒有被拆散？
- **必要解釋有據可查**：reference 已有的關係是否講清楚，而非只剩縮寫、箭頭與「促進／抑制」？reference 沒交代的關係是否標待補，而非自行補出？也沒有逐輪重講已理解的循環？
- **資料有去向且未越界**：核准 reference 的相關文字、表格、例外與圖是否已核對？每項新增事實是否在核准 reference 內？有外部 citation 不能代替這項條件，引用與圖說也不能夾帶。
- **待補清楚**：缺口是否放在所屬位置，使用 `（待補 by {執行者}：具體缺項）` 並填入實際執行者名稱，必要時寫明缺哪個關係？沒有先填入未核准答案再標待補？
- **既有檔案受到保留**：除使用者當次明示的特定例外外，執行前後既有檔案是否零變動？新稿的引用、去重、圖片與預覽流程沒有暗中修改舊檔？
- **共用不斷線**：同一完整機制是否有正本？讀者是否仍能在需要的位置理解它？
- **語言一致**：符合本次語言與術語設定；預設繁體中文、英文醫學術語前後一致，動作與因果保持白話。必要全名須有核准 reference 支持，不憑記憶展開縮寫；名詞有身分與作用，不另造一套難記的譯名。其他領域採該領域與讀者適用的詞彙。
- **畫面成立**：表格、圖、引用及縮排在實際檢視器中正確；沒有用語法正確冒充閱讀清楚。
- **正文只保留有助學習的內容**：摘要符合本次設定；沒有空泛包裝、修稿自辯，或「這裡已在前面說過」卻不提供有效定位的填充句。

驗收紀錄分開寫明：檔案範圍與既有內容保留、核准 reference 涵蓋與待補、理解與記憶、實際畫面。這些驗收不能互相代替。已知內容的閱讀斷點要修；reference 本身的缺口則明確留待補，可以交付。不能為消除待補而增加未核准的知識內容，也不能用讀起來更順抵銷越界改檔。

交付時簡潔列出：完成的筆記、實際做過的來源與畫面核對、既有檔案保留的實際結果、仍待補或未能讀取的具體項目。若有使用者明示例外，另列該檔的指定改動與備份。將內容去向與工作紀錄另存，讓使用者追溯；不要聲稱未做過的檢查，也不要把 reference 外新增當作「完整性提升」。若使用者在測試 prompt 或 agent 能力，另如實區分獨立初稿與經其他 agent 評讀修正後的成果，不把協作完成冒稱為單次獨立完成。
