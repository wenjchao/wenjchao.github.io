# Dyspnea & 呼吸器設定

## 內文
- 注意：Respiratory failure:

  Type 1: 缺氧氣 (hypoxemia)

  Type 2: 二氧化碳太多 (hypercapnia) ⇒

  1. Won’t breathe: 藥物或疾病等造成 CNS depression，無法呼吸
  2. Can’t breathe: 神經學上正常，想呼吸，但其他原因 (ex: obstruction、脊柱側彎) 造成換氣困難

  Type 4: shock ⇒ 組織 perfusion 不夠，供氧不足
