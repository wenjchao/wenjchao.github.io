# Etiology: 要分系統(肺/心/酸/精神) & 是哪個 Type

## 內文
- 注意：如果不會喘但是 O2 掉：可能CNS壞掉了 ex: hyperammonemia, stroke

### lung & airway:

1. 肺內: pulmonary edema, fibrosis, **<u>pneumonia</u>**(bacterial, viral, tuberculosis, atypical, fungal)
2. 出現奇怪的東西: pneumothorax, hemothorax, pleural effusion, pleuritis, lung tumor
3. Airway: **<u>COPD</u>**(not COPD if no smoking), asthma, croup, **<u>bronchiolitis</u>**, airway tumor, foreign body
4. Vascular: pulmonary hypertension, **<u>pulmonary embolism</u>**
5. Neuro: MG, myopathy, neuropathy(ex: GBS)

### left heart:

1. **<u>heart failure</u>**
2. **<u>AMI, ischemia</u>**
3. arrthymia
4. cardiomyopathy, pericarditis
5. cardiac tempondae (Onco/外科病人), pericardial effusion

### metabolic acidosis:

1. lactate acidosis: sepsis, ischemia,
2. ketoacidosis: DKA, alcohol
3. renal cause: renal failure, RTA
4. drug / toxic

### others:

1. **<u>hyperventilation</u>** / anxiety
2. **<u>anemia</u>**
