# Diagnostic test

## 內文
1. Lab: ABG, CBC, Troponin, Lactic acid
2. EKG
3. Chest X-ray:
   1. Lung marking ⇒ PPH
   2. <u>Pneumonia (gold standard)</u>
   3. Abcesses: Caviting ⇒ K.P./ TB(apical lobe) / Staphylococcus(藥品注射) / Infective endocarditis(會有Lung abscess)
   4. Pneumothorax
   5. big bleb/bullae ⇒ Emphysema
   6. 懷疑氣道阻塞 ⇒ neck X-ray
4. echo: cardiac temponade, b-line, pleural effusion, pneumothorax
