# 抗體五類

## 內文
各類 Ig 都能以 **monomer** 存在；IgM、IgA 分泌時可形成多聚體。
heavy-chain constant region 決定作用與分布；作用不足或傷害自身細胞，可造成相應疾病。

| Ig 類別 | 形式／分布 | 何時產生／哪些訊號促進 | 作用與相關疾病 |
|---|---|---|---|
| **IgM** | B cell 表面 monomer；分泌為 **pentamer＋J chain** | 初次反應 **最先產生** | 表面抗原受體；pentamer 的多個位點提高 avidity；Fc 可活化補體<br>**Cold AIHA**：低溫下，致病自體抗體以 **IgM** 為主 → 紅血球凝集、補體作用 → 血管內／外溶血，見 [[Autoimmune hemolytic anemia\|AIHA]]<br>**Hyper-IgM**：CD40L 缺陷 → IgM 正常或↑，IgG／IgA／IgE↓ |
| **IgG** | Monomer；**血清最多** | Th1 **IFN-γ**<br>Th2 **IL-4**（部分 IgG） | 再次反應主要抗體；活化補體、opsonization、中和毒素／病毒<br>**唯一可過胎盤** → 嬰兒取得現成抗體；出生後母體抗體逐漸下降，被動保護也減弱<br>**Warm AIHA**：致病自體抗體以 IgG 為主，紅血球被 macrophage 清除 → 以 **血管外溶血** 為主，見 [[Autoimmune hemolytic anemia\|AIHA]] |
| **IgA** | 血中 monomer；分泌為 **dimer＋J chain**<br>淚液、唾液、黏液、母乳；**總產量最多** | **TGF-β：促進 IgA 切換**<br>Th2 **IL-5：支持 B cell 分化、後續 IgA 產生** | **Plasma cell 分泌 IgA**；GI tract（如 Peyer patches）參與黏膜 IgA 反應<br>IgA 經 **transcytosis 穿過上皮**，取得 **secretory component** 保護 Fc，減少被腔內 proteases 分解<br>分泌的 IgA **阻止病原黏附黏膜**；不活化補體<br>**IgA 不足** → 黏膜保護減弱 → 可有 GI／呼吸道感染，尤其 **Giardia 腸道感染**，見 [[Congenital Immunodeficiency\|IgA deficiency]]<br>IgA 類 celiac 血清學檢驗：可測到的 IgA 不足 → 可能偽陰性<br>血品中的 IgA 可引發 anaphylaxis（致敏條件與機制待補） |
| **IgE** | Monomer | Th2 分泌 **IL-4** → 促進 B cell 切換為 **IgE**<br>**IL-13** 支持 IgE 產生 | IgE 先結合 mast cell／basophil；相應 allergen 再使表面 IgE **cross-link** → 釋放 histamine 等 → [[Hypersensitivity 四型\|Type I 過敏]]<br>活化 eosinophil，參與抗寄生蟲反應（細胞接觸機制待補）<br>[[Congenital Immunodeficiency\|Job syndrome]]：IgE↑（與其缺陷的完整因果待補） |
| **IgD** | Monomer；成熟 naïve B cell 表面；血清量低 | 與 IgM 同時表現 | 表面抗原受體；相關疾病待補 |

表中的 Th1／Th2–Ig 對照沿用 First Aid，實際效應亦依細胞環境、Ig 亞類而異。
