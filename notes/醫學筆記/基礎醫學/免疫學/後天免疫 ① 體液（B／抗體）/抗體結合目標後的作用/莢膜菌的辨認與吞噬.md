# 莢膜菌的辨認與吞噬

## 內文
吞噬需要表面受體接觸目標，並接收推動包覆、內吞的訊號。
**莢膜位於菌體外側，多由多醣構成**，可遮住原本能被免疫分子辨認的表面結構。某些莢膜還會減少 IgG 結合、C3b 沉積 → 吞噬細胞較難透過相應受體接觸細菌。[莢膜作用的研究](https://pubmed.ncbi.nlm.nih.gov/19948837/)

**IgG 的 Fab 結合外露抗原**（例如莢膜抗原）後，Fc 可被吞噬細胞的 **活化型 Fcγ receptor** 辨認。
多個受體結合細菌表面的 IgG、聚集 → 傳入訊號 → 細胞膜包覆細菌，形成 **phagosome**。[Fc 受體與吞噬](https://www.ncbi.nlm.nih.gov/books/NBK27171/)

**IgM／IgG 可活化補體 → C3b 沉積於細菌表面**。吞噬細胞的 **CR1** 結合 C3b，使細菌附著；仍需細胞活化訊號，例如 **C5a 結合 C5a receptor**，才能有效吞噬。[補體受體與活化條件](https://www.ncbi.nlm.nih.gov/books/NBK27100/)

抗體不足 → 較少透過 IgG–FcγR 或抗體啟動的補體作用被辨認 → 吞噬清除減弱，**莢膜菌感染風險上升**。
莢膜種類不同，影響分子接觸、補體沉積與吞噬的方式也不同，細節待補。
脾功能下降 → **IgM↓ → 補體活化↓ → C3b 調理作用↓** → 莢膜菌感染風險上升。
