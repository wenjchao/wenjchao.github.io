# 主動／被動免疫與疫苗應用

## 內文
### 自己建立反應，或直接取得抗體

| | 主動免疫 | 被動免疫 |
|---|---|---|
| 如何取得保護 | 接觸抗原 → 自己活化免疫細胞、製造抗體並建立記憶 | 直接取得已製造好的抗體 |
| 為何起效速度不同 | 建立反應需要時間 → 起效較慢 | 抗體已可作用 → 起效快 |
| 為何持續時間不同 | 有免疫記憶 → 可維持較久，再次遇到抗原時反應較快 | 現成抗體逐漸被清除 → 保護消退；IgG 半衰期約 **3 週** |
| 例子 | 自然感染、疫苗、toxoid | 母體 IgG、母乳 IgA、antitoxin、人源化單株抗體、IVIG（intravenous immunoglobulin） |

HBV 或 rabies 暴露後，可合併現成抗體提供的即時保護，以及主動免疫建立的後續保護。

### 疫苗抗原如何影響能否取得 T cell 幫助

- **Diphtheria toxoid** 是蛋白質抗原，可分解、呈現 peptide → 取得相應 helper T cell 的幫助，形成 **T-dependent 反應**。
- **PPSV23** 是單純多醣疫苗；多醣無法分解成 peptide、藉 MHC II 呈現 → 不能如此取得 T cell 幫助，屬 **T-independent 反應**，通常以 IgM 為主，class switching 與長期記憶較有限。
- **Conjugate vaccine** 將多醣接上 carrier protein → B cell 同次內吞蛋白質，得以呈現其 peptide、取得 T cell 幫助，形成 **T-dependent 反應**。

單純多醣等抗原免疫原性較弱；First Aid 另列追加劑（booster）與佐劑（adjuvant）作為增強疫苗反應的方法。
