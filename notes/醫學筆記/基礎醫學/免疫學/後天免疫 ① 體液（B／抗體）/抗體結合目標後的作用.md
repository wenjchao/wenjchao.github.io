# 抗體結合目標後的作用

## 內文
| 抗體造成的作用 | 從結合抗原到保護身體 |
|---|---|
| **Neutralization** | 抗體結合病原或毒素 → 阻止病原黏附細胞、毒素發揮作用<br>病毒可在進入細胞前被中和；抗體缺陷可見 enterovirus／poliovirus 感染，見 [[Immunocompromised\|B cell／抗體缺損]] |
| **Opsonization** | 抗體先結合病原，吞噬細胞再透過 Fc receptor 辨認 → 促進吞噬 |
| **活化補體** | IgM／IgG 的 Fc 啟動 [[Complement 補體系統]] → **C3b** 促進吞噬、**MAC（membrane attack complex）** 使病原溶解 |
| **ADCC**（antibody-dependent cell-mediated cytotoxicity） | IgG 包被目標後，可讓 NK cell 辨認並殺傷目標；**CD16 如何結合 IgG、引起殺傷**，見 [[IFN 與 NK 如何對抗病毒\|NK 的抗體辨認方式]] |
