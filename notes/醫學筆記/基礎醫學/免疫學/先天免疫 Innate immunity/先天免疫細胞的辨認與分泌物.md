# 先天免疫細胞的辨認與分泌物

## 內文

### 一、吞噬、呈現與殺傷細胞：外觀與角色分開比較

1. **用外觀辨認細胞**

   | 細胞 | 核形 | 大小／胞質與顆粒 |
   |---|---|---|
   | **Neutrophil** | 多葉核 | Specific granules、azurophilic granules；成分見 [[吞噬後如何殺菌]]。 |
   | **Monocyte** | 腎形核 | 大型細胞，胞質呈 frosted-glass 外觀。 |
   | **NK（natural killer）cell** | — | 比 B／T cell 大，胞質有 lytic granules。 |

2. **位置與主要角色**

   | 細胞 | 位置／移動 | 主要角色與機制 |
   |---|---|---|
   | **Neutrophil** | 急性發炎時由血中進入組織 | 重要的吞噬細胞；移出步驟見 [[白血球如何離開血管]]，殺菌工具見 [[吞噬後如何殺菌]]。 |
   | **Monocyte** | 位於血中，進入組織後可分化為 macrophage 或 dendritic cell | 對應分化後細胞的吞噬、抗原處理等作用。 |
   | **Macrophage** | 可長期存在組織 | 吞噬並調整局部反應；也可呈現抗原、參與 ADCC（antibody-dependent cell-mediated cytotoxicity）。 |
   | **Dendritic cell** | 可由組織移向引流淋巴結 | 具有高吞噬能力的 APC（antigen-presenting cell），把抗原訊號提供給 T cell；完整步驟見 [[抗原呈現與 T cell 活化]]。 |
   | **NK cell** | — | 以感染或腫瘤細胞為殺傷目標，使用 lytic granules 中的 perforin／granzymes；辨認與殺傷見 [[IFN 與 NK 如何對抗病毒]]。 |

3. **表面分子對應哪些作用**

   | 細胞 | 表面分子 | 作用定位 |
   |---|---|---|
   | Macrophage | **CD14** | 協助辨認 LPS（lipopolysaccharide）；與 TLR4（Toll-like receptor 4）相關的訊號見 [[發炎訊號與局部、全身反應]]。 |
   | Macrophage | **Fc／C3b receptors** | 辨認包被在目標上的抗體或補體，見 [[吞噬後如何殺菌]]。 |
   | Macrophage | **MHC II（major histocompatibility complex class II）、B7** | 抗原呈現與共刺激，見 [[抗原呈現與 T cell 活化]]。 |
   | Macrophage | **CD40** | 接收 T cell 的接觸訊號，見下方 macrophage 的活化。 |
   | Macrophage | **CCR5（C-C chemokine receptor 5）** | 另一個表面受體；相關受體與應用見 [[後天免疫 ② 細胞（T）]]。 |
   | Dendritic cell | **MHC II、Fc receptors** | 抗原取得與呈現；也可作 cross-presentation，提供 CD8 T cell 的抗原訊號，見 [[抗原呈現與 T cell 活化]]。 |
   | NK cell | **CD16、CD56** | NK 的辨認標記；CD16 參與的抗體辨認見 [[IFN 與 NK 如何對抗病毒]]。 |

4. **Macrophage 在不同組織的名稱與作用**

   | 組織 | 名稱 |
   |---|---|
   | Liver | **Kupffer cell** |
   | Connective tissue | **Histiocyte** |
   | Brain | **Microglia** |
   | Bone | **Osteoclast** |
   | Lung | **Alveolar macrophage** |

   - **肺部清除**：alveolar macrophage 清除外來物與碎屑，也釋放 cytokines、proteases。
   - **持續反應中的形態**：macrophage 是 [[Granuloma (innate immunity)|granuloma]] 的重要成分，可融合成 giant cells。
   - **受到 T cell 訊號增強**：IFN-γ（interferon-γ）與 CD40L–CD40 參與增強已吞入病原的清除；作用關係見 [[後天免疫 ② 細胞（T）|Th1 與 macrophage 的互動]]。

### 二、Eosinophil、basophil 與 mast cell：分布、產物與啟動條件

1. **外觀與分布**

   | 細胞 | 核形／顆粒外觀 | 分布 |
   |---|---|---|
   | **Eosinophil** | 雙葉核；顆粒大型、大小均一且 eosinophilic | — |
   | **Basophil** | Granulocyte，顆粒高度 basophilic | 血中 |
   | **Mast cell** | — | 組織中；與 basophil 是不同細胞。 |

2. **分泌物與其他清除作用**

   | 細胞 | 分子／產物 | 作用或特性 |
   |---|---|---|
   | Eosinophil | **MBP（major basic protein）** | 傷害 helminths。 |
   | Eosinophil | Histaminase、eosinophil cationic protein、eosinophil-derived neurotoxin、IL-5（interleukin-5） | Eosinophil 的其他分泌物；IL-5 同時也是可作用於 eosinophil 的訊號，見下項。 |
   | Basophil | **Histamine、heparin** | 儲存在顆粒內，參與過敏反應。 |
   | Basophil | Leukotrienes | 需要時製造、釋放。 |
   | Mast cell | **Histamine、heparin、tryptase、eosinophil chemotactic factors** | Degranulation 時釋放的介質，參與局部反應。 |

   - **Eosinophil 也可吞噬 antigen–antibody complexes**；這與釋放 MBP 傷害 helminths 是不同的清除動作。

3. **哪些訊號啟動或增強細胞作用**

   - **Eosinophil：IL-5 促進生長、分化與活化。** IL-5 的來源與其他作用見 [[後天免疫 ② 細胞（T）|Th2 的 cytokines]]。
   - **Mast cell：不同刺激可匯入 degranulation。**
     1. **依賴 IgE**：表面受體先結合 IgE 的 Fc；抗原同時結合多個 IgE、形成 cross-linking 後，可引起 degranulation。IgE 相關反應見 [[Hypersensitivity 四型]]。
     2. **不依賴 IgE**：組織創傷、C3a／C5a，以及 vancomycin、opioids、radiocontrast 等刺激，也可引發 degranulation。臨床判讀與處置見 [[Anaphylaxis]]；不能把所有 mast cell 反應都當成已先經 IgE 致敏。
