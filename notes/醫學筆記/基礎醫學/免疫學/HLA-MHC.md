### 疾病關聯

| HLA | 疾病／情況 |
|---|---|
| HLA-DR2 | Goodpasture's、MS；SLE（原速查頁另列，待核對） |
| HLA-DR3 | Graves's、MG、SLE、PSC |
| HLA-DR4 | RA、PV |
| HLA-DR5 | Hashimoto's |
| HLA-B27 | [[Spondyloarthritis (oligoarthritis)\|Seronegative spondyloarthropathy]]（seronegative＝RF (−)）：AS、reactive arthritis、psoriatic arthritis、IBD-related arthritis；acute anterior uveitis |
| HLA-Cw6 | Psoriasis（與 HLA-B27 相比，關聯較大） |
| HLA-B51／HLA-B\*51 | [[Vasculitis\|Behcet]]（正文／原圖 1 的記法） |
| HLA-DRB1\*1301、DRB1\*1302 | 降低 ACPA-positive RA 機率 |
| HLA-DQA1\*0501 | Sjogren's syndrome |
| HLA-DRB1\*1101 | Sarcoidosis |

RA 的 HLA-DR4 細分（原圖 1）：

- DRB1\*0401：風險最高。
- 其他：\*0101、0404、1001、0901（沿用原圖記法）。
