# Post-streptococcal：ARF 與 PSGN

## 內文
同一 GAS（group A Streptococcus），感染部位不同 → 免疫反應不同 → 後果不同：

| | Acute rheumatic fever（ARF） | Post-streptococcal glomerulonephritis（PSGN） |
|---|---|---|
| 前驅感染 | 咽喉炎（acute pharyngotonsillitis），ASLO (+) | 皮膚感染，ASLO (−) |
| 免疫反應 | Type II | Type III（immune complex 沉積） |
| 後果 | 大部分變成 rheumatic heart disease（MR 居多） | （待補 by claude） |
| 抗生素 | 可以治 | 對病程無影響 |
