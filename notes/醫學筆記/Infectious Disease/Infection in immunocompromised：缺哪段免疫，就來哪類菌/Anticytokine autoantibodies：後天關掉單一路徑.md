# Anticytokine autoantibodies：後天關掉單一路徑

## 摘要
**成人沒 HIV、沒吃免疫抑制劑，卻反覆某類伺機性感染 → 想到自體抗體把一條 cytokine 路徑中和掉了。** 對應關係：

- **抗 IFN-γ** → 播散性 NTM（adult-onset immunodeficiency）
- **抗 IL-17／IL-22** → 慢性皮膚黏膜 candidiasis
- **抗 GM-CSF** → Cryptococcus、Nocardia、Aspergillus、PAP
- **抗 IFN-α／ω** → 重症 COVID-19

治療（實驗性）：拿掉抗體，或補回 cytokine。

## 內文
| 自體抗體 | 易感染 | 背景／機制 |
|---|---|---|
| Anti-IFN-γ | 胞內菌（intramacrophagic）：**播散性 NTM**（nontuberculous mycobacteria） | Adult-onset immunodeficiency；IL-12 → Th1 → IFN-γ → macrophage → [[Granuloma (innate immunity)]] 這條路被關掉 |
| Anti-IL-12／IL-23 | **Mycobacteria**、Coccidioides | 同一條路的上游；Thymic neoplasia、Good syndrome（thymoma with immunodeficiency） |
| Anti-IL-17／IL-22 | **Chronic mucocutaneous candidiasis** | APECED（autoimmune polyendocrinopathy-candidiasis-ectodermal dystrophy） |
| Anti-GM-CSF | **Cryptococcus**（播散、CNS）、Nocardia、Aspergillus；pulmonary alveolar proteinosis（PAP） | — |
| Anti-IFN-α／ω | **重症 COVID-19** | — |
| Anti-IL-6 | **Staphylococcus** | — |

治療（實驗性）：

1. 減少抗體：rituximab（CD20）、bortezomib、daratumumab（CD38）、cyclophosphamide、abatacept（CTLA-4）。
2. 補回 cytokine：rh-GM-CSF、rh-IFN-γ。

來源：台大感染科鄭醫師；[Anticytokine autoantibodies: Autoimmunity trespassing on antimicrobial immunity (JACI 2021)](https://www.sciencedirect.com/science/article/pii/S0091674921018005)
