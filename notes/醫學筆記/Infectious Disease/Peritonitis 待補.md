# Peritonitis 待補

## 內文

1. GPC: 45\~65% (Mostly Coagulase-negative staphylococci); GNB: 15\~35% ; Fungus: 5% ; Culture negative : 20\~25%
2. Risk factor for fungus infection: emergency peritoneal dialysis, HIV, extraperitoneal fungal infection
3. If multiple enteric organisms => suspect secondary peritonitis
4. Peritoneal fluid analysis: cell count and differential (WBC > 100), gram stain, culture
5. Treatment: Empiric antibiotics should be initiated as soon as possible
   - Intraperitoneal antibiotics > intravenous (except septic)
