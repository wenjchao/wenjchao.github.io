# CAR-T 後感染預防

## 內文
CAR-T（chimeric antigen receptor T cell）目前用於 DLBCL（diffuse large B-cell lymphoma）、B-ALL（B-cell acute lymphoblastic leukemia）、MM（multiple myeloma）。療程前情提要（→ [[醫學筆記/基礎醫學/免疫學/腫瘤免疫治療/CAR-T]]）：

1. 收之前：要收健康的細胞，所以收之前要停一陣子化療，也不能打 G-CSF（granulocyte colony-stimulating factor）（這樣收集的 T 細胞效果不好）。
2. 打進去之前：先化療（lymphodepletion）把細胞清一清，不然 CAR-T 細胞有可能被我們自己的免疫細胞攻擊。

### 三期換班

| | 期 1：急性毒性 | 期 2：延遲毒性 | 期 3：晚期 |
|---|---|---|---|
| 時間 | 輸注 → day 28 | day 28 → 90 | day 90 → 365 以後 |
| 免疫狀態 | neutropenia；CRS（cytokine release syndrome）、ICANS（immune effector cell–associated neurotoxicity）→ 用 steroid、tocilizumab（抗 IL-6）壓發炎 | 細胞與體液免疫都差 | CD19+ B cell 持續缺失、hypogammaglobulinemia |
| 細菌 | **bacteremia**、C. difficile 腸炎、肺炎（莢膜菌） | 肺炎（少） | 肺炎（莢膜菌、病毒）持續 |
| 病毒 | HSV／VZV、其他疱疹病毒、呼吸道病毒 | HSV／VZV、呼吸道病毒 | HSV／VZV、呼吸道病毒 |
| 黴菌 | **Candida**；day 14 起 Aspergillus 等 mold | mold（→ 約 day 60）、**PJP**（day 28 起） | PJP（→ day 180） |
| 預防 | levofloxacin、fluconazole／micafungin（輸注 → day 14）；acyclovir／valacyclovir（lymphodepletion 起） | acyclovir 持續；TMP-SMX（day 21–28 起） | acyclovir（→ day 365）；TMP-SMX（→ day 180） |

輸注前先做篩檢（文獻 Table 1）。CRS、ICANS 本身見 [[醫學筆記/基礎醫學/免疫學/腫瘤免疫治療/CAR-T/CRS & ICANS post CAR-T]]。
