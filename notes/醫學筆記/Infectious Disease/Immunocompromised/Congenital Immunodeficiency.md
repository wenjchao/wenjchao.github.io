# 先天性免疫缺陷與免疫失調

## 內文
### 吞噬細胞缺陷

| 疾病 | 缺陷 → 影響 | 臨床表現與治療 |
|---|---|---|
| Fanconi anemia、severe congenital neutropenia | 白血球太少 | **廣泛皮膚、腸道菌**：Staph、Strep、腸道 G(–) 桿菌<br>Candida、Aspergillus<br>治療：待補 |
| LAD1（leukocyte adhesion deficiency） | 無法到達感染處 | 皮膚黏膜反覆感染卻**無 pus**<br>新生兒臍帶晚脫落<br>治療：待補 |
| CGD（chronic granulomatous disease） | 無法製造活性氧 | **catalase(+) 菌**：S. aureus、Serratia、Burkholderia、Nocardia<br>Candida、Aspergillus<br>治療：IFN-γ、steroid、終身預防性抗生素／移植 |
| MPO（myeloperoxidase）deficiency | 過氧化酶缺乏 | 反覆 **Candida**：oral thrush、vulvovaginitis<br>通常很輕；治療待補 |
| Chédiak-Higashi syndrome | Lysosome-fusion defect → 無法消化吞入的病原 | **Pyogenic**：S. pyogenes、S. aureus、Pseudomonas<br>治療：待補 |

殺菌：製造活性氧 → 過氧化酶進一步加強殺菌力。
CGD 無法製造活性氧（**最嚴重**）；MPO 缺乏後段酵素（**通常很輕**）。

### T／B cell 的發育與協作缺陷

| 疾病 | 缺陷 → 影響 | 臨床表現與檢查 |
|---|---|---|
| **DiGeorge** | 22q11 microdeletion → thymic hypoplasia／aplasia → **T cell↓** | 反覆病毒／黴菌感染<br>低 PTH、低血鈣、胸腺影缺如 |
| **SCID**（severe combined immunodeficiency） | B、T cell 發育／增殖受損<br>IL-2R γ-chain 缺陷（最常見，X-linked）<br>Adenosine deaminase 缺陷（AR）<br>RAG mutation／V(D)J recombination 缺陷 | **T cell↓**<br>新生兒篩檢：**TREC**（T-cell receptor excision circle）↓ |
| **Bare lymphocyte syndrome**（AR） | 抗原呈現受損<br>Type I：TAP mutation → **MHC I↓ → CD8↓**<br>Type II：transcription factor mutation → **MHC II↓ → CD4↓** | Type II：呈現給 CD4 的訊號受損<br>其他臨床表現待補 |
| **IL-12 receptor deficiency**（AR） | **Th1／IFN-γ↓** | 播散性 mycobacterial、fungal infection；亦易感染 **Salmonella**<br>可在 BCG 疫苗後出現 |
| **Job syndrome**（AD） | STAT3 mutation → **Th17↓** → neutrophil 招募受損 | **Cold staphylococcal abscess**<br>IgE↑、eosinophil↑ |
| **Hyper-IgM syndrome** | 最常見為 **CD40L 缺陷**（X-linked）<br>T cell 對 B cell 的幫助受損 → class switching 受損 | **IgM 正常或↑；IgG／IgA／IgE↓** |
| **X-linked（Bruton）agammaglobulinemia** | **BTK（Bruton tyrosine kinase）缺陷** → B cell 無法成熟<br>X-linked recessive | **周邊血 B cell 缺如，所有 Ig 類別↓**<br>母體 IgG 下降 → 約 6 個月後反覆細菌、enterovirus 感染<br>淋巴結／扁桃腺缺如或很少，缺少初級濾泡與 germinal centers<br>活疫苗禁忌 |
| **Selective IgA deficiency** | 最常見的 primary immunodeficiency<br>可為家族性或散發；也可能繼發於病毒感染、藥物 | **IgA↓；IgG、IgM 正常**<br>多數無症狀；可有呼吸道／GI 感染，尤其 **Giardia**<br>可伴 celiac disease 等自體免疫疾病、atopy<br>血品中的 IgA 可引發 anaphylaxis<br>Celiac disease 血清學檢驗可能偽陰性；血清驗孕可能偽陽性 |
| **CVID（common variable immunodeficiency）** | B cell 分化受損，多數原因不明 | **Plasma cells↓、immunoglobulins↓**<br>可在兒童期出現，通常青春期後診斷<br>Sinopulmonary infections、bronchiectasis，以及自體免疫疾病、lymphoma 風險↑ |

IL-12 receptor 缺陷的後天對照：**anti-IFN-γ autoantibodies**（adult-onset）→ 播散性 NTM，見 [[Anticytokine autoantibodies：後天關掉單一路徑]]。

### 補體缺陷

| 疾病 | 缺陷 → 影響 | 易感染病原 |
|---|---|---|
| C3 缺損 | 機轉待補 | **[[莢膜菌]]** |
| Terminal complement（C5–9）缺損 | 機轉待補 | **Neisseria** |

### 免疫耐受失調

| 疾病 | 缺陷 → 影響 | 臨床表現 |
|---|---|---|
| Autoimmune polyendocrine syndrome | **AIRE 缺陷** → 胸腺 negative selection 受損<br>會攻擊自身組織的 T cell 未被充分清除 | **Chronic mucocutaneous candidiasis**<br>Hypoparathyroidism、adrenal insufficiency |
| **IPEX**（Immune dysregulation, Polyendocrinopathy, Enteropathy, X-linked） | **FOXP3（核內轉錄因子）缺陷** → Treg 無法有效抑制攻擊自身組織的 T cell<br>→ 這些 T cell 傷害腸道、內分泌器官等組織 | 腸道：enteropathy<br>內分泌：endocrinopathy，可見男嬰糖尿病<br>皮膚／指甲異常 |
