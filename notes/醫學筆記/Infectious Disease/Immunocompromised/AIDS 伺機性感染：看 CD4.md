# AIDS 伺機性感染：看 CD4

## 內文
### 依 CD4 分層（往下累加：低的層包含高的層）

| CD4 | 這一層開始出現 | 備註 |
|---|---|---|
| 任何 | 細菌性肺炎（CD4 越低越容易變 bacteremia）；TB；NHL（non-Hodgkin lymphoma） | 非感染的肺病（COPD、asthma、PAH、ILD 如 LIP、sarcoidosis）和 HIV 陰性者一樣會有 |
| > 200 | 主要還是 [[醫學筆記/Infectious Disease/TB]]、MRSA | TB 隨 CD4 變臉：> 500 reactivation TB → 約 200 primary TB → < 100 atypical TB |
| < 200 | **PJP**（Pneumocystis jirovecii pneumonia）、[[醫學筆記/Infectious Disease/Fungus infection/Cryptococcus]]、Talaromyces（台灣） | PJP、Cryptococcus 的長條都從 200 開始，< 100 最深 |
| < 100 | **Toxoplasmosis**、**食道 candidiasis**、其他黴菌、**Kaposi sarcoma** | |
| < 50 | **CMV end-organ disease**、**NTM／MAC**（nontuberculous mycobacteria） | 最深的兩個 |

### 像感染但不是感染

1. [[醫學筆記/Dermatology/Tumor/Vascular Tumors (紅的)/Kaposi sarcoma (Malignant)|Kaposi sarcoma]]（< 100）、NHL（任何 CD4）：都在 HIV 肺部併發症的圖上，表現得像感染。
2. 治好之後的 IRIS（immune reconstitution inflammatory syndrome）：免疫恢復才誘發大量發炎反應，也像感染，見 [[醫學筆記/Infectious Disease/Fungus infection/Cryptococcus]]。
