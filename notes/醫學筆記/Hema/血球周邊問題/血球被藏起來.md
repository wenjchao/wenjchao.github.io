# 血球被藏起來

## 內文

沒壞也沒流掉，全身血球總量正常，只是**抽血抽不到**

marrow reserve 正常、程度多半 mild ⇒ **治底下的原因，不要補血球**

- 注意：
  1. 與 [[血球被破壞]] 的分界 → [[Blood test for hemolytic anemia|溶血指標]]陰性
  2. 與 [[血球周邊問題/血球流掉]] 的分界 → 血球「總量」有沒有真的變少（決定要不要補）
  3. hypersplenism 嚴重時會加速清除，那一段算進 [[血球被破壞]]
  4. 第 4 類機轉是體外聚集／檢驗誤差，不是真的 sequestration，只是同樣「抽不到」
