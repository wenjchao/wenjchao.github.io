# 製造不出血球

## 內文

量的問題：骨髓做不出足夠的血球

怎麼認：
1. 紅血球：[[RPI]] 低 → 骨髓沒在造血
2. 白血球：看 [[Marrow reserve 的臨床徵象|bone marrow reserve]]
3. 血小板：（待補 by claude）
4. 三系同時低下 → 問題在骨髓 → 骨髓檢查

找原因，由淺入深：
1. 先抓常見可逆：原料不足、藥物／毒物、post-infectious → 抽血＋病史
2. 再想骨髓本身：衰竭／浸潤（骨髓檢查）、 congenital（年齡＋病史）
