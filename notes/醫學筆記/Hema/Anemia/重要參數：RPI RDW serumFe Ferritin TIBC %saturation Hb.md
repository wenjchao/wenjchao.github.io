# 重要參數：RPI RDW serumFe Ferritin TIBC %saturation Hb MCV MCH MCHC RBCCount

## 內文
- [[重要參數：RPI RDW serumFe Ferritin TIBC %saturation Hb/RPI (造血能力)= RI (Reticulocyte 數)／ 校正數字 (1.02.5)|扁平]]
- MCV: 指每個 RBC 的平均體積
- MCH: 指每個 RBC 內所含 Hb 的平均量 = Hb / RBC count (個/cc)
- MCHC: 指 每升 RBC 中平均所含 Hb 濃度 = Hb / Hct (%)
- Ferritin: 鐵儲量
- TIBC: 與 Ferritin 成反比
- % saturation = serumFe / TIBC
