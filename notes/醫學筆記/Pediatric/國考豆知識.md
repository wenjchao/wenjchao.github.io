# 國考豆知識

## 內文
hypothyroidism：大囟門、大舌頭

Reverse differential cyanosis ⇒ TGA

interrupted aortic arch ⇒ DiGeorge

TAPVR 不要用 PGE1 擴大 PDA，因為會造成肺鬱積更嚴重

Blue spell 時 murmur 反而變小 (PS 太嚴重) ⇒ beta-blocker

right atrial isomerism 有兩個 SA node

流感疫苗 6 個月以上即可施打

哺乳

1. 除了 HIV、HTLV、化療 (ex: MTX) 媽媽不建議哺乳以外，都可以哺乳
2. TB 媽媽要先治療兩週、HBV寶寶要施打免疫球蛋白、VZV / HSV 皰疹不要碰到寶寶
3. 希望媽媽不要抽煙喝酒，但是就算沒戒還是可以哺乳

兒童感冒後中耳炎 > 鼻竇炎

PPV 23 (只有莢膜)：不產生 memory cell (T cell independent) ⇒ 持續短 (5年)，要等兩歲以上才能打 (自費)

PCV 13 (莢膜 + 蛋白質)：有 memory cell (T cell dependent) ⇒ 持續久 (>10年)，出生六週以上就能打 (健保)

消化道閉鎖 on X-ray：

1. Single bubble: Congenital hypertrophic **<u>pyloric</u>** stenosis
2. Double bubble: **<u>Duodenal</u>** atresia, annular **<u>pancreas</u>**
3. Triple bubble: **<u>Jejunal</u>** atresia

新生兒黃疸從臉開始，跟早產 (34~36 wks)有關

indirect bilirubin > 16~18 可以開始照光

D / T bilirubin > 20 就不正常了

兒童腹瀉不要給運動飲料，要給口服葡萄糖電解質液

RTA 1 遠端、不排酸。RTA 2 近端、不吸收 HCO3-

Febrile seizure 再發燒時可以給 BZD 防復發

嬰幼兒異位性皮膚炎先臉 & 外肘 ⇒ 急性期 (有組織液滲漏時) 用乳霜比較乾爽，慢性期用油膏保濕 (濕則乾之、乾則濕之)

副食品 4 個月就可以開始一個一個加

TOF 過一段時間等 RV 越來越肥厚塞住 outlet 會更嚴重

TOF blue spell 給 支氣管擴張劑不如給鎮靜劑

non-cyanotic heart disease 周邊不太會掉血氧

VSD

1. perimembraneous ⇒ 自然癒合
2. Subarterial ⇒ AR
3. Atrioventricular canal-type ⇒ MR / TR
4. Muscular ⇒ 自然癒合

STSS 可以給 Oxacillin + Clindamycin (進胞內殺細菌)

rett syndrome: 某種 x-link neurological disorder in girls ⇒ 智力障礙、反覆拍手

新生兒：毒性紅斑（Erythema toxicum）& 半紅半白（Harlequin color change）都正常，無特殊意義

男女都一樣 先第二性徵 ⇒ 陰毛 ⇒ 最後長高

T cell 如果沒問題 剛出生六個月應該可以靠媽媽的抗體

1. 六個月才開始出事 ⇒ Bruton (**<u>X-link</u>**, B)
2. 一出生沒多久就出事 ⇒ SCID (**<u>X-link</u>**, B + T)
3. IgA deficiency 最常見 但沒症狀 (拉肚子、IBD、呼吸道為主)
4. CVID：hypogammaglobulinemia，B cell 數量正常但是功能差，可能成人才發病

斜頸症常是右側 SCM 問題

一歲可以揮手拍手

高血鈉可能癲癇

延遲斷臍可以增加 Hb
