# Toxidrome: 毒物造成的身體變化 (每個都會Consciousness Disturbance)

## 內文
1. Sympathomimetic 擬交感：Dilated pupil, 譫妄, HR↑, BP↑, <mark>**皮膚濕**</mark>**（交感支配sweat gland）**
2. Anti-cholinergic 抗副交感：Dilated pupil, 譫妄, HR↑, BP↑, <mark>**皮膚乾熱**</mark>
3. Cholinergic 副交感：Constricted pupil, HR↓, <mark>**Hyperactive bowl**</mark>**, 分泌物↑**
4. Sympatholytic 抗交感：HR↓, BP↓, Lethargy
5. 麻醉鎮定劑：Constricted pupil, 意識障礙, 呼吸抑制, HR↓, BP↓
6. 甲醇、乙二醇：意識障礙, Acidosis, Dyspnea
7. 降血糖藥：dizziness, weakness, hypothermia
