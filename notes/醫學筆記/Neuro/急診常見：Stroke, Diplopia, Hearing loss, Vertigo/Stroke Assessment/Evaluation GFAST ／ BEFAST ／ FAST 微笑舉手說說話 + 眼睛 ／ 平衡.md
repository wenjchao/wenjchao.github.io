# Evaluation: GFAST / BEFAST / FAST 微笑舉手說說話 + 眼睛 / 平衡

## 內文
1. Balance：走路困難、不平衡、頭暈。Tandem gait 本來就不好走，不要亂抓，Romberg test也不一定適合 → 看一般走路五公尺就好了
2. Eyes/Gaze：**Diplopia**, blurred vision, Visual Field defect, Gaze in one direction
3. Face：微笑（看對稱與否），測Motor同arm
4. Arms：Motor (客觀)比 sensory (主觀)準，半側無力比單手無力像中風
5. Speech：問名字、住址。注意Dysrthria VS Aphasia
6. Time_for_119

其他：頭痛、頭暈、嘔吐、記憶喪失

Cincinnati Prehospital Stroke Scale(更簡易)：微笑舉手說說話，中一個72％中三個87%是 stroke
