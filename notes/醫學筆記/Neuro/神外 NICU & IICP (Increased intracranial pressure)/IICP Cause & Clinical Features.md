# IICP Cause & Clinical Features

## 內文
### Cause

1. **Mass**：**tumor / hematoma / edema**( ischemia / hypoxia / trauma )
2. increase CSF production : choroid plexus papilloma
3. decreased CSF absorption : arachnoid granulation adhesions after bacterial meningitis
4. Obstructive hydrocephalus
5. Obstruction of venous outflow : venous sinus thrombosis / jugular vein compression
6. IIH (Idiopathic intracranial hypertension)

### Clinical Features

1~3出現 ⇒ 緊急處理＋ICP monitor

1. Depressed global conscious, especially **GCS≤8**
2. **Cranial nerve** :
   1. CN2(optic nerve) : Papilledema, Blurred vision
   2. CN3 : unilateral/bilaterally fixed & dilated pupil
   3. CN5 : headache, via the pain fibers in dura & blood vessels
   4. CN6 palsy
   - 注意：Cranial nerve & accompanied arteries
     CN3: posterior communicating artery
     CN5: superior cerebellar artery
     CN7: anterior inferior cerebellar artery
3. **Cushing Triad**: **PR↓、RR↓、systolic BP↑**
   猜測是因為brainstem compression，結論是跟shock剛好相反
4. Others: periorbital bruising, herniation syndromes, other local NE findings
