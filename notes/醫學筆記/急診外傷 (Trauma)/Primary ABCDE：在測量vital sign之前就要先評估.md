# Primary ABCDE：在測量vital sign之前就要先評估（因為測量vital sign需要儀器）

## 內文
- 注意：要弄清楚傷害發生機轉（高動能？）、傷害發生時間（例：頭部外傷有清明期）

1. Airway + C-spine : clear obstruction, intubation if needed
2. Breathing : 呼吸音、胸廓起伏是否對稱，呼吸pattern
   1. needle decompression for **Tension Pneumothroax** (anterior axillary line & 4~6 rib)
   2. chest tube for **Hemothorax**, pigtail for **Pneomothroax**
   3. **Flail chest**
3. Circulation + bleeding control（ilium, femur骨折也可能會大出血）
   1. capillary refiling time < 2s
   2. 止血(壓近心端)，補水補血
4. Disability：評估GCS＆Neurological status，身體四肢是否能動＆動的狀態如何
5. Exposure：將患者暴露，仔細從頭到尾檢查尤其受傷部位，但要注意保暖！！！
6. eFAST：超音波看腹腔出血 ⇒ subxiphoid **pericardial**, **perisplenic**, **hepatorenal**, pelvic / **retrovesical**, bilateral anterior **lung**
