# 方程式推導

## 內文
1. 既然哈密頓正則變換可以隨便變，那最好變換出的新座標可以直接讓 $H' = 0$
   此時 $\dot P_j = \frac{\partial H'}{\partial Q_j}$，$\dot Q_j = \frac{\partial H'}{\partial P_j}$，即所有正則變量 P Q 均為循環座標，也均守恆
2. 如何做到？ ⇒ 因為 $H' - H =\frac{\partial F}{\partial t}$ ⇒ $H +\frac{\partial F}{\partial t} = 0$
3. 將這個特殊的生成函數 F 設為第二型生成函數，即 $F_2(q,P,t)$。第二型生成函數產生的正則變換規則如下：
   1. $p_j = \frac{\partial F_2}{\partial q_j}$
   2. $Q_j = \frac{\partial F_2}{\partial P_j}$
   3. $H' - H =\frac{\partial F_2}{\partial t}$
4. 因為 $p_j = \frac{\partial F_2(q,P,t)}{\partial q_j}$，因此原哈密頓量 H 可以表示為 $H(q,p,t) = H(q, \frac{\partial F_2(q,P,t)}{\partial q},t )$
   將此生成函數 $F_2$ 命名為 **<u>哈密頓主函數 S</u>** ⇒ $H(q, \frac{\partial S(q,P,t)}{\partial q},t ) + \frac{\partial S(q,P,t)}{\partial t}=0$
   此即為 **<u>哈密頓-雅可比方程式</u>**
5. 此偏微分方程式 $H(q_1, q_2,…q_s, \frac{\partial S}{\partial q_1},…\frac{\partial S}{\partial q_s},t ) + \frac{\partial S}{\partial t}=0$ 有 s+1 個變量，即 $\{q_1,q_2,…q_s,t\}$，因此 S 的解應當有 s+1 個積分常數
   1. 其中 $S(q,P,t)$ 加上任何常數均滿足此方程式 ⇒ 必有一常數 $S(q,P,t) + C$
   2. 因為此方程式中 P 為常數（所有 $\dot P_j =0$），因此索性把這 s 個 P 取為這剩下 s 個積分常數 $\{P_1,P_2,…P_s\}$
6. 若原哈密頓量不顯含時間，即 $\frac{\partial H}{\partial t} = 0$，則 $\frac{\partial^2 S}{(\partial t)^2}=0$ ⇒ $\frac{\partial S}{\partial t}$ 為常數
   ⇒ 此時 t 是可以分離的變量，即 $S(q,P,t) = S_0(q,P) + P_1t+C$
   - $S_0(q,P)$ 不含時間，稱為**<u>哈密頓特徵函數</u>**
   - 其實常數 $P_1 = \frac{\partial S}{\partial t}= -H$（通常寫作$-E$）
