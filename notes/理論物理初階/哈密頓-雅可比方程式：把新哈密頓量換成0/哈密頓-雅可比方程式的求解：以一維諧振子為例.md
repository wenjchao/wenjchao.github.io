# 哈密頓-雅可比方程式的求解：以一維諧振子為例

## 內文
1. 一維諧振子的哈密頓量是 $H = \frac{1}{2}\frac{p^2}{m} + \frac{1}{2}{m \omega^2q^2}$，代入哈密頓-雅可比方程式
   ⇒ $\frac{1}{2m}\frac{\partial S(q,P,t)}{\partial q} + \frac{1}{2}{m \omega^2q^2} + \frac{\partial S(q,P,t)}{\partial t}=0$
   ⇒ $\frac{1}{2m}(\frac{\partial S(q,P,t)}{\partial q} + {m^2 \omega^2q^2}) + \frac{\partial S(q,P,t)}{\partial t}=0$
2. 因為哈密頓量 H 不顯含時間 ⇒ $S(q,P,t) = S_0(q,P) +P_1t+C$，代入方程
   ⇒ $\frac{1}{2m}(\frac{\partial S_0(q,P)}{\partial q} + {m^2 \omega^2q^2}) + P_1=0$
   ⇒ $S_0 =\int (\sqrt{-2mP_1-m^2 \omega^2q^2})dq$
   ⇒ $S = S_0 + P_1t+C =  \int (\sqrt{-2mP_1-m^2 \omega^2q^2})dq + P_1t+C$
3. 代入 $Q_j = \frac{\partial F_2}{\partial P_j}$ ⇒ $Q_1 = \int \frac{m}{\sqrt{-2mP_1-m^2 \omega^2q^2}}dq + t = \frac{1}{\omega}arcsin(\frac{m\omega q}{\sqrt{-2mP_1}})+t$
4. 計算 $q = \sqrt{\frac{2(-P_1)}{m\omega^2}}sin(-\omega t + \omega Q_1) = \sqrt{\frac{2E}{m\omega^2}}sin(\omega t + \omega (-Q_1))$
   其中 $-P_1 = H =E$（即為能量，前面有提到），$-Q_1$ 即為初相角
5. 此諧振子因為只有一維，故 P & Q 也只有各一個
