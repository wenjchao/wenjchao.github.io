# 第一步：寫出彎矩 $M(x)$﻿ 方程式，即梁上每個點的彎矩

## 內文
1. 假設從左邊支撐點開始，取長度為 $x$ 的一段梁（稱為左段梁）來進行分析：
2. 不管 $x$ 取多少 (甚至也可以從中間取)，任一段梁都應符合<u>力平衡</u>與<u>力矩平衡</u>
3. 對於左段梁而言，受到的力（全部以向上為正）有：
   1. 左邊支撐點向上的支撐力為 $N_1 = \frac{W_0}{2}$
   2. 這段梁本身的重量 $W_左(x)= -\frac{W_0x}{l}$
   3. 右邊截面給予的剪切力 $F(x) = W_0(\frac{x}{l} - \frac{1}{2})$
   - 此三力相加為 0
4. 同樣對於左段梁而言，受到力矩 (全部以逆時針為正，以左支撐點為支點) 有：
   1. 左邊支撐點的支撐力提供的力矩 $M_N = 0$
   2. 這段梁本身重量提供的力矩 $M_W(x) = -\frac{W_0x}{l} \times \frac{x}{2} = -\frac{W_0x^2}{2l}$
   3. 右邊截面剪切力提供的力矩 $M_F(x) = W_0(\frac{x}{l} - \frac{1}{2})\times x = W_0x(\frac{x}{l} - \frac{1}{2})$
   4. 為何三力矩相加不為 0？因為梁本身的彎曲也提供了力矩（梁有彈性，會想彈回來），稱為**<u>彎矩</u>**（詳情見<u>補充：彎矩是什麼</u>）：
      $$
      M_彎(x) = 0-M_W - M_F = \frac{W_0x}{2}(1-\frac{x}{l})
      $$
