# 2. & 3. 的證明

## 內文
1. 已知 $\vec{\omega } =\frac{d}{dt}\theta(t)$，若有一個三維向量 $\vec f$，則對於一個在慣性觀察系、另一個在非慣性觀察系的兩個觀察者而言，可以發現
   $f_{x慣} = f_{x非慣}，\hat{i}_{慣}=\hat{i}_{非慣}$
   $f_{y慣} = f_{y非慣}，\hat{j}_{慣}=\hat{j}_{非慣}$
   $f_{z慣} = f_{z非慣}，\hat{k}_{慣}=\hat{k}_{非慣}$
   ⇒ 可以發現，對於兩座標系而言，向量 $\vec{f}$ 均為 $f_x\hat{i}+ f_y\hat{j} + f_z\hat{k}$
   ⇒ 因此，分歧點在於向量 $\vec{f}$ 以及座標 $\hat{i}、 \hat{j}、 \hat{k}$ 如何隨時間變化（即對 t 微分）
2. 對於慣性觀察者而言：
   $\frac{d\hat{i}_{慣}}{dt} = \frac{d\hat{j}_{慣}}{dt} = \frac{d\hat{k}_{慣}}{dt} = 0$
   $\frac{d\hat{i}_{非慣}}{dt} = \vec{\omega } \times \hat {i}_{非慣}$，$\frac{d\hat{j}_{非慣}}{dt} = \vec{\omega } \times \hat {j}_{非慣}$，$\frac{d\hat{k}_{非慣}}{dt} = \vec{\omega } \times \hat {k}_{非慣}$
   因此，在慣性觀察系的視角中看到
   $$
   (\frac{d \vec{f}}{dt})_{慣}=\frac{d(f_{x慣}\hat{i}_{慣})}{dt}+\frac{d(f_{y慣}\hat{j}_{慣})}{dt}+\frac{d(f_{z慣}\hat{k}_{慣})}{dt} \\= \frac{df_{x慣}}{dt}\hat{i}_{慣} + \frac{df_{y慣}}{dt}\hat{j}_{慣} + \frac{df_{z慣}}{dt}\hat{k}_{慣}\\ + \xcancel{f_{x慣}\frac{d\hat{i}_{慣}}{dt} +f_{y慣}\frac{d\hat{j}_{慣}}{dt} + f_{z慣}\frac{d\hat{k}_{慣}}{dt}}
   $$
   - 後面被劃掉是因為等於 0
3. 而對於非慣性觀察者而言：
   $\frac{d\hat{i}_{非慣}}{dt} = \frac{d\hat{j}_{非慣}}{dt} = \frac{d\hat{k}_{非慣}}{dt} = 0$
   因此，在非慣性觀察系的視角中應該要看到
   $$
   (\frac{d \vec{f}}{dt})_{非慣}=\frac{d(f_{x非慣}\hat{i}_{非慣})}{dt}+\frac{d(f_{y非慣}\hat{j}_{非慣})}{dt}+\frac{d(f_{z非慣}\hat{k}_{非慣})}{dt} \\= \frac{df_{x非慣}}{dt}\hat{i}_{非慣} + \frac{df_{y非慣}}{dt}\hat{j}_{非慣} + \frac{df_{z非慣}}{dt}\hat{k}_{非慣}\\ + \xcancel{f_{x非慣}\frac{d\hat{i}_{非慣}}{dt} +f_{y非慣}\frac{d\hat{j}_{非慣}}{dt} + f_{z非慣}\frac{d\hat{k}_{非慣}}{dt}}
   $$
   - 後面被劃掉是因為等於 0
4. 問題在於，牛頓力學實際上在慣性觀察系中才成立，因此 c. 這個等式，其實是假的視角，即非慣性觀察者根據牛頓力學**<u>以為、假設</u>**物體應該如何運動
5. 實際上我們必須從慣性系觀察者視角出發，計算非慣性系座標應該如何變化
   此時 $\frac{d\hat{i}_{非慣}}{dt} = \vec{\omega } \times \hat {i}_{非慣}$，$\frac{d\hat{j}_{非慣}}{dt} = \vec{\omega } \times \hat {j}_{非慣}$，$\frac{d\hat{k}_{非慣}}{dt} = \vec{\omega } \times \hat {k}_{非慣}$（同 b. 視角）
   $$
   (\frac{d \vec{f}}{dt})_{慣}=\frac{d(f_{x非慣}\hat{i}_{非慣})}{dt}+\frac{d(f_{y非慣}\hat{j}_{非慣})}{dt}+\frac{d(f_{z非慣}\hat{k}_{非慣})}{dt} \\= \frac{df_{x非慣}}{dt}\hat{i}_{非慣} + \frac{df_{y非慣}}{dt}\hat{j}_{非慣} + \frac{df_{z非慣}}{dt}\hat{k}_{非慣}\\ + f_{x非慣}\frac{d\hat{i}_{非慣}}{dt} +f_{y非慣}\frac{d\hat{j}_{非慣}}{dt} + f_{z非慣}\frac{d\hat{k}_{非慣}}{dt}\\= (\frac{d\vec f}{dt})_{非慣}*\vec{\omega } \times\hat{i}+f_y*\vec{\omega } \times\hat{j}+f_z*\vec{\omega } \times\hat{k}\\=(\frac{d\vec f}{dt})_{非慣}  +\vec{\omega } \times\vec f = [(\frac{d}{dt})_{非慣}  +\vec{\omega } \times]\vec f
   $$
   - 此公式後半段出現的 $(\frac{d\vec f}{dt})_{非慣}$，指的是非慣性觀察系的視角中的$\frac{d\vec f}{dt}$ （詳情見前面 c.）
   - 後半段的 $\hat{i}、 \hat{j}、 \hat{k}$ 因為不是被微分的狀態，所以對於兩觀察系來說都沒差
   - 事實上 $(\vec{\omega } \times)$ 本身可以視為一個矩陣（把三維向量變換為另一個三維向量）⇒ 此矩陣其實就是 $(\vec{\omega } \times) = R'(t)\cdot R^T(t)$ ，其中 R 為旋轉矩陣
6. 此時如果帶入 $\vec f = \vec r$ ，則
   $$
   \vec v_{慣} = (\frac {d\vec r}{dt})_{慣} = [(\frac{d}{dt})_{非慣} +\vec{\omega } \times]\vec r = \vec v_{非慣} + \vec \omega \times\vec r
   $$
   $$
   \vec a_{慣} = (\frac {d}{dt})(\frac {d\vec r}{dt})_{慣} = [(\frac{d}{dt})_{非慣} +\vec{\omega } \times][(\frac{d}{dt})_{非慣} +\vec{\omega} \times]\vec r \\= (\frac{d^2\vec r}{dt^2})_{非慣}  + \vec{\omega} \times(\frac{d\vec r}{dt})_{非慣} + (\frac{d}{dt})_{非慣}({\vec \omega} \times\vec r) +{\vec\omega} \times{\vec\omega} \times\vec r \\=   \vec a_{非慣} + \vec{\omega} \times\vec v_{非慣} + \vec{\omega} \times\vec v_{非慣} + \vec{\omega}' \times\vec r_{非慣} + {\vec\omega} \times{\vec\omega} \times\vec r \\=\vec a_{非慣} + 2* \vec{\omega} \times\vec v_{非慣} + \vec{\omega}' \times\vec r_{非慣} + {\vec\omega} \times{\vec\omega} \times\vec r \\
   $$
   當然也可以用 $\vec a_{慣} = (\frac {d\vec v}{dt})_{慣}$ 來計算，結果相同
