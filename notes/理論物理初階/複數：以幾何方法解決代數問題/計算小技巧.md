# 計算小技巧

## 內文
1. 對於複數 $z = a+bi$，其模長 $\vert z \vert = \sqrt{a^2 + b^2}$ ，角度 $\theta = \arctan (\frac{b}{a})$
   ⇒ $z = a+bi = \vert z \vert e^{i \arctan (\frac{b}{a})}$
2. 對於複數 $z = \frac{1}{a+bi} = \frac{a-bi}{a^2 + b^2}$，其模長 $\vert z \vert = \frac{1}{\sqrt{a^2 + b^2}}$ ，角度 $\theta = \arctan (\frac{-b}{a})$
   ⇒ $z = \frac{1}{a+bi} = \vert z \vert e^{i \theta} = \frac{1}{\sqrt{a^2 + b^2}} e^{i\arctan (\frac{-b}{a})}$
3. 對於兩相同振幅的複數，$Ce^{i\theta} + Ce^{i\delta} = C e^{i(\frac{\theta + \delta}{2})}(e^{i(\frac{\theta - \delta}{2})} + e^{-i(\frac{\theta - \delta}{2})}) = C cos(\frac{\theta - \delta}{2}) e^{i(\frac{\theta + \delta}{2})}$
