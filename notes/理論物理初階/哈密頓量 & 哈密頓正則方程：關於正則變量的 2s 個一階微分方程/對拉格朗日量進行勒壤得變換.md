# 對拉格朗日量進行勒壤得變換

## 內文
1. $dL(q,\dot q,t) = \sum_{j} (\frac{\partial L}{\partial \dot q_j})d\dot q_j + \sum_{j}(\frac{\partial L}{\partial q_j})dq_j + \frac{\partial L}{\partial t}dt$
   ⇒ 定義 $p = \frac{\partial L}{\partial \dot q}，\dot p = \frac{\partial L}{\partial q}$ （ $p$ 即為廣義動量，$\dot p$ 即為廣義力）
   ⇒ $dL(q,\dot q) = \sum_{j} p_jd\dot q_j + \sum_{j}\dot p_jdq_j +\frac{\partial L}{\partial t}$
2. 我們不想要 $\dot p$，因此構造新函數 $\sum_{j} p_j\dot q_j$ ⇒ $d(\sum_{j} p_j\dot q_j) = \sum_{j} p_jd\dot q_j + \sum_{j} \dot q_jdp_j$
3. 定義新函數 $H = \sum_{j} p_j\dot q_j -L(q,\dot q,t)$
   則 $dH = d(\sum_{j} p_j\dot q_j -L(q,\dot q,t)) = \sum_{j}\dot p_jdq_j - \sum_{j} \dot q_jdp_j -\frac{\partial L}{\partial t}dt$
   此處 $H(p,q,t)$ **<u>即為哈密頓量</u>**（廣義能量）（有 t 是因為 H 可以正則變換）
