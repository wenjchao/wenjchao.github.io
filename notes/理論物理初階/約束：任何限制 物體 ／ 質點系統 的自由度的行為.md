# 約束：任何限制 物體 / 質點系統 的自由度的行為

## 內文
1. 什麼是約束：理論上一個物體在三維空間的位置中有三個變數 $s_x、s_y、s_z$，即 $\vec{s}_{(\hat{i},\hat{j},\hat{k})} = s_x\hat{i}+ s_y\hat{j} + s_z\hat{k}$，但如果此物體受到約束（ex: 放在桌面上 or 掛在單擺上），則 $s_x、s_y、s_z$ 就不能自由變化。
2. 約束力的性質：約束力經常不固定，經常與時間、空間、速度、額外外力有關，對牛頓力學而言很頭痛 ⇒ 發展拉格朗日力學
3. 約束的性質：約束可以寫成方程式（或是不等式）。如果有 n 個質點組成質點系統，本來有 3n 個自由度，但每加一條新的約束方程式，自由度便會減少 1
4. 因此可以用座標數更少的廣義座標（新座標數 a = 3n - 約束方程式數量）來完整描述此質點系統的狀態（ex: 可以只用 θ 一個數來描述一個平面單擺的狀態）。此新的廣義座標組成的抽象 a 維空間稱為**<u>位形空間</u>**
