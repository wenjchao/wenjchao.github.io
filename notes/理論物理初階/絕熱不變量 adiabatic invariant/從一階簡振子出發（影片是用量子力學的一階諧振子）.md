# 從一階簡振子出發（影片是用量子力學的一階諧振子）

## 內文
1. 最小作用量 $J = \frac{H}{\omega}$，其中哈密頓量 $H = T+V = \frac{p^2}{2m} + \frac{kq^2}{2}$，$\omega = \sqrt {\frac{k}{m}}$ 為角頻率
   - $m$ 不會改變
   - $H、\omega$ 會隨著時間緩慢改變 （ $\vert\frac{\dot \omega }{\omega^2}\vert \ll 1$ ）
   - $p、q$ 則是會隨著簡諧運動而週期性改變
   - 單一週期中相軌圍成的橢圓方程式：$\frac{p^2}{2mH} + \frac{q^2}{\frac{2H}{k}} = 1$
     ⇒ 圍成的橢圓面積 $\oint pdq = \pi ab = \pi\sqrt{2mH}\sqrt{\frac{2H}{k}}=\frac{2\pi H}{\omega}$
     ⇒ $J = \frac{H}{\omega}=\frac{1}{2\pi}\oint pdq$ 成立
2. 因為 $\omega = \sqrt {\frac{k}{m}}$ ⇒ $k=\omega^2m$ ⇒ 哈密頓量 $H = \frac{p^2}{2m} + \frac{m\omega^2q^2}{2}$
3. 最小作用量對時間的變化 $\dot J=\frac{\partial J}{\partial t} = \frac{\omega \dot H - \dot \omega H}{\omega^2} = \frac{\omega (m\omega \dot\omega q^2) - \dot \omega (\frac{p^2}{2m} + \frac{m\omega^2q^2}{2})}{\omega^2} \\=\frac{\dot \omega (\frac{1}{2} m\omega^2 q^2 - \frac{p^2}{2m}) }{\omega^2} = \frac{\dot \omega }{\omega^2}(V-T)$
4. 注意此處 V 為一個週期內的平均位能，T 則是一個週期內的平均動能，兩者基本上相等（即 $V-T$ 很小），又因為 $\frac{\dot \omega }{\omega^2}$ 本身已經很小了
   ⇒ $\dot J = \frac{\dot \omega }{\omega^2}(V-T)$ 真的非常非常非常小
