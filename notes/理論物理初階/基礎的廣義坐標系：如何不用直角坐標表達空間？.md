# 基礎的廣義坐標系：如何不用直角坐標表達空間？

## 內文
1. 一個物體在平面上的位置，可以用 x-y 笛卡兒座標來表示，也可以用 r-θ 極座標來表示，也可以用任何廣義坐標表示。
2. 盡量選擇彼此獨立的廣義坐標 ⇒ 這代表如果此系統的自由度是 n，所選的廣義坐標最好剛好有 n 個參數。
   > 舉例：對於單擺而言，雖然可以用 x-y 座標描述它，但他其實只有一個自由度，因此直接用 θ 一個參數描述它更方便
3. **座標微分（以及變分**$\delta$**）的轉換**：對於一個在平面上的向量 A ，根據 chain rule，此向量的
   $d\vec{f} =d\vec{f}(\vec{x},\vec{y}) = \frac{∂\vec{f}}{∂\vec{x}}d\vec{x} + \frac{∂\vec{f}}{∂\vec{y}}d\vec{y} = d\vec{f}(\vec{r},\vec{\theta}) = \frac{∂\vec{f}}{∂\vec{r}} d\vec{r} + \frac{∂\vec{f}}{∂\vec{\theta}}d\vec{\theta}$
   即 $d\vec{f}(\vec{p_n}) = \displaystyle\sum_{i=1}^n\frac{∂\vec{f}}{∂\vec{p_i}}d\vec{p_i}$
4. **座標之間的轉換**：要同時注意 **係數**＆**座標軸** 各自的轉換
   以平面座標軸 ⇒ 極座標軸 為例
