# 克卜勒三大定律、萬有引力的平方反比定律

## 內文
### 克卜勒三大定律

1. 軌道定律：行星軌道為橢圓形
2. 面積定律：在相等時間裡，行星與太陽連線所掃過的面積相等
3. 週期定律：行星公轉週期的平方與半長軸的立方成正比，即 $\frac{T^2}{a^3} = K$
   - K 與行星無關
   - 當然也和長軸的立方成正比

### 從克卜勒三大定律 + 比耐公式 ⇒ 推導平方反比定律

1. 根據面積定律，行星在極短時間內掃過的面積固定 ⇒ $\frac{dS}{dt} = \frac{1}{2}r^2\dot \phi = \frac{p_\phi}{2m}$
   ⇒ 角動量守恆（注意這裡沒有規定軌道必須長怎樣）
2. 根據軌道定律，行星軌道可以寫成極座標的形式：$r= \frac{a(1-e^2)}{1-ecos\phi }$，$u = \frac{1-ecos\phi }{a(1-e^2)}$
3. 根據比耐公式，
   $F = -\frac{p_\phi^2u^2}{m}(\frac{d^2u}{(d\phi)^2}+u)= -\frac{p_\phi^2u^2}{m}(\frac{ecos\phi }{a(1-e^2)}+\frac{1-ecos\phi }{a(1-e^2)}) = -\frac{p_\phi^2}{ma(1-e^2)}u^2$
   ⇒ $F \propto -u^2$，即 $F \propto -\frac{1}{r^2}$
4. 因為想了解 $\frac{1}{r^2}$ 前方的比例係數 $\frac{p_\phi^2}{ma(1-e^2)}$ ⇒ 根據週期定律，$\frac{T^2}{a^3} = K$ ⇒ 想辦法把$p_\phi$ 用週期 T 來表示
5. 對於一個週期行星掃過的面積而言，$S = \int_0^T \frac{p_\phi}{2m}dt$
   ⇒ $\pi ab = \pi a^2\sqrt{1-e^2} = \frac{p_\phi T}{2m}$
   ⇒ $p_\phi = \frac{2\pi ma^2\sqrt{1-e^2}}{T}$ ⇒ $\frac{p_\phi^2}{ma(1-e^2)} = \frac{4\pi^2ma^3}{T^2} = \frac{4\pi m}{K}$
   ⇒ $F = -\frac{4\pi }{K} \frac{m}{r^2}$，其中 $\frac{4\pi }{K}$ 為常數，即是 $GM$

### 從平方反比定律 + 比耐公式 ⇒ 推導天體軌道

1. 將平方反比定律 $F = \frac{GMm}{r^2} = GMmu^2$ 帶入比耐公式
   ⇒ $\frac{p_\phi^2u^2}{m}(\frac{d^2u}{(d\phi)^2}+u) = GMmu^2$ ⇒ $\frac{d^2u}{(d\phi)^2}+u = \frac{GMm^2}{p_\phi^2}$，此為 u 的二階微分方程
2. 有常數的二階微分方程 ⇒ 解 = 特解 + 通解
   1. 通解（假裝常數項 = 0）：$\frac{d^2u}{(d\phi)^2}+u = 0$ ⇒ $u = c_1*cos(\phi+c_2)$ (這裡cos 也可以換成 sin。c是積分常數)
   2. 特解：$u = \frac{GMm^2}{p_\phi^2}$
   ⇒ 結論： $u = c_1cos(\phi+c_2) + \frac{GMm^2}{p_\phi^2}$ ⇒ $r=\frac{1}{u} = \frac{\frac{p_\phi^2}{GMm^2}} {1+ \frac{p_\phi^2 c_1}{GMm^2}cos(\phi+c_2)}$
3. 設 $e=-\frac{p_\phi ^2c_1}{GMm^2}$，$l = \frac{p_\phi^2 }{GMm^2}$ ⇒ $r=\frac{l}{1-ecos(\phi+c_2)}$ ⇒ 軌道為圓錐曲線
4. 想算出 e，需使用推比耐公式推出來的軌道方程
   $p_\phi \frac{du}{d\phi} = -\sqrt{2m(E-V(u)) - {(p_\phi u)}^2}$
5. 將 $u = \frac{1-ecos(\phi^2+c)}{l}$、$l = \frac{p_\phi^2 }{GMm^2}$、$V = -\frac{GMm}{r} = -GMmu$ 代入
   ⇒ $p_\phi \frac{-esin(\phi^2+c)}{l} = - \sqrt{2m(E+GMm\frac{1-ecos(\phi^2+c)}{l}) - {(p_\phi \frac{1-ecos(\phi^2+c)}{l})}^2}$
   ⇒ $esin(\phi^2+c) = \sqrt{\frac{2ml^2}{p_\phi^2}E+2(1-ecos(\phi^2+c)) - (1-ecos(\phi^2+c))^2}$
   ⇒ $e^2sin^2(\phi^2+c) = \frac{2ml^2}{p_\phi^2}E+ 1-ecos^2(\phi^2+c)$
   ⇒ $e^2 = \frac{2ml^2E}{p_\phi^2}+ 1 = \frac{2p_\phi^2E}{G^2M^2m^3} + 1$
6. 因此當總能量 E、角動量 $p_\phi$ 被決定好，該天體就只有唯一的運動軌跡
   $r=\frac{l}{1-ecos(\phi+c_2)}$ ，其中 $e = \sqrt{\frac{2p_\phi^2E}{G^2M^2m^3} + 1}$， $l = \frac{p_\phi^2 }{GMm^2}$
