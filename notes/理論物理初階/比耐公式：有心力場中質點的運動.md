# 比耐公式：有心力場中質點的運動

## 內文
對於一個只受有心力的質點而言，想知道它如何運動

1. 先列出已知資訊：角動量守恆、能量守恆、有心力場的位能
   1. 角動量守恆：將拉格朗日量用極座標 $r,\phi$ 表示 ⇒
      $L = T - V = \frac{1}{2}m(\dot r^2 + r^2\dot \phi^2)-V(r)$
      可看出不顯含 $\phi$，即角動量 $p_\phi$ 守恆，$p_\phi = \frac{\partial L}{\partial \dot \phi} = mr^2\dot \phi$
   2. 能量守恆：$E = T + V = \frac{1}{2}m(\dot r^2 + r^2\dot \phi^2)+V(r)$
   3. 有心力：$F = -\frac{dV(r)}{dr}$ ，因為有心力是保守力，所以位能只和位置 r 有關
2. 因為想算出此質點如何運動，因此最重要的是了解 $\dot r = \frac{dr}{dt}$ & $\dot \phi = \frac{d\phi}{dt}$ & $F = -\frac{dV(r)}{dr}$
   - 其他數都當成常數：$m, r,p_\phi,E$。注意 $V(r)$不是常數
3. 因為 $P_\phi = mr^2\dot \phi$ ⇒ $\dot \phi = \frac{d\phi}{dt}= \frac{p_\phi }{ mr^2}$
4. 先把能量守恆的公式用 $P_\phi$ 代換：$E = \frac{1}{2}m\dot r^2 + \frac{1}{2}\frac{p_\phi^2}{mr^2}+V(r)$
   ⇒ $\dot r = \frac{dr}{dt} = \sqrt{\frac{2(E-V(r))}{m} - {(\frac{p_\phi}{mr})}^2}$
5. 兩式相除：$\frac{dr}{d\phi}= \sqrt{\frac{2(E-V(r))}{m} - {(\frac{p_\phi}{mr})}^2} / \frac{p_\phi }{ mr^2}=\frac{r^2\sqrt{2m(E-V(r)) - {(\frac{p_\phi}{r})}^2}}{p_\phi}$
   ⇒ $\frac{p_\phi}{r^2}\frac{dr}{d\phi} = \sqrt{2m(E-V(r)) - {(\frac{p_\phi}{r})}^2}$
6. 為了讓式子好看，因此進行變數代換，使 $u = \frac{1}{r}$ ⇒ $\frac{du}{d\phi} = -\frac{1}{r^2} \frac{dr}{d\phi}$
   ⇒ $p_\phi \frac{du}{d\phi} = -\sqrt{2m(E-V(u)) - {(p_\phi u)}^2}$ ⇒ **<u>此式可以拿來求軌道方程</u>**
7. 想知道有心力如何作用，因此使用公式 $F = -\frac{dV}{dr}$⇒ $\frac{dV}{du} = \frac{dV}{dr}\frac{dr}{du} = \frac{F}{u^2}$
   如果想湊出 $\frac{dV}{du}$ ⇒ 把上面 6. 的公式兩邊同時對 $\phi$ 再微分一次
   ⇒ $p_\phi \frac{d^2u}{(d\phi)^2} =- \frac{-m\frac{dV}{d\phi}- p_\phi^2u\frac{du}{d \phi}}{\sqrt{2m(E-V(u)) - {(p_\phi u)}^2}} = -\frac{-m\frac{dV}{d\phi}- p_\phi^2u\frac{du}{d \phi}}{-p_\phi \frac{du}{d\phi}} = -\frac{m}{p_\phi}\frac{dV}{du} - p_\phi u$
   ⇒ $F = \frac{dV}{du}u^2 = -\frac{p_\phi u^2 (p_\phi \frac{d^2u}{(d\phi)^2} + p_\phi u)}{m} = -\frac{p_\phi^2u^2}{m}(\frac{d^2u}{(d\phi)^2}+u)$
   此即為**<u>比耐公式</u>** $F = -\frac{p_\phi^2u^2}{m}(\frac{d^2u}{(d\phi)^2}+u)$，其中 F < 0 代表引力，> 0 代表斥力
