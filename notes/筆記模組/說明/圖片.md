# 圖片

## 摘要
圖片放在模組旁邊的 `圖片/` 資料夾，用一般 Markdown 語法 `![說明](圖片/檔名.png)` 引用；在內建編輯器裡直接貼上或拖入就會自動存檔並插入。

## 內文
### 引用方式

```markdown
![架構圖](圖片/架構圖.png)
![遠端圖片](https://example.com/a.jpg)
```

- 路徑**相對於這個 .md 檔**。`專案/筆記.md` 裡的 `圖片/a.png` 指的是 `專案/圖片/a.png`；要引用上一層的檔案用 `../圖片/a.png`。
- 支援 png、jpg、jpeg、gif、webp、svg、avif、bmp。
- 圖片不是模組，不會出現在左側列表；放在哪個資料夾都可以，`圖片/` 只是慣例（可在 `CONFIG.imageFolder` 改）。

### 在編輯器裡貼上

來源是「資料夾」（Chrome／Edge）或「本機伺服器」時，在編輯器裡：

- **貼上**剪貼簿的圖片（截圖後直接 ⌘/Ctrl + V）
- 或把圖片檔**拖進文字框**

圖片會存成 `圖片/20260821-142530-名稱.png`（時間戳＋原檔名，截圖類的通用名稱只留時間戳），Markdown 會插在游標處，預覽立刻看得到。其他來源（拖放、檔案選取、GitHub Pages）無法寫檔，請自己把圖片放進資料夾再引用。

### 各種載入方式下的圖片

| 來源 | 圖片 |
|---|---|
| 匯入資料夾（Chrome／Edge） | 直接讀取，不用設定 |
| 本機伺服器 serve.py | 直接讀取 |
| 拖放資料夾／選擇資料夾 | 一起拖進來的圖片可以顯示；重新整理後從快取載入時**圖片不會顯示**（快取只存文字） |
| 從「檔案」多選 | 要把圖片一起選進來 |
| GitHub Pages | 直接讀取（相對路徑） |
| build.py 單一檔案 | 會把 ≤ 5 MB 的圖片內嵌進 HTML（`--max-image-mb` 調整、`--no-images` 不嵌） |

### 大小建議

- 截圖存 PNG 沒問題，但照片請轉 JPEG 或 WebP，單張控制在 1–2 MB 以內。
- 單一檔案打包時，圖片會以 base64 內嵌，檔案大小約是圖片總和的 1.35 倍；超過十幾 MB 的單檔在 iPad 上會開始變慢。
- 想重新命名或搬移圖片，記得同步改 Markdown 裡的路徑（圖片路徑壞掉時會顯示瀏覽器的破圖，不會出現在「壞連結」報告裡——那份報告只管模組）。
