# 快速開始

## 摘要
三分鐘上手：打開檢視器、載入資料夾、寫第一個模組、把模組裝進另一個模組。

## 內文
### 1. 打開檢視器
用 Chrome 或 Edge 雙擊 `index.html`，按「匯入資料夾」，選這個資料夾（就是 `index.html` 所在的資料夾）。瀏覽器會問你要不要允許「檢視並編輯」，允許之後就能直接在頁面上編輯、存回檔案。

只要匯入一次：下次打開會先看到上次的內容，上方提示按一下「重新連接資料夾」就能繼續編輯。右上角「來源 ▾」選單可以隨時重新匯入或「忘記匯入的內容」回到起點。其他瀏覽器或裝置的做法見 [[說明/載入與同步]]。

### 2. 寫第一個模組
按左下角「＋ 新增模組」，輸入名字（例如 `讀書心得`），會得到這樣的檔案：

```markdown
# 讀書心得

## 摘要


## 內文

```

編輯器預設是「直觀編輯」：直接在「摘要」和「內文」兩個區域打字，像 Notion 一樣，選字後用釘在頂端的編輯列設粗體、標題、清單，按 ⌘/Ctrl + S 儲存；想看或改 Markdown 原文就切到「原始碼」，想一邊手寫原始碼一邊看效果就切「並排」（都在同一條編輯列上）。用任何文字編輯器（VS Code、Typora、記事本）打開 `讀書心得.md` 直接改也可以，頁面會自動更新。

### 3. 把模組裝進另一個模組
在別的模組的內文裡寫一行：

```markdown
[[讀書心得|摘要]]
```

（或者直接打 `[[讀` ，跳出的清單裡選「讀書心得」；直觀編輯裡也可以按工具列的「模組」。）存檔後，那裡就會出現一張「讀書心得」的卡片，預設展開到摘要；卡片右上角可以切換 標題／摘要／全文，切換的結果會直接寫回 .md（`[[讀書心得|摘要]]` 會變成 `[[讀書心得|全文]]`），點標題會進入那個模組。想讓模組躲在清單裡、和其他項目長得一樣，寫 `[[讀書心得|扁平]]`。左邊側欄是樹狀的，資料夾可以逐層展開。寫 `[[還沒建立的名字]]` 也沒關係，按一下那個虛線晶片就會幫你建檔——先寫大綱、再填內容，是最順的寫法。
