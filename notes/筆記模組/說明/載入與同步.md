# 載入與同步

## 摘要
檢視器怎麼拿到你的 .md：電腦 Chrome／Edge 直接開資料夾最方便；其他瀏覽器用拖放或本機伺服器；iPad 用伺服器、單一檔案或檔案選取；要給別人看就上 GitHub Pages。各方式的能力差異見表。

## 內文
### 能力總表

| 方式 | 瀏覽器 | 即時更新 | 可編輯 | 圖片 | 適合 |
|---|---|---|---|---|---|
| 匯入資料夾 | Chrome、Edge（桌面） | ✓ 每 2 秒檢查 | ✓ | ✓ | 日常主力 |
| 本機伺服器 `serve.py` | 全部 | ✓ | ✓ | ✓ | Safari／Firefox、iPad 連電腦 |
| 拖放資料夾／選擇資料夾 | 全部桌面瀏覽器 | ✗ | ✗ | 一起拖進來的可以 | 臨時看一下 |
| 從「檔案」多選 | iPad／iPhone Safari | ✗ | ✗ | 要一起選 | iPad 單機閱讀 |
| 單一檔案 `build.py` | 全部 | ✗（重新打包） | ✗ | 內嵌 | 寄給別人、離線、iPad |
| GitHub Pages | 全部 | ✓ 每 60 秒檢查 | ✓ 輸入 token 後直接編輯（或透過 GitHub 網頁） | ✓ | 分享、跨裝置、iPad／手機編輯 |

### 匯入資料夾（File System Access API）

1. 雙擊 `index.html` → 「匯入資料夾」→ 選筆記資料夾 → 允許「檢視並編輯」。
2. 之後用任何編輯器改檔，頁面 2 秒內更新；新增、刪除、改名也會反映在左側列表。
3. **只要匯入一次**。下次打開，頁面會先顯示上次的內容（快取、唯讀），上方有一條「重新連接資料夾」的提示，按一下重新授權，就恢復編輯與自動更新。這個「按一下」是 Chrome 的安全規定，每次重開瀏覽器都要一次；新版 Chrome／Edge 在權限提示裡提供「每次造訪都允許（Allow on every visit）」，選了之後理論上連按都不用按——但實際上對**直接雙擊打開的 `index.html`（`file://` 網址）**，Edge／Chrome 常常記不住，下次還是會問。這不是檢視器能控制的，是瀏覽器對 `file://` 的限制；不想每次被問，就改用下面的本機小伺服器（`http://localhost:8765` 是正常網址，完全不需要這個權限，也沒有提示）。
4. 權限只給這個網頁、這個資料夾；瀏覽器不會碰資料夾以外的東西。

只有 Chromium 系列瀏覽器（Chrome、Edge、Brave、Arc…）支援；Safari 與 Firefox 沒有這個 API，請用下面兩種。

### 為什麼我只能看、不能編輯？

狀態列最右邊寫「唯讀」時，工具列有一顆「唯讀？」會直接告訴你原因與解法；整理如下：

| 你看到的狀態 | 原因 | 解法 |
|---|---|---|
| `…（快取）· 唯讀`，上方有「重新連接資料夾」提示 | 重開頁面後瀏覽器要你再按一下才准寫入 | 按提示，或直接按「重新連接後編輯」 |
| 用拖放／「匯入檔案」進來的（Chrome／Edge） | 這種匯入方式瀏覽器不給寫回 | 選單 →「匯入資料夾…（可編輯）」重新匯入一次 |
| Safari／Firefox 永遠是「唯讀」、沒有「自動更新」 | 這兩個瀏覽器沒有寫入資料夾的 API，`file://` 下只能匯入一次性的唯讀快照 | 雙擊 `啟動筆記.command`／`.bat`，改開 http://localhost:8765，狀態就會變成「本機伺服器 · 自動更新 · 可編輯」；或改用 Chrome／Edge |
| Edge／Chrome 每次打開都跳「View and edit files…」的權限視窗，選了 Allow on every visit 也沒用 | `file://` 網頁的持久權限在這兩個瀏覽器裡常常不會被記住 | 用本機小伺服器（上面那行），`http://` 網址不需要這個權限 |
| 雙擊 `啟動筆記.command` 說「無法打開」，同一個檔案放在別的資料夾卻可以 | 從下載的 zip 解出來的檔案帶著 macOS 的「隔離」標記，Gatekeeper 不讓它執行；程式自己複製出來的副本沒有這個標記 | 對檔案按右鍵 → 打開 → 打開（只要一次）；或把能開的那份複製一份過來蓋掉；或在終端機 `xattr -d com.apple.quarantine 啟動筆記.command` |
| 匯入資料夾時瀏覽器問「檢視」還是「編輯」，選了檢視 | 只拿到讀取權限 | 重新匯入，選「編輯」 |
| 單一檔案版（build.py 產生的） | 那是快照 | 打開 index.html 匯入原始資料夾 |
| GitHub Pages | 靜態網站，預設唯讀 | 按「啟用編輯」輸入一次 GitHub token 就能直接編輯（見下面 GitHub Pages 一節）；或用「在 GitHub 編輯」 |

### 每一份 index.html 各自記憶

瀏覽器把「上次匯入的資料夾、快取的內容、樣式、最後看的模組、每一頁卡片的展開狀態、側欄展開了哪些資料夾、編輯器用哪種模式」都記在**這個 html 檔的路徑**底下。所以：

- 想同時管理 A、B 兩套筆記，把 `index.html` 各複製一份到 A 和 B 資料夾（要改名成 `A.html`、`B.html` 也行），各自匯入一次，之後各開各的、互不干擾。
- 記憶跟路徑綁在一起：把 html 改名或搬到別的地方，就等於一個新的頁面，要重新匯入一次（舊的記憶不會消失，只是不再對應）。
- 右上角「來源 ▾」選單裡有**「忘記匯入的內容，回到起點」**：清掉這個頁面的記憶，回到待匯入的畫面。只會清瀏覽器裡的東西，你的 .md 檔案一個字都不會動。
- 同一個選單也能隨時**重新匯入**（換一個資料夾、換一批檔案）或**重新載入**。

### 本機伺服器 `serve.py`

最省事的啟動方式：macOS 雙擊資料夾裡的 **`啟動筆記.command`**、Windows 雙擊 **`啟動筆記.bat`**，會開一個終端機視窗並自動打開瀏覽器；關掉視窗就停止。（macOS 第一次可能說「無法打開」——那是從 zip 解出來的檔案帶著「隔離」標記：對檔案按右鍵 → 打開 → 打開，之後就不會再問；見下面的疑難排解表。）手動的話：

```bash
cd 筆記資料夾
python3 serve.py              # 開 http://localhost:8765，會自動打開瀏覽器
python3 serve.py --port 9000  # 換埠
python3 serve.py ~/別的資料夾  # 指定資料夾
python3 serve.py --host 0.0.0.0   # 讓同一個 Wi‑Fi 的 iPad／手機連：http://電腦IP:8765
```

只用 Python 標準函式庫，不用安裝任何套件（macOS 內建 Python 3；Windows 到 python.org 裝一次）。它提供檔案清單、讀檔、寫檔、刪檔四個 API，任何瀏覽器都能看、能編輯、能貼圖、能改名與刪除。

`--host 0.0.0.0` 表示**區網裡的任何裝置都能讀寫這個資料夾**，沒有密碼。只在家裡或信任的網路用；公共 Wi‑Fi 不要開。

### 拖放／匯入檔案（唯讀）

把整個資料夾拖到視窗，或從選單「匯入檔案／匯入資料夾（唯讀）」。內容（含 20 MB 以內的圖片）會存進瀏覽器的快取，下次打開 `index.html` 直接顯示上次的內容，狀態列會標「快取」；檔案有更新要再匯入一次（直接再拖一次就會取代）。

### iPad／iPhone

四種路線，看你要什麼：

- **隨時隨地能看能改**：把筆記放上 GitHub Pages（見下一節），iPad 開公開網址、按「啟用編輯」輸入一次 token，之後就是完整的編輯器。可以「加入主畫面」。
- **在家編輯（不經過網路）**：電腦跑 `python3 serve.py --host 0.0.0.0`，iPad 的 Safari 開 `http://電腦IP:8765`。
- **單機閱讀**：電腦跑 `python3 build.py`，得到 `筆記模組-單檔.html`，AirDrop 到 iPad 用 Safari 打開（存進「檔案」後從「檔案」點開即可）。圖片已內嵌。
- **臨時看**：直接打開 `index.html`（可以放在 iCloud Drive），按「選擇檔案」從「檔案」App 多選 .md。

### GitHub Pages

1. 把整個資料夾變成一個 GitHub 倉庫推上去（公開或私有都行；私有倉庫的 Pages 需要付費方案）。
2. 倉庫 Settings → Pages → Source 選 **GitHub Actions**。
3. 附的 `.github/workflows/pages.yml` 會在每次 push 後執行 `build.py --manifest --inline`，產生 `modules.json`（含所有模組內容，網頁只需一次請求）並部署。
4. 網址是 `https://帳號.github.io/倉庫/`。（放進既有網站的子資料夾也可以——只要那個資料夾裡有 `index.html` 和 `modules.json`，而且**你的部署流程要在每次部署時重建 `modules.json`**（照 `pages.yml` 那樣執行 `build.py --manifest --inline`）——否則在網頁上直接編輯存的 .md 不會反映到網站。）

#### 在 iPad／手機上直接編輯（GitHub 直接存檔）

Pages 版預設唯讀，但按工具列的「**啟用編輯**」、輸入一次 GitHub token，之後這台裝置就能用**和電腦上完全一樣的編輯器**（直觀編輯、並排、貼圖、改名搬移、核取方塊……），每次存檔自動變成一個 commit 推回倉庫，公開網址約 1–2 分鐘後跟著更新。

申請 token（一次就好，在要編輯的那台裝置上做）：

1. 開 [github.com/settings/personal-access-tokens/new](https://github.com/settings/personal-access-tokens/new)（Fine-grained token）。
2. Repository access 選 **Only select repositories**，勾你放筆記的那個倉庫。
3. Permissions → Repository permissions → **Contents** 選 **Read and write**；設個到期日。
4. Generate，把整串貼進「啟用編輯」的框裡。

token 只存在那台裝置的瀏覽器裡（選單裡隨時可「停用直接編輯」清掉）。注意兩件事：存檔到公開網址真的更新有 1–2 分鐘的部署時間（你自己這台會立即顯示新內容）；翻卡片（標題／摘要／全文）在這個模式**不會** commit（不然讀個筆記就生一堆 commit），是記在裝置裡。

不想用 token 的話，工具列仍有「在 GitHub 編輯」：用 GitHub 的網頁編輯器改 Markdown 原文。

#### Mac 這邊：一鍵發佈（`發佈到GitHub.command`）

筆記的正本可以直接住在網站倉庫的子資料夾裡（例如 `wenjchao.github.io/notes/`）——**只有這一份**，Mac 和 iPad 改的都是它，不再有「正本＋副本」。Mac 上的發佈不用碰 git：雙擊筆記資料夾裡的 **`發佈到GitHub.command`**，它會依序——

1. 把這台 Mac 的修改做成一筆版本紀錄（commit）；
2. 抓 GitHub 上的修改（iPad／手機存的）並**合併**——不同檔案、甚至同一檔的不同段落都會自動合起來；同一段兩邊都改，保留 Mac 版（iPad 版還在 GitHub 歷史裡，撈得回來）；
3. 重建 `modules.json`，推送上去，約 1–2 分鐘後公開網址更新。

什麼時候雙擊：Mac 上改了一批想上線時，或想把 iPad 的修改拿下來時。連按兩次是安全的——內容沒變化就不會推送。筆記資料夾裡會有一個隱藏的 `.git` 資料夾（版本紀錄本體），不要動它。完整規則（合併語意、衝突原則、部署端的要求）見 說明/規格書 的「同步架構」一章。

不用 GitHub 也可以：在資料夾裡跑 `python3 build.py --manifest`，把整個資料夾丟到任何靜態空間（Netlify、Cloudflare Pages、公司內網）。

### 用雲端硬碟同步資料夾

把筆記資料夾放在 iCloud Drive、Dropbox、OneDrive 裡，各台電腦都用「匯入資料夾」讀同一份，是最省事的跨裝置方式。注意：

- iCloud 的「最佳化儲存空間」可能把檔案變成雲端佔位檔，檢視器會讀不到內容；在 Finder 對資料夾按右鍵「立即下載」，或關掉最佳化。
- 兩台電腦同時編輯同一個檔案會產生衝突副本（`xxx (衝突).md`），衝突副本也會被當成模組顯示出來，看到就手動合併。
- 同步軟體寫檔可能分兩步，檢視器偶爾會先讀到半截內容，下一輪（2 秒後）就會正確。

### 快取與隱私

- 「匯入資料夾」與「拖放」會把內容快取在**這台電腦的這個瀏覽器**裡（IndexedDB；Safari 的 file:// 不給用 IndexedDB 時改存 localStorage，只存文字、上限約 4 MB），方便下次秒開；不會上傳到任何地方。清瀏覽器資料、或按選單裡的「忘記」就會清掉。
- 樣式、深淺色、最後看的模組、每頁的展開狀態、側欄樹的展開、編輯模式、編輯中的草稿、GitHub 直接編輯的 token 存在 localStorage，同樣依 html 路徑分開。展開狀態：來源可以寫入時**不用記憶**——你切換卡片的結果直接寫回 .md（連結的模式字會改），檔案就是真相；只有唯讀來源（單一檔案、GitHub Pages、拖放匯入）才記在瀏覽器裡，而且只記你動過的卡片，工具列「回到預設」可以清掉那一頁的記憶。
- 檢視器完全離線可用；唯一的對外連線是載入 Google Fonts（沒網路會自動用系統字體）。
