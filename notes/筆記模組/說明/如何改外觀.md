# 如何改外觀

## 摘要
1. 五種樣式：墨線（預設）、便條、大綱、手帳、標籤；右上角選單切換，◐ 切深淺色。
2. 卡片左側粗線的顏色＝巢狀層級。
3. 要改顏色、字體或新增樣式，改 CSS token 就行。

## 內文
### 五種樣式

| 名稱 | 特徵 | 適合 |
|---|---|---|
| **墨線 ink**（預設） | 白卡片、細外框、4px 左線依層級換色、明體大標題、點陣紙底 | 一般閱讀 |
| **便條 card** | 暖色紙張、6px 色條像索引卡標籤、黑體粗標題、底線式切換鈕 | 紙感 |
| **大綱 outline** | 無框只有線、滑過那條才變色 | 長文、純文字派 |
| **手帳 sketch** | 2px 墨線框、8px 墨色粗線、點陣紙、印章式按鈕、紅筆色連結 | 手繪草圖 |
| **標籤 tab** | 標題列依層級上色（藍／青／琥珀／紫），像彩色檔案夾 | 層級多、要一眼分辨 |

共同點：被連結的模組標題一律黑體粗體；筆記區滿版。樣式選擇記在這台瀏覽器（localStorage），◐ 沒動過就跟系統的深淺色。
想改預設樣式或藏起選單：`index.html` 最上面 `CONFIG` 的 `defaultStyle`、`showStylePicker`（下一節）。

### 鎖定或隱藏選單

`index.html` 最上面的 `CONFIG`：

```js
defaultStyle: 'ink',        // ink / card / outline / sketch / tab
showStylePicker: true,      // false＝藏起樣式選單
```

### 自訂顏色與字體

樣式＝CSS token，都在 `index.html` 的 `<style>` 最上面（或 `開發/src/style.css`）。常用：

| token | 作用 |
|---|---|
| `--rail-w` | 左側粗線寬度 |
| `--rail-1` … `--rail-4` | 第 1～4 層線色（第 5 層回到 1） |
| `--rail-1-soft` … | 對應淡色（摘要邊線、標籤色帶、群組縮排的線） |
| `--rail-root` | 根模組左線 |
| `--card-radius`、`--card-bw`、`--card-border` | 卡片圓角、框粗、框色 |
| `--paper`、`--dot` | 頁底色、點陣紙的點 |
| `--card`、`--ink`、`--ink-2`、`--accent` | 卡片底、文字、次要文字、強調色 |
| `--font-title`、`--font-body`、`--font-mono` | 大標題、內文（卡片標題同，粗體 700）、等寬 |

筆記區寬度無上限；要限制：`#main > .page { max-width: 80ch; margin: 0 auto; }`。

線更粗、全部同色：

```css
:root { --rail-w: 6px; --rail-2: var(--rail-1); --rail-3: var(--rail-1); --rail-4: var(--rail-1); }
```

深色 token 在 `@media (prefers-color-scheme: dark)` 與 `:root[data-theme="dark"]` 兩處（內容相同：一給系統深色、一給手動切換）。

### 新增第六種樣式

1. CSS「五種樣式」區塊整組複製（如 `:root[data-style="tab"]` → `:root[data-style="mine"]`），改 token。
2. `CONFIG.styles` 加 `mine: '我的樣式'`。
3. 重新整理。

字體預設載 Google Fonts（Noto Sans TC／Noto Serif TC），離線自動退系統字體；不想連外→刪 `<head>` 裡三行 `<link … fonts.googleapis.com>`。
