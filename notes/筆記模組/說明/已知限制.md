# 已知限制

## 摘要
目前還沒有的功能、各平台的限制，以及實際使用時最可能踩到的坑與對策。看完這頁再決定要不要把重要筆記搬過來。

## 內文
### 還沒有的功能

| 沒有的 | 目前怎麼辦 | 難度 |
|---|---|---|
| 搬移時圖片不跟著搬 | 圖片留在原資料夾，連結用 `../` 指回去；想一起搬就手動搬資料夾 | 低 |
| 搜尋的相關度排序、模糊比對 | 現在是子字串比對、依路徑排序；多個字以空白分隔全部要出現 | 中 |
| 在畫面上直接編輯標籤 | 切到原始碼模式改 frontmatter 的 `tags:` | 低 |
| 模組歷史版本、復原 | 用 git 或 Time Machine（編輯到一半的草稿會自動留在瀏覽器裡） | 不做（交給 git） |
| 多人同時編輯、帳號、權限 | 不做；用 git 分工 | 不做 |
| 匯出 PDF／Word | 瀏覽器「列印」→ 存成 PDF（樣式已調過） | 低 |
| 數學式的完整 LaTeX | 用 KaTeX，涵蓋常用語法；不支援 TikZ、部分套件指令（會以原文顯示並標色） | 不做 |
| 關係圖（graph view） | 每頁底部有「被引用於」 | 中 |
| 手機上的舒適編輯 | 直觀編輯器與工具列在手機上可用；鍵盤彈出時畫面較擠 | 低 |
| 直觀編輯器的極限 | 靠瀏覽器內建的 contenteditable；複雜的巢狀表格、HTML 區塊請用原始碼模式；存檔會把檔案整理成正式格式（畫面相同、逐字可能不同） | 中 |
| 並排模式不是逐字雙向綁定 | 哪邊在打字就以哪邊為準，停 0.3 秒才同步到另一邊；很長的模組每次同步整份重畫，會有一點延遲；兩邊的捲動只是按比例跟，不是逐段對齊 | 低 |
| 切換卡片模式會改檔 | 來源可寫入時，每次按 標題／摘要／全文 都會改寫父模組 .md 裡那個連結（約 0.6 秒後存檔）；用 git 的人會看到這些小改動。不想要就用「全部展開／收合」（不寫檔），或把來源改成唯讀 | 低 |
| 拖拉排序、看板 | 順序就是檔案裡的順序 | 不做 |

### 各平台的限制

- **Safari／Firefox 不能直接開資料夾**（沒有 File System Access API）。用 `serve.py` 或拖放。
- **Safari 的清單號碼**：Safari 會把清單項目的號碼畫進項目裡第一個方塊——所以清單裡的卡片（扁平或一般）改由程式自己畫號碼與圓點；若你手寫 HTML 用了 `<ol type="a">`、`reversed`，那些卡片的號碼會照十進位顯示。
- **iPad 無法寫回檔案**，除非透過伺服器（同一 Wi‑Fi 的電腦，或自己架）。
- **Chrome 每次重開瀏覽器要重新授權一次資料夾**（一個按鍵）。在那之前頁面先顯示上次的快取（唯讀）。部分版本的 Chrome 在權限提示裡有「每次造訪都允許」。
- **記憶跟 html 的路徑綁定**：把 `index.html` 改名或搬家，就要重新匯入一次。Safari 在 file:// 下不給用 IndexedDB，改用 localStorage 時只能記文字（不含圖片）且上限約 4 MB。
- **file:// 直接開 `index.html`** 時，瀏覽器不允許網頁自己讀旁邊的檔案，所以一定要經過「匯入資料夾」或拖放；這是瀏覽器的安全規則，不是 bug。
- 單一檔案版（`build.py`）是**快照**，原檔更新後要重新打包。
- **GitHub Pages 版的直接編輯**：每次存檔＝一個 commit、觸發一次部署；公開網址約 1–2 分鐘後才更新（自己這台立即）；翻卡片不寫回（記在裝置）；token 存在該裝置的瀏覽器裡，離手的裝置記得「停用直接編輯」。
- Google Fonts 需要網路；離線時自動改用系統字體，版面會略有不同。數學字型已內嵌，離線也正確（代價是 index.html 約 800 KB）。

### 命名與連結的坑

- **同名檔案**在不同資料夾：`[[檔名]]` 會取路徑排序最前面的那個，另一個永遠連不到。請避免同名，或寫完整路徑。
- **在檔案總管改名不連動**：用檢視器工具列的「改名／搬移」才會一起改連結；在 Finder 改的，事後用「壞連結」報告修。
- **檔名含 `|`、`[`、`]`、`#`** 會讓連結解析錯誤。
- macOS 檔名用 NFD 編碼、其他系統用 NFC，程式已統一成 NFC；但若你在別的工具看到「看起來一樣卻連不到」，多半是這個，重新輸入檔名即可。
- 在**表格**裡寫 `[[x|摘要]]` 要寫成 `[[x\|摘要]]`。
- 檔案開頭若剛好是一條 `---` 水平線（不是 frontmatter），會被誤判成 frontmatter；開頭先放標題就不會。
- `## 摘要` 出現在 `## 內文` **之後**會被當成普通標題，不是摘要。

### 同步與多機

- iCloud「最佳化儲存空間」的佔位檔讀不到內容 → 關掉最佳化或「立即下載」該資料夾。
- 雲端硬碟的衝突副本（`xxx (衝突).md`、`xxx (conflicted copy).md`）會變成多一個模組；手動合併後刪掉。
- 同步軟體分兩步寫檔時，偶爾會先看到半截內容，2 秒後自動修正。
- 內建編輯器與外部編輯器同時改同一個檔：後存的贏。編輯器會在偵測到外部修改時提示，但不會幫你合併。

### 效能

- 每 2 秒掃一次資料夾（匯入資料夾／伺服器模式）。幾百個檔案沒問題；上千個檔案、或放在很慢的網路磁碟時，可把 `CONFIG.pollMs` 調大（例如 10000），或把不需要的子資料夾放 `.noteignore`。
- 一頁「全部展開」會渲染所有巢狀內容；極深極大的樹會變慢，循環引用與 10 層深度上限能擋住無限展開，但不擋「很大」。
- 單一檔案版內嵌圖片：超過十幾 MB 的 HTML 在 iPad Safari 會明顯變慢。

### 安全

- `serve.py --host 0.0.0.0` 對區網開放**無密碼的讀寫**權限，只在信任的網路用。`127.0.0.1`（預設）只有本機能連。
- 檢視器會把 Markdown 裡的 HTML 原樣渲染（方便你放 `<details>`、`<kbd>` 之類）。這代表**打開別人給的筆記資料夾，等於執行對方寫的 HTML／JavaScript**；只載入你信任的內容。需要嚴格一點可在 `MD.render()` 後接一個 sanitizer（例如 DOMPurify）。
- GitHub Pages 公開倉庫 = 全世界可讀；私有倉庫的 Pages 需要 GitHub 付費方案。

### 「應該」要注意但容易忘的

- 寫完新模組要**存檔**（內建編輯器 ⌘/Ctrl + S），頁面上的預覽不等於已存檔。
- 快取模式（狀態列標「快取」）看到的是**上次**的內容。
- 刪檔案不會問你「有 N 個模組連到它」；刪之前先到該模組底部看「被引用於」。
