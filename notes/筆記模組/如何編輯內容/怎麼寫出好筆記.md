# 怎麼寫出好筆記

## 內文

**字數是成本、理解是收益。** 字越多，每個字換到的新資訊越少——所以「寫多少」是在曲線上挑位置：摘要與內文是同一條曲線上的兩個甜蜜點。

註：標題本身也是同一條曲線上的第三個甜蜜點。收合時讀者只看得到標題，所以標題本身就要是資訊——可以寫成結論或問題（ex:「為什麼剩下單心室就要改成單循環？」）

### 怎麼寫出好摘要

摘要＝「字極少、資訊還很多」的那個點：**用 10% 的文字傳遞 90% 的資訊**，不點開內文就知道全貌。例：咳嗽藥的摘要——「分成止咳（opioid 為主）、氣管擴張（常作為止咳藥的輔助）、化痰（讓痰不黏）三大類。注意：兩種 opioid 不要同時併用」——一句話，分幾類、每一類是什麼、最重要的禁忌，都在了。

1. 拿掉也不會少懂的句子，刪；不是移去內文。
2. 裝不進 10% 的（劑量、例外、原因），是內文的資訊。
3. 內容太少、摘要會和內文講一樣的話：不寫摘要，整份放內文，連結用 `|全文`。
4. 摘要不一定是一段話：**分點＋箭頭串因果**常常更好掃——一句核心（粗體）→ 逐點列（有先後用編號、並列用項目）→ 用 `→` 串起因果與對應。

### 怎麼寫出好內文

內文＝另一個甜蜜點：資訊接近全部，但每一句仍然要划算——可以長，不可以稀。
寫作的對象是人：人不讀冗長的、記不住生澀的、會被錯的直覺帶偏。所以——

1. 一句只講一件事：連環長句要讀兩次——資訊沒變，成本翻倍。
2. 白話、用具體動作講：生澀的句子有資訊也傳不出去。例：「凹槽可能抓住被排開的非目標 DNA 股」→「凹槽可能抓錯 DNA」。
3. 講機制，少背規則：一句機制頂好幾條規則。例：記住「MTX 有肺毒性」，就不用背「interstitial lung disease 不可用 MTX」。
4. 舉例和比喻用同一個標準：更少的字、更深的理解，做得到就留；純裝飾的刪；會建立錯誤直覺的（「MAC 像送貨到大門」讓人以為 MAC 能跨網路）比不寫更糟。
5. 一個東西一個名字：一下「群組縮排」、一下「group」，讀者得自己對照，白花成本。
6. 要比較就用表格：一張表講完的事，散在幾段裡就是加字不加資訊。
7. 這篇用不到的深度、或會被多處引用的內容，抽成獨立模組——模組系統就是為此存在。注意**嵌入只能嵌整個檔、不能嵌某一節**：要被別頁引用／嵌入的東西，本身就得是一個模組（一份正本、到處嵌）。

### 用字用詞用句

白話是把事講清楚，不是幼稚的講話語氣。摘要、內文、引言句、標題都一樣：

- 主題標籤破題（用冒號） → 符號推進進程與因果（用 →） → 括號補充機制細節。
- 絕對禁用擬人口語（如：打架、記住、壞掉） → 全面使用醫學學術動詞（如：清除、分泌、引發、調控）。
- 刪除所有冗餘連接詞（因為、接著） → 建立清晰對比句型（例：反應太強 → ...；反應太弱 → ...）。
- 禁止長句：一行只講一件事
  - 「標籤：A；B；C」→ 標籤一行、A／B／C 各一行
  - 因果鏈可以用 → 串在同一行；換了主題就換行
  - 多用項目符號與編號，不用分號、破折號把幾件事縫成一句

你不要給我 「三條線」、「兩個重點」、「有三種」、「分兩批」這種智障用詞。
以下是我非常厭惡的糟糕範例：
1. 「兩層：先天（快、廣、無記憶）擋前線；後天（慢、專一、有記憶）精準清除，再分體液（B／抗體）與細胞（T）。  失衡兩個方向：太強 → 自體免疫、過敏；太弱 → 免疫缺損 → 感染。  治療＝反向調控：壓下（免疫抑制）／放出（腫瘤免疫）。」

2. 「先天免疫第一時間就到：快、不挑對象、打完不記得。後天免疫要幾天才到：只認特定敵人、打過一次就記住——B 細胞放抗體出去打、T 細胞自己上場；疫苗就是讓它先預習。
壞掉有兩種：太強就打自己（自體免疫）或反應過頭（過敏）；太弱就擋不住病原（免疫缺損 → 感染）。
治療是往反方向推：太強就壓（免疫抑制劑；移植抗排斥也是同一招）、要它去打腫瘤就放（腫瘤免疫治療）。」、
3. 「病原進來，免疫系統分兩批出手。先天免疫馬上就到，見誰擋誰，打完不記得；後天免疫要幾天才動起來，只打特定目標，但打過一次就記住，疫苗用的就是這個記性。後天免疫分兩路：B 細胞派抗體出去打，T 細胞自己上場。 這套系統會出兩種錯。太強，會攻擊自己的組織（自體免疫），或對無害的東西反應過頭（過敏）；太弱，擋不住病原，缺哪一段免疫、就來哪一類病原（免疫缺損）。 治療就是往反方向調。太強就用免疫抑制劑壓下去，移植抗排斥也是同一招；要它去打腫瘤就把它放出來，鬆開煞車（免疫檢查點抑制劑）或直接改造 T 細胞（CAR-T）。放出來的免疫也會誤傷正常組織或反應過猛，那就是免疫治療的副作用。」 

我喜歡的是：
「防禦機制：先天免疫第一時間擋下病原 → 後天免疫接手精準清除（B 細胞分泌抗體、T 細胞直接攻擊） → 留下記憶。
免疫失衡：反應太強 → 引發過敏、自體免疫與移植排斥；反應太弱 → 導致免疫缺損與感染。
人為調控：太強就壓下 → 使用免疫抑制劑；對抗腫瘤就放出 → 啟動免疫活化療法；利用記憶預防 → 施打疫苗。」

### 寫作與分級格式

1. 一切的格式都是為了人的閱讀與記憶服務。善用列點、項目、小標題、模組可以把複雜的內容分組成容易理解與記憶的單位
2. 單一文章內列點不要超過三層。太多層的話
   1. 實際內容不多則應該扁平化，不要用太多層包裝
   2. 實際內容很多則應該善用模組，把內容完整的文字打包成獨立的子模組
3. 單一文章內不要超過 1500 字。太多字的話應該精簡或是把內容完整的文字打包成獨立的子模組
4. 若是字數太少、內容不夠獨立且不會被別處引用，則可以不切（模組往回併）。幾行字撐不起一個模組，切了只是把「一眼看完」變成「多點一次」。
5. 粗體是給**重點**用的、不是裝飾：粗的是**總稱**（胞內菌、莢膜菌、catalase(+) 菌）或**決定性關聯**（C5–9 → Neisseria）。全粗＝沒有重點；平行列舉一串、沒有誰特別跳出來時，就不硬挑一個粗。

### 卡片還是膠囊（句中）

連結有兩種長相，看**周圍的字有沒有意義**來選。一句話判準：**把連結拿掉，剩下的話還有意義 → 膠囊；只剩「相關：」這種空殼 → 卡片。**

1. 膠囊：句子本身在講一件事、連結只是順帶帶到。寫法是連結放**行內**（前面有字）。例：「anti-postsynaptic ACh receptors（Type II）」——句子在講機轉，Type II 順帶連到 Hypersensitivity。
2. 卡片：連結本身就是重點——目錄、「相關：」這類列舉，周圍的字只是指標。寫法是連結**獨佔一行、前後空行**。一頁的功能若是目錄，就整排卡片。
3. 反例：「相關：肉芽腫 ⟨膠囊⟩」——「相關：肉芽腫」和連結重複、沒有額外意義，該改成卡片：「相關：」一行、連結自己一行。
