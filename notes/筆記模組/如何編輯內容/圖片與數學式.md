# 圖片與數學式

## 內文
### 圖片

1. 語法：`![說明](圖片/檔名.png)`，路徑相對於這個 .md（上一層寫 `../圖片/…`）。
2. 編輯器裡直接貼上或拖入，會自動存進 `圖片/`。
3. 支援 png、jpg、gif、webp、svg。
4. 顯示時預設最多佔 1/3 寬；按一下圖片放大到全寬、再按縮回（不會改到檔案）。
5. 圖片不是模組：不進側欄、不進壞連結報告；路徑錯就是破圖。

### 數學式

1. 行內 `$E=mc^2$`，獨立一段 `$$…$$`（LaTeX，KaTeX 渲染）。
2. 化學式與反應式（mhchem）：`$\ce{Na+}$`、`$\ce{2H2 + O2 -> 2H2O}$`；單位 `$\pu{123 kJ/mol}$`。
3. `$` 要緊貼內容：`$ x $` 不會渲染；「$5 和 $10」不會誤判。被誤判就寫 `\$`。
4. 不支援的指令以紅字原樣顯示，不會弄壞頁面。

### 表格

1. 一般 GFM 表格；儲存格裡的 `|` 要寫 `\|`。
2. 格子裡要換行寫 `<br>`（直觀編輯在格子裡按 Enter 就是換行）；真正的換行會被當成新的一列。
3. 合併儲存格：格子裡只寫 `^^`＝併入上面那格、只寫 `<<`＝併入左邊那格；要照字面顯示就寫 `` `^^` ``。
4. 欄不換行：表頭格開頭寫 `==`（如 `| ==大類 |`）——該欄整欄不換行。預設表格自動換行、不橫向捲動；只有不換行的欄放不下時才會出現橫向捲動。
5. 例（「周邊問題」直向合併成一格跨兩列、大類欄不換行、格內用 `<br>` 換行）：

| ==大類 | 子分類 |
|---|---|
| 周邊問題 | 被破壞<br>（免疫、機械） |
| ^^ | 流掉 |
