# 外觀樣式

## 摘要
右上角選單有五種樣式（墨線、便條、大綱、手帳、標籤），都支援深淺色；共同點是卡片左側有一條粗線，線的粗細與顏色標示巢狀層級；被連結的模組標題（卡片標題、行內晶片）一律用黑體粗體；筆記區永遠滿版，手機隨螢幕收窄。要改顏色、字體或新增樣式，改 CSS token 即可。

## 內文
### 五種樣式

| 名稱 | 特徵 | 適合 |
|---|---|---|
| **墨線 ink**（預設） | 白卡片、細外框、4px 左側粗線依層級換色（藍→青→琥珀→紫）、明體大標題、點陣紙底 | 一般閱讀 |
| **便條 card** | 暖色紙張、6px 色條像索引卡的分類標籤、黑體粗標題、底線式切換鈕 | 喜歡紙感 |
| **大綱 outline** | 沒有外框只有一條線、滑鼠移過的那條線才變色、最安靜 | 長文、純文字派 |
| **手帳 sketch** | 2px 墨線外框、8px 墨色粗線、看得見的點陣紙、印章式按鈕、紅筆色連結 | 最接近手繪草圖 |
| **標籤 tab** | 卡片標題列是依層級上色的色帶（藍／青／琥珀／紫），像彩色檔案夾 | 層級多、要一眼分辨 |

選擇會記在這台瀏覽器的 localStorage。右上角 ◐ 切換深淺色；沒動過的話跟著系統設定。

### 鎖定或隱藏選單

`index.html` 最上面的 `CONFIG`：

```js
defaultStyle: 'ink',        // 預設樣式：ink / card / outline / sketch / tab
showStylePicker: true,      // false 就把右上角的樣式選單藏起來
```

### 自訂顏色與字體

樣式是用 CSS 自訂屬性（token）堆出來的，都在 `index.html` 的 `<style>` 最上面（或 `開發/src/style.css`）。常用的：

| token | 作用 |
|---|---|
| `--rail-w` | 卡片左側粗線的寬度 |
| `--rail-1` … `--rail-4` | 第 1～4 層的粗線顏色（第 5 層回到 1） |
| `--rail-1-soft` … | 對應的淡色（摘要的邊線、標籤樣式的色帶） |
| `--rail-root` | 整頁根模組左側的粗線 |
| `--card-radius`、`--card-bw`、`--card-border` | 卡片圓角、外框粗細、外框顏色 |
| `--paper`、`--dot` | 頁面底色、點陣紙的點 |
| `--card`、`--ink`、`--ink-2`、`--accent` | 卡片底、文字、次要文字、強調色 |
| `--font-title`、`--font-body`、`--font-mono` | 整頁大標題、內文（卡片標題與晶片也用這個，粗體 700）、等寬字體 |

筆記區的寬度沒有上限（使用者的決定：電腦與 iPad 要寬），想限制可以在 CSS 加一行 `#main > .page { max-width: 80ch; margin: 0 auto; }`。

例如想讓預設樣式的粗線更粗、全部同一個顏色：

```css
:root { --rail-w: 6px; --rail-2: var(--rail-1); --rail-3: var(--rail-1); --rail-4: var(--rail-1); }
```

深色模式的 token 在 `@media (prefers-color-scheme: dark)` 與 `:root[data-theme="dark"]` 兩個區塊（內容相同，一個給系統深色、一個給手動切換）。

### 新增第六種樣式

1. 在 CSS 的「五種樣式」區塊複製一段，例如把 `:root[data-style="tab"]` 整組複製成 `:root[data-style="mine"]`，改 token。
2. 在 `CONFIG.styles` 加一行 `mine: '我的樣式'`。
3. 重新整理，選單就多一個。

字體：預設從 Google Fonts 載入 Noto Sans TC／Noto Serif TC，沒網路時自動退回系統字體（蘋方、微軟正黑、宋體）。不想連外就把 `<head>` 裡的三行 `<link ... fonts.googleapis.com>` 刪掉。
