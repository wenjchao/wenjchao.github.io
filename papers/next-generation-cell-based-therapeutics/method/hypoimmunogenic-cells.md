# 低免疫原性「通用細胞」的多重編輯建構

1. 引用自哪篇 paper: next-generation-cell-based-therapeutics
2. Outline (任務主線): 低免疫原性「通用細胞」的多重編輯建構
3. Method: 
   這一節處理的是異體細胞最根本的死因：被病人的免疫系統認出來清掉。作者的對策是兩手齊下——把會被認出來的東西刪掉，同時把叫免疫細胞收手的東西大量掛上去。刪除清單有兩個，B2M 與 CIITA。為什麼是這兩個、而不是直接去刪 HLA 本身？因為 HLA 分子不是一個蛋白單獨上台的，而且 HLA 基因數量多、版本又極度多變，一個一個刪不切實際，所以作者改打共同的必要環節。HLA class I 要組裝並送上細胞表面，少不了 β2-microglobulin 這個共同的搭檔零件，B2M 沒了，整套 class I 就上不了台面；HLA class II 的關卡在另一層，CIITA 是啟動 class II 那一整組基因所必需的調控因子，把它拿掉，class II 就整組不表現。加上去的清單則有三個，全部是負向調控子，而且一個對付一種免疫細胞：PDL1 抑制 T 細胞，HLA-G 抑制自然殺手細胞，CD47 對巨噬細胞發出「別吃我」的訊號。做出來的就是本文所稱的低免疫原性細胞，或者叫通用細胞（REF.89, Deuse, Nat Biotechnol 2019；REF.159, Han, PNAS 2019）。
   光把身分證刪掉並不安全，反而會踩到第二道關卡，因為三道防線的判斷邏輯根本不一樣。自然殺手細胞的邏輯和 T 細胞相反：T 細胞是看身分證上寫的內容對不對，自然殺手細胞則是查「你到底有沒有身分證」，發現一顆細胞把 HLA 藏起來，它就把這顆細胞當成可疑對象處理——這套邏輯叫 missing-self。巨噬細胞又是另一回事，它根本不查身分證，靠的是表面訊號決定要不要把東西整個吞掉。三套人馬是並行的，不是接力的，所以只要漏掉一道，前面的努力就白費：只刪 HLA 而不補 HLA-G，自然殺手細胞會因為 missing-self 反而更積極地動手；補了前兩道卻不管 CD47，巨噬細胞照樣把細胞吞掉。這也解釋了為什麼加上去的是這三個而不是別的——它不是「愈多愈好」的堆疊，而是三道關卡各配一把鑰匙的最小完整集合。
   作者也列出一條不必把 HLA 全部藏起來的替代路線，它正是為了繞開 missing-self 這個陷阱設計的。每個人身上的 HLA 都有兩套版本，差異就是排斥的來源。這條路線不全刪，而是只針對特定版本動刀，把兩套修成看起來一模一樣，這種狀態叫偽同型合子 (pseudo-homozygosity)（REF.88, Xu, Cell Stem Cell 2019）。好處是身分證還在，自然殺手細胞查得到、不會觸發 missing-self，同時保留下來的那套組合夠通用，T 細胞也不把它當外來者。本文另外指出，只做 B2M 敲除加上 CD47 過表現這個簡化組合，就已經能大幅降低 iPSC 的免疫原性（REF.89）。
   整套策略還有一個常被略過、實際上是關鍵的決定：這些手術全部在細胞還處在「什麼都能變成」的階段時就做完。誘導多能幹細胞 (induced pluripotent stem cell, iPSC) 是一種能長成任何細胞型別的萬用起始細胞，作者是在它還沒被推去變成心肌細胞或胰島細胞之前，就把五個基因座全部改好。為什麼堅持這個時序？第一是同質性：先編輯好，之後由這一批細胞分化出來的後代全部帶著同一組改造，得到的是性質一致的細胞族群，製造才有辦法規模化、成本才壓得下來；若等分化完再逐批動手，每一批的編輯效率與結果都會有落差，等於把「批次間差異大」這個老毛病又請回來。第二是耐受度：多能細胞本身對重複而且大規模的基因操作比較耐得住，而這一節要動的手術一共是兩刪三加、五個基因座，換成已經分化的細胞不見得撐得過去。
   改完之後最關鍵的驗證是：這批細胞還能不能用。答案是可以——經過改造的 iPSC 保有多能性，能分化成血管內壁的內皮細胞、心肌細胞，甚至長成胰島類器官這種在培養皿裡自己組織起來的迷你器官（REF.89, 160, 161）。如果改造把多能性弄壞了，前面所有的免疫隱形都沒有意義，因為做不出真正要拿去治病的那種細胞。分化這一關過了，接著才輪到免疫這一關：在體外以及植入人源化小鼠——移植了人類免疫系統、免疫功能健全的小鼠——體內，這些細胞都沒有誘發免疫反應。但作者把話說得很直白，它們在人體中能不能真的逃過排斥，原文寫的是「remains to be established」，也就是還沒有被證明。目前離臨床最近的是胰島移植領域，已有臨床試驗規劃或進行中（REF.162）；iPSC 現貨產品在實體瘤與血液惡性腫瘤的試驗則見 NCT03841110 與 NCT04023071。
4. 工具與材料: 
   - **iPSC（誘導多能幹細胞）**: 能長成任何細胞型別的萬用起始細胞，是這套通用細胞底盤的原料。
   - **B2M（β2-microglobulin）**: HLA class I 組裝上台所必需的共同搭檔零件；刪掉它，class I 整套消失。
   - **CIITA**: 啟動 HLA class II 那一整組基因所必需的調控因子；刪掉它，class II 整組不表現。
   - **PDL1**: 過表現在細胞表面的負向調控子，作用是讓 T 細胞收手。
   - **HLA-G**: 過表現的負向調控子，用來安撫因 missing-self 而被觸發的自然殺手細胞。
   - **CD47**: 對巨噬細胞發出「別吃我」訊號的表面蛋白，擋下不查身分證、直接吞噬的那一道。
   - **missing-self**: 自然殺手細胞的判斷邏輯：查的不是身分證內容，而是有沒有身分證。
   - **等位基因專一性編輯 / 偽同型合子**: 只針對特定 HLA 版本動刀，把兩套修成一模一樣，保留身分證又不觸發排斥的折衷解。
   - **人源化小鼠**: 移植了人類免疫系統、免疫功能健全的小鼠，用來在動物體內測試免疫隱形效果。
   - **胰島類器官**: 在培養皿裡自己組織起來的迷你胰島，用來證明改造後的 iPSC 仍能長出複雜結構。
5. 與此篇文章的關係: 
   在《Engineering the next generation of cell-based therapeutics》這篇文章中，作者的大目標是讓現貨型的異體細胞產品真的成立。低免疫原性通用細胞的多重編輯解決的是移植細胞被 T 細胞、自然殺手細胞與巨噬細胞三路清除的瓶頸，做法是刪掉 B2M 與 CIITA、再補上三個負向調控子。它吃進尚未分化的 iPSC，產出能再分化成內皮細胞、心肌細胞與胰島類器官的通用底盤。
