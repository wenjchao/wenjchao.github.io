# 編輯結果的基因毒性、脫靶與免疫原性評估框架

1. 引用自哪篇 paper: next-generation-cell-based-therapeutics
2. Outline (任務主線): 編輯結果的基因毒性、脫靶與免疫原性評估框架
3. Method: 
   先把要查的東西分類。這套框架針對的是四類彼此獨立的傷害。第一類是結構變異：Cas9 造成雙股斷裂後，斷點附近可能出現非預期的大片段刪除與複雜重排，這已經在小鼠胚胎幹細胞、造血前驅細胞與人類細胞株中被觀察到，本文的措辭是，若未經妥善評估與控制，可能驅動危險的病理 (REF.69, Kosicki, Nat Biotechnol 36, 765)。第二類是 DNA 損傷反應，具體要檢測的是 p53 通路有沒有被活化；p53 是細胞內的損傷警報總開關，偵測到 DNA 斷裂就被叫醒，決定要停下來修、還是乾脆讓細胞自殺，而在永生化的人類視網膜色素上皮細胞中，CRISPR–Cas9 編輯已被觀察到誘發 p53 介導的損傷反應 (REF.70, Haapaniemi, Nat Med 24, 927)。第三類是脫靶，也就是剪刀切到不該切的位置。第四類是免疫，包括病患對剪刀蛋白本身的既往免疫。這四類的共通點是：它們全都可能在編輯成功率很漂亮的同時默默發生。
   第二類傷害還有更麻煩的一層，因為警報本身會篩選細胞。單純讓細胞表現 Cas9 這件事，就與多種人類癌細胞株中 p53 失活突變的富集相關 (REF.70, 82)。機制很直白：p53 正常的細胞被編輯時會拉警報，停下來或死掉；p53 已經壞掉的細胞感覺不到警報，照常增生。於是編輯與擴增這個流程本身就成了一道選擇壓力，把 p53 缺陷的細胞一步步篩上來——而那正是最不希望留在最終產品裡的那一種細胞。所以這一項不能只查「有沒有活化 p53」，還得查「產物裡有沒有被富集出 p53 缺陷的族群」。
   第三類的脫靶要怎麼判，關鍵在於不能只看一個數字。高保真變體 SpCas9-HF1 (REF.257) 與 eSpCas9 (REF.258) 的評估基準寫得很清楚：要改善全基因體的標的專一性，同時維持高的標的位點活性 (on-target activity)。為什麼一定要綁在一起？因為把剪刀改鈍就能讓脫靶數字變漂亮——切哪裡都切不動，當然沒有脫靶，但也沒有療效，所以這兩個數字必須成對報告。不動任何一個鹼基的表觀基因體編輯也不能免驗，只是它換掉的是另一種風險。本文明確指出，dCas 型表觀編輯的專一性遠高於那些會全域擾動人類表觀基因體的小分子，但對它的穩定性與專一性做細緻分析，仍是調校療效、耐久性與藥效時間曲線 (PK/PD) 的前提。白話說，表觀編輯改的是可逆的調節狀態，所以問題不只是有沒有改到別的位置，還有改了之後撐多久——它自己改回去的速度，直接決定療效能維持多久。
   第四類的免疫則是唯一一項與剪刀切不切無關的風險。Cas 蛋白來自細菌與古菌，對人體來說是外來蛋白，而且不少人因為過去的自然暴露，身上已經帶著針對它的獲得性免疫 (REF.80, 81)。這件事的後果不是編輯效率變差，而是編輯過的細胞進到體內後被清掉，或者引發發炎反應。要注意的是換工具並不能免掉這一項：改用鹼基編輯雖然不再製造雙股斷裂，蛋白骨架仍然來自細菌，風險原封不動；表觀基因體編輯所掛的效應域若是病毒或合成來源，長期表現同樣會被免疫系統盯上。
   四張檢查表查完之後，結果會反過來決定產線怎麼蓋。最有效的閃法是把細胞取出體外編輯，接著篩選與挑選，只把驗收合格的細胞群送回病人身上，上面那些問題大多可以被擋在體外；代價是成本高且不易規模化——每個病人都要跑一次完整的編輯、篩選與品管流程，這正好撞上細胞療法「可規模化製造」那道大挑戰。這些項目也不只是學術上的好習慣：FDA 已就基因編輯納入人類基因治療產品發布指引 (https://www.fda.gov/media/156894/download)，本文把它列為評估編輯效率、預存免疫與核酸酶作用機制的框架依據，意味著送審時會被逐項追問。沒有這種共同基準時，每家報自己的數字、用自己的指標，跨產品之間根本無從比較安全性。
4. 工具與材料: 
   - **結構變異（大片段刪除與複雜重排）**: 雙股斷裂修復後在斷點附近出現的非預期大範圍改動，已在小鼠胚胎幹細胞、造血前驅細胞與人類細胞株中觀察到 (REF.69)。
   - **DNA 損傷反應 (DNA damage response)**: 細胞偵測到 DNA 斷裂後啟動的反應；在編輯後的細胞裡要當成獨立的檢查項。
   - **p53**: 損傷警報的總開關，決定細胞停下來修還是自殺；編輯已被觀察到誘發 p53 介導的損傷反應 (REF.70)。
   - **選擇壓力 (selection pressure)**: 編輯與擴增流程本身會篩掉 p53 正常的細胞、留下 p53 缺陷的細胞，使風險族群在產品中被富集 (REF.70, 82)。
   - **脫靶 (off-target)**: 剪刀切到不該切的位置；必須以全基因體的尺度評估。
   - **標的位點活性 (on-target activity)**: 剪刀在指定位置的作用效率；必須與脫靶率成對報告，否則把剪刀改鈍就能造出漂亮數字。
   - **SpCas9-HF1**: 高保真變體，評估基準是在維持高標的位點活性的前提下改善全基因體特異性 (REF.257)。
   - **eSpCas9**: 另一個高保真變體，與 SpCas9-HF1 適用同一套成對比較基準 (REF.258)。
   - **預存免疫 (pre-existing immunity)**: 病患因過去自然暴露而帶有針對 Cas 蛋白的獲得性免疫；換成鹼基編輯也閃不掉 (REF.80, 81)。
   - **表觀編輯的穩定性與專一性**: 表觀編輯改的是可逆狀態，除了改到哪裡，還要量它撐多久，這決定療效的耐久性與 PK/PD。
   - **體外編輯 (ex vivo editing)**: 把細胞取出體外編輯再篩選挑選，可擋掉多數風險，代價是成本高、不易規模化。
   - **FDA 基因編輯指引**: 把基因編輯納入人類基因治療產品的官方文件，本文據以評估編輯效率、預存免疫與核酸酶作用機制。
5. 與此篇文章的關係: 
   在《Engineering the next generation of cell-based therapeutics》這篇文章中，作者要讓編輯過的細胞產品能安全進到病人體內，因此提出一套基因毒性與免疫原性的評估框架。它解決的瓶頸是：編輯效率漂亮不代表產品安全，大片段刪除、p53 活化與病患的預存免疫都會被漂亮的效率數字蓋過去。這套框架吃進編輯後的細胞，產出一份可送審的安全判準，並直接決定製造要走體外還是體內編輯。
