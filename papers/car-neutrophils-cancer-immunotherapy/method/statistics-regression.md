# 統計檢定與線性回歸建模

1. 引用自哪篇 paper: car-neutrophils-cancer-immunotherapy
2. Outline (任務主線): 統計檢定與線性回歸建模
3. Method:
   作者每種量到的數字都先整理成「平均值加減一個標準差 (mean ± SD)」：平均值是這組的典型落點，標準差告訴你組內的數字散得多開，圖上的誤差棒畫的就是它。接著依「要比幾組」挑一把統計裁判——只比兩組時用雙尾 t 檢定 (two-tailed Student's t-test)，三組以上時改用單因子變異數分析 (one-way ANOVA)。裁判會吐出一個 p 值，也就是「假設兩組其實沒差、光靠運氣看到眼前差異或更大差異的機率」；這個機率小於 0.05 (p < 0.05) 就判定差異不是巧合，這是生醫領域長年沿用的慣例門檻。每個體外實驗至少獨立重複三次 (n = 3)，體內動物實驗則用到六隻 (n = 6)。
為什麼要按組數換裁判？因為 t 檢定一次只能比兩組。碰到三組以上如果貪方便去「兩兩各做一次 t 檢定」，每做一次就有 5% 機會抓到假的差異，做越多次、累積的假陽性風險越高——三組要比三對，跑三次抓到至少一個假差異的機會就跳到約 14%，組數再多更誇張。單因子變異數分析 (one-way ANOVA) 換了個作法：它一次把所有組的變異放在一起比，只問「這幾組裡至少有一對真的不一樣嗎」，用單一檢定把整體假陽性壓在 5%。所以組數一多就換 ANOVA，不是形式問題，而是不讓假陽性靠次數偷偷堆出來。
判定完差異，作者還想再進一步證明殺傷力是「跟著 MMP2 走」的。他們手上有好幾株 MMP2 含量高低不同的腫瘤細胞，就把每一株當成一個點：橫軸放這株的 MMP2 表現量，縱軸放 CLTX-T-CAR 嗜中性球對它的殺傷率，畫成散點後拉一條最貼合的直線 (linear regression / 線性回歸)。這條線明顯往上斜，代表 MMP2 越多的細胞株被殺得越兇 (Fig S4I–K)。為什麼前面已經用敲降 (把 MMP2 這個基因單獨關掉看效果) 證明「沒有它就殺不動」，這裡還要做回歸？因為敲降只證明「有或沒有」的必要性，回歸才補上「越多越強」的劑量關係，兩者搭起來才難以反駁。反過來也要提醒：如果只有這條上升斜線、沒有敲降，還不能下結論——相關不等於因果，真正被鉤住的有可能是另一個剛好跟著 MMP2 一起變多的分子，只有把 MMP2 單獨關掉、殺傷力就掉，才真正把它從「相關」釘成「決定因子」。
至於小鼠活多久，作者用 Kaplan-Meier 存活曲線呈現，而不是直接比平均壽命。直接算「平均活幾天」有個大漏洞：實驗到期時往往還有幾隻老鼠活著，你不知道牠們最後能撐到第幾天，算平均等於被迫給牠們一個假的死亡日。存活曲線改成隨時間畫出「每個時間點還有多少比例存活」，遇到還沒死、只是實驗結束的老鼠會特別標記、不硬塞死亡日，既正確處理了這些個體，也把整條存活過程完整攤開。
4. 工具與材料:
   - **mean ± SD (平均值 ± 標準差)**: 每組數據的呈現方式：平均值是典型落點，標準差是組內散布程度，對應圖上的誤差棒。
   - **two-tailed Student's t-test (雙尾 t 檢定)**: 只比兩組平均數、事先不假設哪邊大的檢定；本研究用於任兩組比較。
   - **one-way ANOVA (單因子變異數分析)**: 一次比較三組以上平均數的檢定，避免反覆兩兩 t 檢定累積假陽性；本研究用於三組以上比較。
   - **p < 0.05**: 顯著門檻：假設兩組其實沒差時、光靠運氣看到眼前差異的機率低於 5%，即判定差異非巧合。
   - **n (獨立重複次數)**: 每個條件重複的樣本數；本研究體外多為 n = 3、體內動物實驗 n = 6。
   - **linear regression (線性回歸)**: 把各腫瘤細胞株的 MMP2 表現量與 CLTX-T-CAR 殺傷率畫成散點並擬合一條斜線，正斜率代表殺傷隨 MMP2 上升。
   - **knockdown (敲降)**: 把某個基因單獨關掉看功能是否喪失的實驗；本研究以敲降 MMP2 證明其為殺傷所必需。
   - **Kaplan-Meier curve (存活曲線)**: 隨時間畫出各組還有多少比例存活的曲線，能正確處理實驗結束時仍存活的個體。
5. 與此篇文章的關係:
   在《Engineering chimeric antigen receptor neutrophils from human pluripotent stem cells for targeted cancer immunotherapy》這篇文章中，作者為了讓各種組間比較與機制主張站得住腳，替不同資料挑對應的統計裁判：兩組用雙尾 t 檢定、三組以上用單因子變異數分析。更關鍵的是，他們用線性回歸把跨多株腫瘤的殺傷率與 MMP2 表現量拉成一條上升斜線，替前面的敲降實驗補上「越多殺越兇」的定量證據。小鼠存活則以 Kaplan-Meier 曲線呈現，整套統計把前面所有實驗的數字轉成可客觀判讀的結論。
