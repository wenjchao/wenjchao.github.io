# FACS 族群級螢光量測

1. 引用自哪篇 paper: cellular-logic-gate-physics
2. Outline (任務主線): FACS 族群級螢光量測
3. Method:
   螢光細胞分選儀 (FACS, Fluorescence-Activated Cell Sorting) 是一台把細胞「排隊、逐顆通過雷射」的儀器 (protocol 見 Shapiro, Practical Flow Cytometry, 3rd ed., 1995)。原理如下：先把培養好的細菌液裝進儀器，用一條裝有懸浮液的極細液流噴出、被震動切成一顆一顆像水滴一樣的微液滴，每顆液滴裡剛好只裝一顆細菌；液滴依序通過雷射光束時，細胞內的螢光蛋白被激發發光，光電倍增管 (光的極敏感偵測器) 立刻記下這顆細胞在各波長的螢光強度。這樣一次實驗就能拿到上萬顆細胞「各自」的螢光讀值，而不是把整群加起來平均。

   FACS 的第二個關鍵設計，是讓每顆細胞同時攜帶 ECFP (輸入報告) 與 EYFP (輸出報告)、儀器一次讀兩通道。如果作者改用「一批只讀藍色、一批只讀黃色」的分批策略，能算的只有「A 批的平均輸入」對「B 批的平均輸出」——但 A 批與 B 批本來就是兩群不同細胞，細胞數、培養時間、隨機雜訊都有差；量出來的關聯可能只是兩批的環境差異，跟 inverter 本身的輸入-輸出關係無關。同顆細胞同時記錄兩通道，每筆資料就是「這顆細胞剛好輸入多少、輸出多少」——真正的細胞內配對。這樣的 transfer curve 才是 inverter 的實際行為，而不是平均之間的假關聯。

   作者採樣的時間點也是設計出來的：液態培養約 5 小時後才 FACS。為什麼要等 5 小時？作者要量的是 transfer curve 的穩態 (steady state) 行為——「輸入 IPTG 給定後輸出蛋白最後會穩在多少」——不是瞬時值。剛接種時細胞內 mRNA、蛋白都還在爬，這時量的螢光還在「往上跑」而不是「穩住」；5 小時剛好是 E. coli 在該培養條件下經驗上的穩態時間，蛋白合成、稀釋、降解達動態平衡，濃度不再隨時間顯著變化。反過來看兩端的極端：太早採樣，各條件的曲線混雜「還沒穩下來的暫態」——同樣 IPTG 條件在不同時間點量會得到不同的 transfer curve；太晚採樣，細菌進 stationary phase、資源耗盡、生理狀態改變，量到的曲線也不再反映 gate 內在特性。5 小時就是「已經穩定、細胞又還健康」的甜蜜點。

   FACS 每個實驗條件回報的是「族群裡上萬顆細胞的螢光分布」，作者把它摘要成兩個數字——中位螢光值當該條件的中央讀數，加上涵蓋 95% 細胞的螢光區間當誤差棒 (Figure 8b 就是這樣定義)。為什麼用 95% 區間而不是常見的標準差或標準誤？因為作者要判斷的是「高輸入的細胞群 vs 低輸入的細胞群，兩群的螢光分布會不會重疊」——沒重疊才代表數位訊號分得開、noise margin 夠。95% 區間直接畫出「95% 的細胞落在哪到哪」，一眼就能看出兩群分布有無重疊；標準差要分布近常態才好解讀，細胞群常有長尾偏斜；標準誤只反映平均值本身的不確定性，跟族群主體寬度無關。作者刻意選 95% 區間，就是把 FACS 給的分布資訊「翻譯」成能直接讀出 noise margin 的形式。(把分布壓成中位＋95% 區間、以及為什麼中位而不是平均的更深展開，屬「Transfer Curve 建構與 Gain 量化」模組的討論。)

   反過來想：如果作者不用 FACS、改用傳統平板螢光讀值 (plate reader) 量整孔細胞的總螢光，會失去什麼？平板讀值把整孔細胞當一團，把所有細胞發出的螢光加總、除以細胞數，回傳一個「這孔的平均螢光」。用它量 transfer curve 有兩個致命問題：第一，你只拿到平均值、看不到族群內的散布，也就無法讀出 noise margin——高輸入時的分布跟低輸入時的分布有沒有重疊完全不知道。第二，平均值算的是「這孔所有細胞的平均輸入」對「這孔所有細胞的平均輸出」，一樣是平均對平均而不是同顆細胞配對，量到的關聯可能被 gate mismatch 之外的雜訊污染。整篇論文的 transfer curve 都依賴「族群散布 + 單細胞配對」這兩件事，平板讀值兩者都丟——所以必須用 FACS。

4. 工具與材料:
   - **FACS (Fluorescence-Activated Cell Sorting)**: 把細胞「排隊、逐顆通過雷射」的儀器 (Shapiro, Practical Flow Cytometry, 3rd ed., 1995)：極細液流被震動切成單細胞微液滴，逐顆通過雷射激發螢光蛋白，光電倍增管記下各波長螢光強度。
   - **同顆細胞雙通道量測**: 同一顆細胞同時攜帶 ECFP (輸入報告) 與 EYFP (輸出報告)，FACS 一次讀兩通道，讓輸入-輸出配對發生在單一細胞內、避免跨批次平均對平均的假關聯。
   - **液態培養 5 小時穩態**: E. coli 在該培養條件下達 transfer curve steady state 的經驗時間，蛋白合成、稀釋、降解達動態平衡；太早採樣量到暫態，太晚採樣細菌進 stationary phase 失真。
   - **中位螢光 + 95% 涵蓋區間**: 作者把 FACS 每個條件量到的族群分布摘要成的兩個數字：中位螢光為中央讀數、涵蓋 95% 細胞的螢光區間為誤差棒 (Figure 8b 定義)。
   - **傳統平板讀值 (plate reader)**: 把整孔細胞當一團、量總螢光除以細胞數的傳統方法；沒有族群散布資訊、也無法做單細胞輸入-輸出配對，作者刻意避開的替代方案。

5. 與此篇文章的關係:
   在《The Device Physics of Cellular Logic Gates》這篇文章中，作者為了量出帶有 noise margin 資訊、且輸入-輸出成對的 inverter transfer curve，採用了 FACS 族群級螢光量測。這個方法解決了傳統平板讀值只給整孔平均值、看不到族群散布也做不到單細胞配對的瓶頸，把每個 IPTG 條件下上萬顆細胞的 ECFP／EYFP 分布摘要成中位螢光＋95% 涵蓋區間，供下游的 transfer curve 建構與 gain 量化模組直接使用。
