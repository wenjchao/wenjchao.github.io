# 五階段電腦輔助設計流程與軟體工具鏈

1. 引用自哪篇 paper: synthetic-genetic-circuit-design
2. Outline (任務主線): 五階段電腦輔助設計流程與軟體工具鏈
3. Method:
   這篇綜述把合成基因迴路的設計，整理成一條像工廠生產線的五階段電腦輔助設計流程 (computer-aided design, CAD；流程全貌見 FIG. 2)。第一階段是「規格 (specification)」：先不碰任何 DNA，而是把想要的電路行為用明確規則寫死——包括它安定下來後該停在什麼狀態 (穩態)，以及收到輸入訊號後該怎麼隨時間變化。第二階段是「設計」：畫出幾種可能的接線方式 (拓樸)，再替每個節點填上具體的零件。第三階段是「建模與分析」：在電腦裡模擬每種接線的行為，挑出最有希望的少數幾種。第四階段才真正「構建」：把 DNA 組裝出來。第五階段是「測試」：在細胞裡量它到底對不對。最關鍵的是，這五階段不是走一遍就結束的直線，而是一個可以反覆回頭修正的迴圈——測出來不對，就退回前面重新設計。
   這套流程真正的價值，不在於發明單一新軟體，而在於把原本各做各的零散工具「對齊」到同一條管線上。在規格階段，Proto Biocompiler 這類工具能把人寫的高階行為描述直接編譯成一張基因網路草圖；在設計階段，GenoCAD 用一套形式文法 (formal grammar)——像規定語言的文法規則一樣——規範零件只能以合法的方式拼接，還有 Cell Designer、TinkerCell 等畫網路圖、對應到模型與零件的工具。這樣一來，由上而下分解產出的規格，就能沿著這條流程一路映射到手邊真正拿得到的基礎零件，而不是停在紙上。反過來說，如果各階段工具各自為政、彼此不通，前一階段吐出的規格就接不進下一階段，設計會永遠卡在抽象層、組不出能進細胞測試的 DNA。
   值得注意的是，這裡叫「電腦輔助」而不是「電腦全自動」，是有原因的。作者用有機合成當對照：在那個領域，軟體能一口氣列出大量可能的合成路線，但最後挑哪一條，仍要靠化學家的經驗判斷。合成生物學也一樣——雖然已經有工具試著從高階規格自動生出電路，但軟體負責的是「列出選項、模擬、優化」這些人腦算不動的苦工，真正的取捨還是留給設計者。換句話說，這條 CAD 流程的目的不是取代人，而是把每一階段的複雜度壓到人腦管得動的範圍。
4. 工具與材料:
   - **五階段 CAD 流程**: 貫穿「規格→設計→建模與分析→構建→測試」、且可反覆迭代的電腦輔助設計管線 (FIG. 2)。
   - **規格 (specification)**: 流程第一步，把想要的電路行為 (含穩態與對輸入的動態反應) 用明確規則形式化寫死。
   - **Proto Biocompiler**: 規格階段工具，把人寫的高階行為描述編譯成一張基因網路草圖 (ref 18)。
   - **GenoCAD**: 設計階段工具，用形式文法 (像語言的文法規則) 規範零件只能以合法方式拼接成電路 (ref 135)。
   - **Cell Designer / TinkerCell**: 設計階段工具，負責畫網路圖並把圖對應到模型與具體零件 (refs 133,138)。
   - **迭代迴圈 (iteration)**: 五階段不是一次走完的直線，測不對就退回前段重設計的循環。
5. 與此篇文章的關係:
   在《Foundations for the design and implementation of synthetic genetic circuits》這篇文章中，作者主張合成生物學應像設計晶片般採用形式化流程，於是盤點出一條貫穿「規格→設計→建模與分析→構建→測試」的五階段電腦輔助設計 (CAD) 流程。它解決了零散軟體各自為政、規格無法一路落實到真實零件的瓶頸，把由上而下分解的產物對齊成一條可操作的管線，往下再銜接序列設計、動力學建模與自動拓樸搜尋等各階段工具。
