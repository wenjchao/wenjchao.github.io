# 大量轉錄體定序與基因表現變異分析

1. 引用自哪篇 paper: neutrophil-heterogeneity
2. Outline (任務主線): 大量轉錄體定序與基因表現變異分析
3. Method:
   這一步想回答一個看似簡單的問題：不同人的嗜中性球，在還沒受到任何刺激時，基因開關的設定是不是都長一樣？作者用大量轉錄體定序 (bulk RNA sequencing) 來量。做法是把一位捐贈者的一整群嗜中性球磨在一起，讀出它們平均正在製造哪些 RNA——也就是讀出這群細胞的轉錄體 (transcriptome，一顆細胞當下打開的所有基因的總和)。這裡用「大量」平均而非逐顆讀，是因為問題是「人跟人之間差多少」，不需要單細胞的解析度。量出來的結果很反直覺：嗜中性球的轉錄體在不同捐贈者之間變異度極高，甚至比單核球或淋巴球（另外兩類白血球）都高，而且變異最大的那批基因，剛好集中在發炎體活化、抗病毒這類免疫功能上（Chen L et al., Cell, 2016；Ecker et al., Genome Biol., 2017）。
變異這麼大，接下來的關鍵問題是：這是天生 DNA 序列決定的，還是後天開關設定造成的？作者用一種叫 eQTL (表現量數量性狀基因座) 的分析來拆帳——它比對每個人的 DNA 序列差異和基因表現量，如果某個 DNA 序列變異能穩定預測某基因開多大，這個差異就算「遺傳決定」的。結果顯示，個體間的差異多數確實由遺傳因子主導（Andiappan et al., 2015；Naranbhai et al., Nat. Commun., 2015）。但仍有數百個高變異基因無法用 DNA 序列解釋，落到另一種可能：由表觀／染色質調控——也就是 DNA 序列一樣、但開關包裝狀態 (染色質) 不同——來微調。人類嗜中性球在 DNA 上外加甲基標記的圖譜 (DNA methylation) 在個體間也有廣泛差異，正好支持這個推論。
最直接證明「即使終末成熟也還很有可塑性」的證據，來自刺激後的反應速度差異。作者比較兩個發炎基因：CXCL8 (也就是 IL-8) 在受刺激後幾分鐘內就衝到最高點，IL6 卻慢得多。為什麼同樣是被打開，一個秒開、一個要暖機？因為 CXCL8 附近的染色質早就處於「預備待命」狀態 (pre-poised chromatin)，開關已經半開，轉錄機器一到位就能立刻工作；IL6 的調控區則必須先經過染色質重塑、掛上正確的組蛋白標記，才准許轉錄機器上工（Zimmermann et al., Nat. Commun., 2015）。這說明嗜中性球的反應不是一視同仁，而是被每個基因事先的染色質狀態決定快慢——也正因如此，作者才要特地把變異拆成遺傳與表觀兩份：唯有由染色質調控的那一份，才支持『事先設定不同、對同一訊號反應就不同』的核心論點。
這類轉錄體分析有兩個特別容易翻車的地方。第一是樣本純度：如果分離出來的嗜中性球混進了其他白血球，讀到的「嗜中性球轉錄體」其實摻了雜訊，個體間的差異就可能被錯誤歸因（Thomas et al., PLOS ONE, 2015）。第二是只看「靜止狀態」會嚴重低估可塑性：嗜中性球真正的彈性要在受到微生物成分、細胞激素、生長因子刺激後才充分顯現，此時有數百個基因會被調動；少了刺激下的動力學（例如 CXCL8 與 IL6 的快慢對比），就看不出染色質如何預先決定反應。所以作者堅持要同時量「靜止的個體差異」和「刺激後的動態」，兩者合起來才站得住『嗜中性球具高度轉錄可塑性』這個論點。
4. 工具與材料:
   - **bulk RNA sequencing (大量轉錄體定序)**: 把一整群細胞磨在一起、讀出平均 RNA 的定序；用來比人跟人的差異。
   - **transcriptome (轉錄體)**: 一顆細胞當下打開的所有基因（RNA）的總和。
   - **個體間變異 (interindividual variability)**: 不同捐贈者嗜中性球的基因開關設定差異，比單核球淋巴球都大。
   - **eQTL (表現量數量性狀基因座)**: 比對 DNA 序列變異與基因表現量，判斷差異是否由遺傳決定的分析。
   - **表觀／染色質調控**: DNA 序列相同、但開關包裝狀態 (染色質) 不同造成的表現差異。
   - **pre-poised chromatin (預備待命染色質)**: 開關已半開的染色質，讓 CXCL8 等基因刺激後幾分鐘就爆發。
   - **chromatin remodeling (染色質重塑)**: IL6 等基因需先重整染色質、掛組蛋白標記才准轉錄的較慢過程。
   - **sample purity (樣本純度)**: 分離純度會影響轉錄體結果，混入其他白血球會污染資料。
5. 與此篇文章的關係:
   在《Heterogeneity of neutrophils》這篇綜述中，作者要反駁「終末成熟的嗜中性球僵化、沒有可塑性」的舊印象。為此作者引用大量轉錄體定序的結果，量出嗜中性球在個體間與刺激下的高度基因表現變異，並用 eQTL 分析把變異拆成遺傳與表觀兩份。它吃進捐贈者的嗜中性球、輸出變異程度與其成因歸屬，替後面以染色質差異解釋異質反應的基因體模型鋪好證據。
