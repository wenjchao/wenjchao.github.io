# 單細胞轉錄體定序與分化軌跡分析

1. 引用自哪篇 paper: neutrophil-heterogeneity
2. Outline (任務主線): 單細胞轉錄體定序與分化軌跡分析
3. Method:
   要客觀還原嗜中性球在骨髓裡怎麼一步步長成，作者靠的是單細胞轉錄體定序 (single-cell RNA sequencing, scRNA-seq)：不把骨髓細胞打成泥量平均，而是一次只讀一顆細胞、記下它此刻正在讀取的全部基因清單（轉錄體, transcriptome），一口氣做上千顆。接著用電腦比對每顆細胞的基因清單，把清單只差一點點的排在一起、差很多的排遠，就能把上千顆細胞串成一條「誰先誰後」的成長順序，也就是擬時序分化軌跡 (pseudotime trajectory)。由於基因不是一次全換、而是慢慢挪動，排出來的分化自然是一條沒有明顯斷點的連續分化 (continuous differentiation)——人類的系別承諾正是這樣一路連續走過來的（Velten et al., Nat. Cell Biol., 2017, ref 11）。沿著這條軌跡再看哪些主控開關蛋白（轉錄因子, transcription factor）在哪一段亮起，早、中、晚期前驅細胞就各自帶上不同的分子特徵（Giladi et al., 2018, ref 2；Paul et al., 2015, ref 3）。
這套做法能取代主觀的染色形態分級，關鍵在解析度。外觀（核濃縮、顆粒多寡）是分化很後段才顯現的少數結果，兩顆長得一樣的細胞內部程式可能早已分家；基因清單在外觀改變之前就先讀到細胞的內部設定，因此能把顯微鏡下看不出差別的階段分開。而堅持做到單一細胞還有一個理由：把一群細胞混著量平均，稀少的前驅細胞會被多數成熟細胞稀釋掉。唯有一顆顆分開讀，才抓得到藏在少數細胞裡的族群——例如 Zhu et al. (Cell Rep., 2018, ref 14) 找到的早期單能前驅 (NeP)，數量少卻帶促腫瘤活性；另有 Kim et al. (ref 13) 的晚期前驅 NeuP。
單細胞解析度還讓作者看見前驅細胞如何在兩種命運間選邊。有一群罕見細胞同時開著兩套身分程式、還沒決定去向，它們同時表現 GFI1 與 IRF8 這兩個互相對打的主控開關蛋白（Olsson et al., Nature, 2016, ref 141）：GFI1 把細胞推向嗜中性球、IRF8 推向單核球，兩者互相壓制，誰贏就決定這顆細胞的下場。這種混合狀態再二選一的命運電路只有在單細胞層級才看得到，也替本文的轉錄因子電路論述提供了直接證據。
反過來看，若仍沿用密度離心加染色形態分級，判讀既主觀又只反映後段外觀，排不出分子軌跡、偵測不到 NeP、也標不出各階段的轉錄因子程式，全篇「發育階段就是異質性來源」的論點便失去分子證據；退一步改用混合樣本的平均值，連續的分化會被抹平成看似幾個離散步驟、稀有前驅被稀釋消失，等於把最想證明的東西親手擦掉。
4. 工具與材料:
   - **single-cell RNA sequencing (scRNA-seq)**: 一次只讀一顆細胞、記下它正在讀取的全部基因清單，一口氣做上千顆，用來取代把細胞打成泥量平均的做法。
   - **轉錄體 (transcriptome)**: 一顆細胞此刻正在被讀取（轉錄）的全部基因清單，反映它當下的內部設定。
   - **擬時序分化軌跡 (pseudotime trajectory)**: 用電腦依基因清單相似度把細胞排成的一條「誰先誰後」成長順序，用來還原連續分化。
   - **轉錄因子 (transcription factor)**: 決定細胞身分的主控開關蛋白；沿軌跡看它們何時亮起，可標出早、中、晚期前驅的分子特徵。
   - **NeP**: 單細胞在小鼠與人骨髓找到的早期單能嗜中性球前驅，數量少卻帶促腫瘤活性（Zhu et al., ref 14）。
   - **NeuP**: 另一群被單細胞刻畫出的晚期嗜中性球前驅（Kim et al., ref 13）。
   - **GFI1／IRF8**: 一對互相對打的主控開關蛋白，前者推向嗜中性球、後者推向單核球，決定雙潛能前驅的命運（Olsson et al., ref 141）。
5. 與此篇文章的關係:
   在《Heterogeneity of neutrophils》這篇綜述中，作者主張嗜中性球的異質性從骨髓的發育階段就開始，為了取代主觀、只看外觀的染色形態分級，他們援引單細胞轉錄體定序搭配擬時序軌跡分析（Velten、Giladi、Paul、Zhu 等）。這套方法吃進一顆顆骨髓細胞的基因清單，產出一張連續的分化地圖並標出稀有前驅（如 NeP、NeuP），為「發育階段即異質性來源」提供分子證據，並把資料交給下游的降維比對（3-B）去對齊各研究不一致的命名。
