# 表觀基因體與染色質可及性分析

1. 引用自哪篇 paper: neutrophil-heterogeneity
2. Outline (任務主線): 表觀基因體與染色質可及性分析
3. Method:
   這一節要做的，是把決定「哪些基因的門是開是關」的整套設定畫出來——這套設定合稱表觀基因體 (epigenome)。它不改 DNA 的字母，只調整 DNA 的包裝與標記，而作者關心的是其中幾個互相搭配的層次。最基礎的一層是染色質可及性 (chromatin accessibility)：染色質是 DNA 纏繞蛋白後的包裝，包得鬆、露出來的區段就「可及」（門開著），轉錄機器搆得到；包得緊就搆不到。這一層可用一種讓轉座酶專門插進鬆開區段的技術 (ATAC) 讀出來，配套的 ATAC-see（Chen et al., Nat. Methods, 2016）還能把可及區段直接在顯微鏡下顯影。其餘幾層包括：掛在 DNA 纏繞軸上的組蛋白修飾 (histone modification，像便利貼標明這段該開還該關)、直接加在 DNA 上、通常代表「關閉」的 DNA 甲基化 (DNA methylation)、以及遠端替某個基因加強音量的開關 (增強子，enhancer)。
畫這張圖之前，得先破除一個舊成見。嗜中性球的細胞核擠成 3–5 葉，在 linear DNA 上相距超過 3 Mb（三百萬個鹼基）的區段竟然還會在空間中互相貼在一起（Zhu Y et al., Genes Dev., 2017，屬三維基因體結構分析），加上它的 RNA 含量又比其他髓系細胞少，過去因此被當成一台包裝鎖死、不能再調的機器。但實際描繪後剛好相反：整個成長與活化過程中，染色質一直在大規模改寫。成熟時，數百個管生合成與增殖的基因被關掉，顆粒與抗菌基因則被打開（Borregaard, Immunity, 2010）；顆粒生成過程中的 DNA 甲基化與增強子甲基化也依時序變化（Rönnerblad et al., Blood, 2014）。可見這套包裝不是死的，而是終其一生都在動態開關。
整篇論文最核心的機制模型就建立在這張圖上，用來回答一個關鍵問題：為什麼同一個腫瘤訊號打在未成熟和成熟嗜中性球上，會得到相反的反應？答案是——訊號帶進細胞核的活化型轉錄因子（例如 TGFβ 派進來的信差 SMAD）只能結合「事先已經打開」的門。未成熟和成熟細胞在發育時被預先打開的門本來就不一樣，所以同一個 SMAD 落在各自開著的位置上，佔據的基因不同，轉錄輸出也就不同。這不是憑空假設：實驗發現用 TGFβ 刺激髓系、肌肉、胚胎幹細胞時，SMAD 結合的位點各不相同，而且正是由先前被打開的位點決定的（Mullen et al., Cell, 2011）。NF-κB、STAT 這些活化型轉錄因子同樣以細胞型別特異的方式結合基因體。這就是「先存的表觀差異決定對共同訊號之差異反應」的分子基礎，也是作者只看轉錄體不夠、非得描繪染色質的原因——染色質才回答得了「為什麼反應不同」。
那麼發育時是誰決定要先打開哪些門？是一組叫譜系決定轉錄因子 (lineage-determining transcription factor，LDTF) 的蛋白，在嗜中性球裡主要是 PU.1、C/EBPα、C/EBPβ。它們特別之處在於能撬開原本關著的染色質、甚至搬到不相干的細胞裡也照樣開門，因此被稱為先鋒轉錄因子 (pioneer TF)。除了這幾個全程在崗的主力，還有只在特定成熟階段上工的幫手——例如 C/EBPε、KLF5、LEF1，以及一對互相拮抗的 GFI1 與 IRF8。它們合力決定每個成熟階段的細胞把哪些門先打開，也就預先佈好了各亞群不同的增強子地景 (enhancer landscape)。這套「工頭先佈線」的邏輯，是作者直接借用研究得更透徹的巨噬細胞推想過來的。
最後看這個模型會壞在哪、又如何被檢驗。第一種失敗是舊思維本身：如果因為細胞核擠成幾葉、RNA 又少，就先入為主認定嗜中性球的基因體鎖死、根本不去量它的染色質，就會完全錯過它一生都在動態開關的事實。第二，這套機制其實自帶一個反面檢驗——假如各亞群事先打開的門都一樣，那同一個 TGFβ 就該到處產生相同結果；但腫瘤裡未成熟與成熟細胞明明暴露在相同訊號下卻呈現相反的活化狀態，正好反證「差異來自先存的染色質，而非訊號本身」。染色質也能反向鎖門：人類嗜中性球會刻意把 IL10 這個位點維持在不活化的構型，擋住它被誘導（Tamassia et al., J. Immunol., 2013）——少了這道鎖，IL10 就會被錯誤打開。
4. 工具與材料:
   - **epigenome (表觀基因體)**: 不改 DNA 字母、只靠包裝與標記決定哪些基因門開門關的整套設定。
   - **chromatin accessibility (染色質可及性)**: DNA 包裝的鬆緊；鬆＝門開、轉錄機器搆得到。
   - **ATAC / ATAC-see**: 用轉座酶專插鬆開區段來讀出（並可顯影）可及染色質的技術。
   - **histone modification (組蛋白修飾)**: 掛在 DNA 纏繞軸上、標明該段開或關的化學標記。
   - **DNA methylation (DNA 甲基化)**: 直接加在 DNA 上、通常代表關閉的甲基標記。
   - **enhancer (增強子)**: 遠端替某基因加強表現音量的開關；其分布合稱增強子地景。
   - **三維基因體結構**: 嗜中性球核 3–5 葉、linear DNA 相距 >3 Mb 仍物理互作的空間排列。
   - **LDTF (譜系決定轉錄因子)**: PU.1、C/EBPα/β 等在發育時先撬開染色質的主控蛋白。
   - **pioneer TF (先鋒轉錄因子)**: 能打開原本關閉染色質、換到別種細胞也開門的轉錄因子。
   - **活化型轉錄因子 (SMAD/NF-κB/STAT)**: 訊號派進核內的信差，只能結合事先打開的位點。
5. 與此篇文章的關係:
   在《Heterogeneity of neutrophils》這篇綜述中，作者最想提出一個能統一解釋嗜中性球多樣性的基因體調控模型。為此作者整合染色質可及性、組蛋白修飾、DNA 甲基化與三維基因體結構等表觀分析，解答「同一訊號為何在不同細胞產生相反反應」的核心謎題。它吃進各成熟階段細胞的染色質地景、輸出「先存表觀差異決定差異反應」的機制框架 (Fig. 4)，收束全篇論點。
