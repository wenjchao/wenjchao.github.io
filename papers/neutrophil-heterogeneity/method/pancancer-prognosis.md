# Pan-cancer 生物資訊學特徵與預後關聯分析

1. 引用自哪篇 paper: neutrophil-heterogeneity
2. Outline (任務主線): Pan-cancer 生物資訊學特徵與預後關聯分析
3. Method:
   這一步作者不做新實驗，而是把已經存在的數千個人類腫瘤基因資料拿來用電腦分析（生物資訊學, bioinformatics），一次橫跨很多種癌症、不分器官一起看（泛癌, pan-cancer）。難點在於一份腫瘤基因資料其實是裡面各種細胞混在一起量出來的總和，於是作者用免疫細胞去卷積 (immune cell deconvolution) 把它拆開：先備好每種細胞的招牌基因清單（gene signature），再用數學從那份混合訊號反推每種細胞各占多少——就像化驗一杯綜合果汁、反推裡面各放了多少種水果，不必把細胞一顆顆挑出來，也能估出嗜中性球在腫瘤裡的比例，再把這個豐度跟病人後來活得好不好對起來（Gentles et al., Nat. Med., 2015, ref 66）。
去卷積之所以可信，靠兩個前提：每種細胞有夠獨特的招牌基因，看到就八九不離十是那種細胞；而混合訊號大致等於各種細胞招牌訊號『按比例相加』。招牌已知、相加規則也大致成立，就能反解出各細胞的比例，如同知道每種水果的味道、又嘗得出整杯果汁便能回推配方。而之所以要橫跨數千腫瘤，是因為把這麼多腫瘤的細胞一個個實體挑出來數根本做不到——它們多半是早就存檔的基因資料。去卷積能重複利用這些現成資料，樣本一大，統計說服力就夠，即使嗜中性球數量相對少，也能穩定測出它與預後的關聯（Gentles et al., ref 66）。
除了吃腫瘤基因資料的去卷積，作者還看一個便宜又現成的抽血指標：嗜中性球對淋巴球的數量比 (neutrophil-to-lymphocyte ratio, NLR)，只要抽一管血、門診常規就能算。用比值而非嗜中性球絕對數，好處是能自動抵銷個體差異、直接反映兩種細胞此消彼長的失衡。正因如此，循環嗜中性球頻率與 NLR 都被評估為癌症進展的預後生物標記（Guthrie et al., ref 67）。
這套分析有三個要小心的地方。第一，招牌基因會撞名：嗜中性球的招牌基因若和其他髓系細胞重疊，去卷積就會把別的細胞誤算成嗜中性球，比例算錯。第二，關聯不等於因果——帶嗜中性球特徵的病人預後較差，不代表就是嗜中性球造成的。第三，去卷積只量『有多少』、量不出『是哪一種狀態』，分不出幫腫瘤與打腫瘤的版本；要補這一刀得靠更精細的表型特徵，例如帶 TGFβ 訊號、會促腫瘤的 Siglec-F⁺ 嗜中性球，其表型就與人類世代的疾病結局對得上（Engblom et al., Science, 2017, ref 79）。
4. 工具與材料:
   - **pan-cancer (泛癌)**: 一次橫跨很多種癌症、不分器官一起做的分析。
   - **bioinformatics (生物資訊學)**: 用電腦從既有的基因資料挖出規律，不必重新做實驗。
   - **immune cell deconvolution (免疫細胞去卷積)**: 從一份『整團腫瘤混在一起』的基因資料，反推各種免疫細胞各占多少。
   - **gene signature (招牌基因清單)**: 一組足以代表某種細胞的基因，是去卷積用來辨認細胞的依據。
   - **meta-analysis (統合分析)**: 把很多研究或很多樣本的結果匯總在一起看，換取更強的統計說服力。
   - **neutrophil-to-lymphocyte ratio (NLR)**: 抽血算嗜中性球對淋巴球的數量比，便宜、常規，被當成癌症預後生物標記。
   - **Siglec-F⁺ 嗜中性球**: 帶 TGFβ 訊號、會促腫瘤的一種嗜中性球，其表型與人類世代疾病結局相關（Engblom et al., ref 79）。
5. 與此篇文章的關係:
   在《Heterogeneity of neutrophils》這篇綜述中，作者要把前面談的細胞多樣性連到真實的臨床後果。為此他們引用泛癌生物資訊學：Gentles 的統合分析（ref 66）對數千個腫瘤做免疫細胞去卷積，發現嗜中性球特徵儘管細胞數少，卻預示較差預後；NLR（ref 67）則作為抽血可得的預後生物標記。這套分析吃進整團腫瘤的基因資料與臨床血液數據，產出嗜中性球豐度與病人結局的統計關聯，替全篇『嗜中性球異質性攸關疾病結局』的主張提供人類層級的證據。
