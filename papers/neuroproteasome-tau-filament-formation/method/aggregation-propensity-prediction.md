# 不可溶受質的聚集傾向與序列生物物理特性計算

1. 引用自哪篇 paper: neuroproteasome-tau-filament-formation
2. Outline (任務主線): 不可溶受質的聚集傾向與序列生物物理特性計算
3. Method:
      前一步篩出一批被 iBEp 推進不可溶堆的蛋白，作者想追問：它們是碰巧被抓來聚集，還是天生體質就容易黏成一團？這一步不做濕實驗，改純粹從胺基酸序列下手。他們先照 iBEp 造成的變化分兩組：相對對照增加超過 25% 的算「明顯增加 (increased)」、變化在正負 10% 以內的算「幾乎沒受影響 (unaffected)」，每個蛋白的完整序列都從蛋白序列資料庫 (UniProtKB/Swiss-Prot) 取得。設對照組是關鍵——單看一個蛋白分數高沒意義，必須拿它和沒受影響那組比，才知道差異蛋白是不是「相對而言」更容易聚集。
   作者用三把尺量這些蛋白的天生體質，而它們正好各對應聚集的一種物理推力。第一把是 TANGO 聚集傾向：它讀序列、依二級結構的物理化學規則預測哪些片段愛彼此疊成 β-摺疊、黏成團（類澱粉樣聚集常見的結構），量的是「愛聚集的片段多不多」。第二把是 Kyte–Doolittle 疏水性：替每種胺基酸打「怕不怕水」的分數再平均成整體疏水程度 (GRAVY，以 Python 工具 Biopython 計算)，量的是「互相黏的推力強不強」——怕水的區段為了躲水會彼此貼合，正是聚集的推力。第三把是 Metapredict V2 無序度：預測一條蛋白有多少比例是沒有固定摺疊、鬆散飄動的區段，量的是「結構鬆不鬆、好不好被扳成愛聚集的姿態」（tau 正是典型的無序蛋白）。三者合起來，就能從序列本身估出一條蛋白與生俱來多容易聚集；但要強調這是電腦的傾向預測、是佐證而非鐵證。
   之所以這樣設計，是為了省力又不被單一指標騙。用電腦從序列預測，不必再做一堆濕實驗，就能一次檢驗「這些受質是不是天生愛聚集」的假說。一次用三種指標，是因為任何單一分數都可能誤導——某蛋白 TANGO 高卻其實不疏水、或很疏水卻結構很硬，三把尺互相參照才穩。用全長序列而非隨手截的片段，避免「挑到哪段」影響結論。而 increased 對 unaffected 的分組比較，把「分數多少」這種絕對值，變成「差異蛋白相對於沒受影響的蛋白是否更高」這種站得住的相對結論。
   反過來說，少了對照或偷懶都會讓結論垮掉。若沒有 unaffected 這組當基準，一個蛋白的 TANGO 或疏水分數再高也無從解讀，因為沒有比較對象、不能宣稱它「比較容易聚集」。若只信單一指標，某蛋白可能因為和聚集無關的原因分數偏高，害人下錯結論——三把尺互相牽制才安全。若拿隨手截的片段而非全長來算，分數會被「剛好挑到哪一段」帶偏。最後，這終究是傾向預測，當成鐵證就過度宣稱——它能說的只是這些受質「看起來本來就偏愛聚集」。
4. 工具與材料:
   - **increased／unaffected 分組門檻**: 把 iBEp 下增加 >25% 的蛋白歸「明顯增加」、變化 <±10% 的歸「幾乎沒受影響」，後者作為比較基準。
   - **UniProtKB/Swiss-Prot**: 蛋白序列資料庫，用來取得每個蛋白的完整全長序列供計算。
   - **TANGO 聚集傾向**: 讀序列、依二級結構規則預測哪些片段愛疊成 β-摺疊聚集，量「愛聚集片段多不多」。
   - **Kyte–Doolittle 疏水性 / GRAVY**: 替每種胺基酸打怕水分數再平均成整體疏水程度；越疏水越傾向互相貼合聚集。
   - **Biopython**: 一套 Python 生物資訊工具，用來計算疏水性平均值 (GRAVY)。
   - **Metapredict V2 無序度**: 預測一條蛋白多少比例是無固定摺疊、鬆散飄動的區段；越無序越易被扳成聚集構型。
5. 與此篇文章的關係:
   在《Neuroproteasomes regulate endogenous tau paired helical filament formation in an APOE genotype- and age-dependent manner》這篇文章中，作者已篩出被 iBEp 推進不可溶堆的受質，接著要回答一個追問：這些蛋白是天生就容易聚集，還是碰巧被抓進來。為此他們純從序列出發，用 TANGO 聚集傾向、Kyte–Doolittle 疏水性與 Metapredict V2 無序度三種預測，並與未受影響的蛋白比較。這一步吃進差異統計給出的 increased／unaffected 蛋白名單，產出序列生物物理的佐證，替 tau 等受質「本質上偏愛聚集」的詮釋補上一層獨立支持。
