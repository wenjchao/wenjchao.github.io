# 統計與顯著性分析

1. 引用自哪篇 paper: fructose-biosensor-liver-cancer
2. Outline (任務主線): 統計與顯著性分析
3. Method: 
這一步不做任何新實驗，也不進試管——它是套在所有前面實驗結果上的『判決程序』。前面每個數字（HYlight 的比率變化、感測器抓 FBP 的緊度 K_D、質譜測到的 FBP 濃度）都只重複做了幾次（例如 n = 3，有些做到 n = 6），而少少幾次重複之間一定會有落差。所以作者需要一位裁判，判斷『葡萄糖讓比率升高』或『磷酸把 K_D 推大』這種差異是真的，還是幾次重複剛好湊出來的巧合，而這整套判決都在同一套軟體 (GraphPad Prism 10.2.0) 裡跑，確保全篇用同一把尺。呈現數據時，作者會在每根長條上加一條誤差棒，標成『平均值 ± SEM』或『平均值 ± SD』。標準差 (standard deviation, SD) 講的是這幾次重複彼此散得多開，平均值的標準誤 (standard error of the mean, SEM) 則是這個平均值本身有多準，公式為 $\mathrm{SEM}=\mathrm{SD}/\sqrt{n}$。因為要除以重複次數的平方根，SEM 一定比 SD 小，而且重複做越多次、SEM 越小，這也是作者每張圖都要註明用的是哪一個的原因。

要用哪種檢定，取決於一次比較幾組。當作者只比較兩組數字時——例如正常 HYlight 對上抓不到 FBP 的對照版 HYlight Null——就用不成對雙尾 t 檢定 (unpaired two-tailed Student's t test)。它做的事很直觀：把兩組平均值差多少，拿去跟每組自己內部抖動多大相比；兩組平均差很大、各自內部又很穩，這個差就很可能是真的。檢定的底層邏輯是『先假設沒差，再看數據有多打臉這個假設』，這個『其實沒差』的假設叫虛無假設 (null hypothesis)。t 檢定最後吐出的 p 值 (p-value) 回答的正是：如果兩組真的沒差，光靠運氣也湊出眼前這麼大差距的機率有多少——例如 p = 0.01 代表只有 1% 機會能巧合抖出這個差距，作者因此有底氣說差異是真的。至於名稱裡那三個修飾詞各鎖定一個前提：『不成對 (unpaired)』是因為兩組是各自獨立的細胞群、不是同一顆細胞前後量兩次，硬用成對檢定會假裝數字一一對得上而算出錯誤顯著性；『雙尾 (two-tailed)』是升高或降低都算數，比只賭單一方向的單尾檢定保守；『Student's』則假設兩組內部抖動幅度差不多。挑這組保守設定，是為了讓報出來的顯著性不會灌水。

當要一次比較三組以上時——例如飢餓、加葡萄糖、加 oligomycin、加 2-DG 這四個代謝狀態的 FBP 濃度——作者改用單因子變異數分析 (Ordinary One-Way ANOVA)，而不是兩兩硬做很多次 t 檢定。原因在於一個『刮刮樂效應』：每做一次檢定，就算兩組其實沒差，也有約 5% 機率誤報成有差；一次比很多次，『至少誤報一次』的整體機率會迅速累積，比較 m 次時這個整體風險會膨脹成 $1-(1-\alpha)^{m}$。ANOVA 的設計正是先擋這一關——它先用一個全局檢定問『這幾組整體上到底有沒有差』，通過了才准往下做兩兩比較。接著由 Šídák 多重比較校正 (Šídák's Multiple Comparisons Test) 把每一次比較的門檻收得更嚴，改用 $\alpha_{\mathrm{adj}}=1-(1-\alpha)^{1/m}$，剛好抵消次數帶來的膨脹，讓整批比較『至少誤報一次』的總風險回到原本的 5%。少了這道校正會有多糟？若對四個狀態硬做六次 t 檢定，整體誤報機率會從 5% 一路爬到約 26%。這在本文特別危險，因為單細胞的 FBP 濃度本來就散得極開（同樣加葡萄糖，有的細胞十幾、有的高達兩百微莫耳）；數據越散越容易靠運氣湊出假差異，不校正就很可能誤判某兩個狀態顯著不同，讓核心的濃度結論站不住腳。

判決的結果用星號數量標在圖上：* 代表 p<0.05、** 代表 p<0.005、*** 代表 p<0.0005、**** 代表 p<0.00005，沒有差異則標 ns (not significant)；星號越多，代表差距是巧合的機率越低。值得注意的是這套門檻比一般慣例更嚴——常見標法是 ** 代表 0.01、*** 代表 0.001，而這篇每加一顆星就把標準再收緊十倍，是刻意保守的設定。最後回到誤差棒的選擇，它其實牽動讀者怎麼判讀數據：想強調『這批細胞彼此差多少』時該用 SD，因為只有 SD 才反映真實散布；想強調『這個平均值量得多準』時才用會隨重複數縮小的 SEM。這個取捨在本文尤其要緊，因為 SEM 會隨著多量幾顆細胞而不斷縮小、誤差棒能畫得又短又漂亮；如果作者的重點其實是細胞間差異很大，卻改畫 SEM，那條被縮短的誤差棒會讓讀者誤以為每顆細胞都差不多，正好把本文最重要的發現之一——細胞間異質性——給蓋掉。這就是為什麼呈現散布時必須誠實地用 SD，並逐圖註明畫的是哪一種。
4. 工具與材料: 
   - **GraphPad Prism 10.2.0**: 本文所有統計檢定與繪圖使用的單一軟體，確保全篇用同一把尺。
   - **標準差 (standard deviation, SD)**: 描述幾次重複彼此散得多開，反映數據的真實散布。
   - **平均值的標準誤 (standard error of the mean, SEM)**: 描述平均值本身有多準，等於 SD 除以重複次數的平方根，恆小於 SD 且隨 n 增大而縮小。
   - **不成對雙尾 t 檢定 (unpaired two-tailed Student's t test)**: 比較兩組獨立樣本平均值差異的保守檢定；不成對、雙尾、等變異三個前提各鎖定一件事，輸出 p 值。
   - **p 值 (p-value)**: 若兩組其實無差、光靠巧合湊出眼前差距的機率；越小代表差異越難用巧合解釋、越可信。
   - **虛無假設 (null hypothesis)**: 『兩組其實沒差』的預設假設，p 值就是衡量數據對它打臉的程度。
   - **單因子變異數分析 (Ordinary One-Way ANOVA)**: 比較三組以上時先做的全局檢定，先問整體有沒有差，通過才准往下做兩兩比較。
   - **Šídák 多重比較校正 (Šídák's Multiple Comparisons Test)**: ANOVA 後的兩兩比較，用更嚴門檻抵消多次比較造成的偽陽性膨脹，把整體誤報率壓回 5%。
   - **多重比較問題 (multiple comparisons problem)**: 比較次數越多、整體至少誤報一次的機率越高的『刮刮樂效應』。
   - **顯著性星號**: *p<0.05、**p<0.005、***p<0.0005、****p<0.00005，ns 為不顯著；本文門檻比慣例更嚴。
   - **重複次數 (n)**: 每個條件的獨立重複數（如 n = 3、n = 6）；SEM 隨其增大而縮小。
5. 與此篇文章的關係: 
   在《Tracking fructose 1,6-bisphosphate dynamics in liver cancer cells using a fluorescent biosensor》這篇文章中，作者為了判斷各種讀值差異究竟是真實效應還是隨機雜訊，用 GraphPad Prism 建立了一套統一的顯著性檢定架構。由於每個結論都只建立在少數幾次重複上，這套架構依比較的組數選用對應檢定，解決了『重複數少時容易把巧合誤認為真效應』的瓶頸。它吃進前面各實驗算出的比率、K_D 與 FBP 濃度重複值，產出帶顯著性星號的判定，替全篇每一個『組間有差異』的宣稱蓋上一致的品質章。
