# 重組 HYlight 蛋白的表現與兩步層析純化

1. 引用自哪篇 paper: fructose-biosensor-liver-cancer
2. Outline (任務主線): 重組 HYlight 蛋白的表現與兩步層析純化
3. Method: 
純化流程像「代工生產，加上兩道篩選」。先把裝有 HYlight 基因的質體轉進大腸桿菌、養成一大鍋，再加一種訊號分子打開表現開關 (IPTG 誘導)，讓細菌整夜代工造出大量 HYlight；收菌後用超音波把細菌震破 (超音波破菌)，倒出裡面所有蛋白的混合湯。第一道篩選是金屬親和層析 (IMAC)：作者把鎳離子固定在樹脂小珠上，而 HYlight 頭上那串六個組胺酸的把手 (6×His-tag) 會牢牢黏住鎳，混合湯流過時只有帶把手的 HYlight 被扣住，其他雜蛋白沖走；接著用低濃度的咪唑 (imidazole，長得像組胺酸) 擠掉黏得不夠緊的雜質，最後用高濃度咪唑把 HYlight 競爭下來收集。第二道篩選是凝膠過濾層析 (SEC)：管柱裡塞滿多孔的珠子，大分子鑽不進孔、走捷徑先流出，小分子鑽進孔裡繞遠路後流出，於是按體型分開；完好單顆的 HYlight (單體) 體型一致，會集中成單一乾淨的峰，萬一彼此黏成團或兩兩相黏就會多出雜峰，所以看到單一峰就確認拿到了均一的單體。最後以 Bradford assay 量出蛋白濃度備用。

幾個條件都是為了拿到「完好可用」的蛋白。誘導刻意用偏低溫、過夜的慢工，是因為造得太快 HYlight 會來不及摺疊、糾成沒用的沉澱團 (包涵體)，而它內含一個要慢慢成熟的發光核心，尤其吃低溫慢工。裂解液裡的添加物則像一組保鏢：還原劑 (DTT) 維持蛋白該有的化學狀態，蛋白酶抑制劑 (PMSF、Leupeptin) 攔住細菌自己的分解酵素、以免 HYlight 被咬碎，DNaseI 搭配鎂離子把破菌後黏糊糊的 DNA 剪斷、降低黏度，鹽 (NaCl) 幫蛋白保持溶解。而之所以非得先做出純蛋白，是因為只有把 HYlight 泡在一杯成分完全由你決定的緩衝液裡，才能一次只動一個變因——單獨加 FBP、單獨改 pH、單獨加磷酸或鹽——看它各自如何影響讀數、畫出乾淨的標準曲線；細胞內部是一鍋你無法逐項調控的複雜湯，什麼都同時在變，拆不出到底是誰在干擾。純蛋白平台因此是後面拆解干擾、重建胞質、反推濃度的地基。

有兩個地方一失手就前功盡棄。貪快用高溫猛誘導，HYlight 會糾成不發光的沉澱團 (包涵體)，整批報廢、純化不出可用的蛋白。省掉凝膠過濾這一步，混在裡面的聚集團塊、兩兩相黏的雙分子、以及前一步殘留的咪唑都會混進實驗，量出來的親和力與光譜通通失真；而且這一步還順便把蛋白換進一套統一的緩衝液，少了它，每批蛋白泡的湯都不一樣，後面的滴定基準就對不齊。
4. 工具與材料: 
   - **IPTG 誘導**: 加入乳糖類似物 IPTG 打開 pQE-30 上的表現開關，誘導大腸桿菌大量造出 HYlight。
   - **超音波破菌 (sonication)**: 以脈衝式超音波震破細菌、釋出胞內蛋白，ON/OFF 交替以避免產熱使蛋白變性。
   - **金屬親和層析 (IMAC)**: 用固定在樹脂上的 Ni²⁺ 抓住 6×His-tag，以咪唑梯度洗雜、沖提，專一純化目標蛋白。
   - **咪唑 (imidazole)**: 與組胺酸相似的競爭分子，低濃度洗去弱結合雜質、高濃度將 His-tag 蛋白自鎳珠置換下來。
   - **凝膠過濾層析 (SEC, Superdex 200)**: 依分子體型分離的第二道純化；單一對稱峰確認 HYlight 為均一單體、無聚集。
   - **蛋白護命添加物 (DTT / PMSF / Leupeptin / DNaseI)**: 裂解液中的還原劑、蛋白酶抑制劑與核酸酶，分別維持化學狀態、防降解、降黏度。
   - **Bradford assay**: 比色法測定純化後的蛋白濃度，供後續滴定定量使用。
5. 與此篇文章的關係: 
   在《Tracking fructose 1,6-bisphosphate dynamics in liver cancer cells using a fluorescent biosensor》這篇文章中，作者需要一批成分可控的純 HYlight 來繪製 FBP 反應標準曲線。他們在大腸桿菌大量表現後，以金屬親和層析與凝膠過濾兩步純化，取得高純度的單體蛋白，解決了「細胞內環境無法逐項調控、拆不出干擾因子」的瓶頸。它往上游取用細菌表現質體，往下游交出乾淨的純蛋白，是所有體外光譜與滴定分析的原料基礎。
