# 活細胞共軛焦比率成像追蹤 FBP 動態與糖解專一性

1. 引用自哪篇 paper: fructose-biosensor-liver-cancer
2. Outline (任務主線): 活細胞共軛焦比率成像追蹤 FBP 動態與糖解專一性
3. Method: 
這一步把 HYlight 當成裝在每顆活細胞裡的即時儀表，用共軛焦顯微鏡逐格讀。作者對同一批細胞輪流打兩種激發光 (488 nm 與 405 nm)、各拍一張並收集細胞發出的綠光，每 2 分鐘重複一次、拼成縮時影片。HYlight 抓到 FBP 時，這兩種激發光點亮它的效率會此消彼長，因此把兩張亮度相除得到的比率 ($R = F_{488}/F_{405}$) 就代表當下 FBP 的多寡；作者再手動把畫面裡每一顆細胞圈起來 (單細胞圈選 ROI) 分別讀值，於是每顆細胞都有自己的一條 FBP 曲線。成像刻意在 37°C、無 CO₂ 下進行：一般培養液靠 CO₂ 穩住酸鹼，一離開培養箱 pH 就會漂，而 HYlight 的發光核心對酸鹼敏感、pH 一飄讀數就假，所以改用一種靠 HEPES 自撐酸鹼、不靠 CO₂ 的成像培養液。用比率、而不是單看亮度也是同樣道理：某顆細胞剛好造比較多 HYlight、或拍久了螢光褪色，都會改變亮度卻與 FBP 無關，把兩種激發光相除就能把這些干擾約分掉。核心的讀值測試是糖解壓力測試：先讓細胞餓一小時把基礎壓到最低，再依序加葡萄糖 (供料，糖解跑起來、FBP 上升)、oligomycin (堵住細胞另一套用氧發電的引擎，逼它把發電全押在糖解上、FBP 再衝)、2-DG (假葡萄糖，混進去把糖解產線卡死、FBP 掉下來)，訊號能升能降，正好證明讀數會即時、可逆地跟著糖解流量走。

最關鍵的一問是：FBP 是糖解和糖質新生兩條路共用的分子，HYlight 到底量的是哪一條？糖解由一個叫 PFK-1 的酵素製造 FBP，反向的糖質新生則由另一個叫 FBPase-1 的酵素拆掉 FBP。作者用一組「正反各擋一刀」的藥來鎖定：先把細胞逼進糖質新生狀態，這時加糖，FBP 幾乎不升；接著擋掉負責拆 FBP 的 FBPase-1，FBP 立刻回升到正常水平，證明剛才不升是代謝真的轉了向、而不是細胞病懨懨；反過來，擋掉在糖解端造 FBP 的 PFKFB3 (用抑制劑 3PO)，正常培養基裡 FBP 應聲下降、糖質新生培養基裡卻沒反應。兩邊夾擊，把 HYlight 的讀數乾淨地釘死在「糖解流量」上。作者還測了病理狀態：用 DMOG 讓細胞的缺氧警報蛋白 HIF-1α 堆積、使細胞誤以為缺氧而把代謝傾向糖解 (這比真的抽掉氧氣好操作)，HYlight 果然讀到基礎糖解活性上升，而且此時再加糖反應反而變弱，像產線已接近滿載。順帶一提，葡萄糖對比率畫成的曲線「Hill 係數約 1」，代表這是一條單純的雙曲飽和關係——加越多糖、FBP 越高，直到抓滿為止。

有兩個對照與前置步驟省不得。少了 HYlight Null 這個抓不到 FBP 的對照版，就無法排除「訊號其實是加藥、酸鹼或鹽度直接晃動了感測器」的假象；作者讓 Null 版跑同樣流程，它基礎值約 0.7、對加糖加藥全無反應，反證正常版的變化真的來自 FBP，而純化的 HYlight 直接泡 oligomycin 或 2-DG 也不動，進一步佐證這些藥不會直接騙感測器。至於不先飢餓一小時，細胞基礎 FBP 就偏高、儀表本來就快滿了，再加糖也看不出明顯上升，動態範圍被壓扁、整個測試失去鑑別力。
4. 工具與材料: 
   - **共軛焦顯微鏡 (confocal microscopy)**: 以針孔濾掉離焦雜光、做出清晰光學切面的顯微鏡 (Nikon Ti2 + AX)，供單細胞即時成像。
   - **兩波長激發比率 ($R = F_{488}/F_{405}$)**: 以 488 與 405 nm 各激發一次、亮度相除；相除可約分掉表現量、光漂白等與 FBP 無關的干擾。
   - **糖解壓力測試 (glycolytic stress test)**: 飢餓後依序加 glucose、oligomycin、2-DG，逼糖解上下起伏，驗證讀數即時且可逆。
   - **PFK-1 / FBPase-1**: 分別為糖解中製造 FBP 的限速酵素，與糖質新生中拆掉 FBP 的酵素；FBP 為兩路共用的分子。
   - **FBPase-1 抑制劑 / PFKFB3 抑制劑 3PO**: 正反各擋一刀的藥：分別阻斷 FBP 的消耗與生成，用以鎖定 HYlight 讀值歸屬於糖解流量。
   - **DMOG / HIF-1α**: DMOG 使缺氧警報蛋白 HIF-1α 堆積、模擬缺氧並上調糖解，用以測試病理狀態下的感測靈敏度。
   - **Hill 係數約 1**: 葡萄糖-比率曲線呈單純雙曲飽和、無合作效應，關係為加糖越多 FBP 越高直到飽和。
5. 與此篇文章的關係: 
   在《Tracking fructose 1,6-bisphosphate dynamics in liver cancer cells using a fluorescent biosensor》這篇文章中，作者要在單顆活細胞裡即時追蹤糖解快慢。他們以共軛焦比率成像讀取 HYlight 的 488/405 訊號，並用糖解壓力測試與正反抑制劑，解決了「FBP 同屬糖解與糖質新生、讀值路徑歸屬不明」的瓶頸。它往上游取用裝好感測器的活細胞，往下游交出經證實只跟隨糖解流量、可逆的單細胞 FBP 動態曲線。
