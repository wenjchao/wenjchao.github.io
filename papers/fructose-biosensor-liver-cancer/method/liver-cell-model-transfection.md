# 肝細胞模型建立與 HYlight 脂質體轉染

1. 引用自哪篇 paper: fructose-biosensor-liver-cancer
2. Outline (任務主線): 肝細胞模型建立與 HYlight 脂質體轉染
3. Method: 
這一步的目標，是把 HYlight 感測器裝進一批健康的活肝細胞裡，當作後面所有成像實驗的舞台。細胞來源有兩類。一類是直接從活小鼠肝臟取下的原代小鼠肝細胞：肝細胞本來被膠原蛋白黏在一起、又彼此手牽手連著，作者用標準的兩步膠原蛋白酶灌流法 (two-step collagenase perfusion)，把溶液順著大血管 (下腔靜脈 vena cava) 灌進整個肝臟，先用不含鈣的溶液鬆開需要鈣才牢固的細胞連結，再灌入會咬斷膠原蛋白的酵素消化掉膠原基質，肝細胞就一顆顆游離出來、而且仍活著。另一類是三株好養的人類肝癌細胞株 (HepG2、HLE、Huh6)。兩者都種進底部為光學級透明塑膠的成像小室 (µ-Slide 8 Well ibiTreat)，方便顯微鏡從下方拍攝；再用一種帶正電的油性小球把感測器質體包起來送進細胞 (Lipofectamine 3000 脂質體轉染)：DNA 帶負電、被油球整包裹住，這團複合體與細胞膜融合或被細胞吞入，細胞便暫時造出 HYlight。之所以選脂質體而不用病毒，是因為成像只需要感測器暫時表現幾天，脂質體轉染又快又省事。

幾個設計選擇都有講究。感測器一定要表現在細胞質，因為糖解整條產線、以及要量的 FBP 都在細胞質這一格裡；pCS2+ 質體驅動的正是不帶定位標籤、直接留在胞質的表現，感測器才能跟 FBP 泡在同一鍋湯裡讀到真值。之所以同時採用原代肝細胞和三株癌細胞，是為了兼顧兩件事：原代小鼠肝細胞最貼近真實肝臟生理，卻嬌貴難養；癌細胞株好操作，又剛好涵蓋不同來源的肝癌、能呈現細胞之間燒糖速度的巨大差異。轉染的時間點也依細胞耐命程度而不同：耐操的癌細胞株等貼穩一天再轉染、24 h 後換液；原代肝細胞則像現摘的鮮花，一離開肝臟就走下坡、還會慢慢忘掉自己是肝細胞 (去分化)，所以種下才 2 h、剛貼住就轉染，12 h 就換液，搶在它最健康的短窗口把感測器裝好。

有兩個容易翻車的地方作者特別把關。第一，剛分離的原代肝細胞常混著死細胞，若不剔除就成像，讀到的 FBP 會是一團被污染的亂數；作者用死活雙染來分辨：Hoechst 33342 能穿透任何細胞膜、把所有細胞核都染上，Propidium Iodide (PI) 卻只鑽得進膜已破洞的死細胞，同時被兩色染到的就排除。第二，同一個蛋白可以用不同的 DNA 拼字寫出來、而各物種偏好的拼法不同，所以小鼠肝細胞用的是為小鼠調過拼字的構築 (取自 Koberstein 等人 2022)，人類細胞則用人類版；若把人類版硬塞進小鼠細胞，翻譯會卡頓、感測器造得太少，螢光就弱到量不準。
4. 工具與材料: 
   - **兩步膠原蛋白酶灌流法 (two-step collagenase perfusion)**: 從活體肝臟分離原代肝細胞的標準法：先灌無鈣溶液鬆開細胞連結，再灌膠原蛋白酶消化膠原基質，把肝細胞一顆顆釋放且保活。
   - **原代小鼠肝細胞 (primary hepatocytes)**: 直接自小鼠肝臟取下的肝細胞，最貼近真實生理，但嬌貴、壽命短。
   - **HepG2 / HLE / Huh6**: 三株可長期培養的人類肝癌細胞株，代表不同來源的肝癌，用以呈現細胞間代謝異質性。
   - **µ-Slide 8 Well ibiTreat**: 底部為光學級透明塑膠的八孔成像小室，讓共軛焦顯微鏡能從下方清楚拍攝細胞。
   - **Lipofectamine 3000**: 帶正電的脂質體轉染試劑，把帶負電的質體 DNA 包成油-DNA 複合體送進細胞，達成瞬時表現。
   - **pCS2+ 質體**: 哺乳類細胞表現載體，驅動 HYlight 於胞質表現 (Addgene #136466)。
   - **Hoechst 33342 / Propidium Iodide (PI)**: 死活雙染組合：Hoechst 染所有細胞核，PI 只進膜破損的死細胞，用以剔除死細胞。
   - **密碼子最佳化構築 (codon-optimized construct)**: 依宿主物種偏好的 DNA 拼字調整過的基因；小鼠肝細胞用小鼠版 (Koberstein 2022) 以確保高效表現。
5. 與此篇文章的關係: 
   在《Tracking fructose 1,6-bisphosphate dynamics in liver cancer cells using a fluorescent biosensor》這篇文章中，作者的大目標是在單顆活肝細胞裡即時量出糖解快慢。要達成這件事，第一步得先建立肝細胞模型並用脂質體轉染 (Lipofectamine 3000) 把 HYlight 送進胞質。這一步解決了「要有健康、且體內裝好感測器的活細胞」這個前提瓶頸，往上游吃進小鼠肝臟與現成癌細胞株，往下游交出一批可直接上顯微鏡的成像樣本，是後續所有活細胞 FBP 成像的生物基礎。
