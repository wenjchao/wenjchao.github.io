# 皂素通透化的細胞內 FBP 劑量-反應校正

1. 引用自哪篇 paper: fructose-biosensor-liver-cancer
2. Outline (任務主線): 皂素通透化的細胞內 FBP 劑量-反應校正
3. Method: 
這一步在真細胞裡直接量 HYlight 對 FBP 的握力。作者把表現 HYlight 的人類肝癌細胞 (HepG2) 先餓一小時，再把不同濃度的 FBP 加進培養液，接著加入低劑量的皂素 (saponin) 在細胞膜上戳洞，讓外面的 FBP 灌進細胞；用共軛焦顯微鏡持續量每顆細胞的激發比率 ($R = F_{488}/F_{405}$)，直到皂素把細胞弄到螢光消失，每個濃度都取讀到最高比率的那些細胞 (最大比率 ROI)，再把外加 FBP 濃度對比率畫成一條劑量-反應曲線、算出感測器在真細胞環境裡的握力 (細胞內表觀 $K_D$)。之所以非通透不可，是因為 FBP 身上帶好幾個磷酸、電荷很重，穿不過完整的細胞膜——不通透時 FBP 只能待在細胞外、碰不到住在胞質裡的 HYlight，比率完全不動 (Fig. S5A)，這正好當作反證「膜是屏障」的陰性對照。皂素之所以能打洞，是因為它專門去抓細胞膜裡的膽固醇、和膽固醇糾成一團而撐出小孔；說它「選擇性」，是因為最外層的質膜膽固醇特別多、而內部各胞器的膜膽固醇少，用低劑量 (50 µM) 時它會優先在外層質膜上開路，讓 FBP 這種小分子鑽進胞質，卻還來不及把整顆細胞溶爛，留下一個剛好夠讀數的短暫窗口。

為什麼試管裡已經量到 $K_D$≈44 µM，還要多做這一步？因為 44 µM 是在人工調出來的「模擬胞質水」裡量的，你還是得回答一句：真細胞內部真的長這樣嗎？皂素通透化正是去對這個答案——它把已知濃度的 FBP 直接送到住在真細胞胞質裡的 HYlight 面前，當場量出細胞內的握力約 61 µM。這個 61 µM 和體外的 44 µM 很接近，等於幫前面那杯仿真水發了一張「確實像細胞內」的認證，於是那條標準曲線就可以放心拿去翻譯細胞的螢光讀數；這一步就是體外曲線與細胞讀值之間的橋。操作細節也有講究：先加 FBP、再加皂素，是為了孔一打開，外面就有一個已知濃度的 FBP 立刻湧進去、方便對應；每個濃度取讀到最高比率的細胞，是因為不同細胞開孔的時間點不一樣，取最大比率代表那顆細胞已經充分進料、達到平衡；而皂素開洞後會越破越大、感測器終究會漏光，作者一路量到螢光消失，正是為了完整抓住從進料到流失的整段變化窗口、不漏掉真正的高點。

皂素是一把雙面刃：加太多，膜被溶爛、HYlight 瞬間漏光，根本來不及讀；加太少，膜沒開洞、FBP 進不去、比率不動，等於白做 (就跟不通透的對照一樣)，所以 50 µM 是拿捏過的甜蜜點。此外，通透這個動作本身會改變細胞內外的鹽度、可能自己晃動一下讀數；作者用抓不到 FBP 的 HYlight Null 當對照——它在同樣通透下只有很小的變化 (純粹來自離子強度)，這就反證了正常版隨 FBP 上升的訊號真的來自抓到 FBP，而不是通透的副作用。
4. 工具與材料: 
   - **皂素選擇性通透化 (saponin permeabilization)**: 皂素抓住膜上膽固醇撐出孔洞；質膜膽固醇多，低劑量 (50 µM) 優先在外層開路，讓小分子進入胞質。
   - **FBP 不透膜**: FBP 帶多個磷酸、電荷重，無法自行穿越完整質膜；不通透時比率不變，作為膜屏障的陰性對照。
   - **細胞內表觀 $K_D$ (≈61 µM)**: 在真細胞環境中量得的握力，與體外重建的 44 µM 相近，驗證體外模擬胞質有效。
   - **活細胞激發比率 ($R = F_{488}/F_{405}$)**: 共軛焦下以 488 與 405 nm 激發的比率讀數，取各條件最大比率 ROI 以代表充分進料的平衡值。
   - **HYlight Null 對照**: 抓不到 FBP 的對照版，在通透下僅微小變化 (源自離子強度)，反證 FBP 依賴的訊號為真。
5. 與此篇文章的關係: 
   在《Tracking fructose 1,6-bisphosphate dynamics in liver cancer cells using a fluorescent biosensor》這篇文章中，作者需要確認體外重建的環境校正曲線是否真等於細胞內所見。他們用 50 µM 皂素選擇性通透細胞膜，讓外加 FBP 直達胞內 HYlight，量得細胞內表觀 $K_D$ 約 61 µM，解決了「體外標準曲線能否套回真細胞」的驗證瓶頸。它往上游取用體外重建曲線與外加 FBP，往下游交出一個橋接體外與細胞讀值的可信換算基礎。
