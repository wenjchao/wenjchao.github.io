# 可複製機器的計算理論與容錯編碼

1. 引用自哪篇 paper: foundations-engineering-biology
2. Outline (任務主線): 可複製機器的計算理論與容錯編碼
3. Method:
   要真正「設計」出我們能理解的可複製生物機器，作者認為得回去接上三套現成、卻一直沒被生物工程借用的理論，它們原本都來自計算與通訊領域。「可靠計算 (reliable computing with unreliable components)」研究的是：手上的零件各自都不太可靠、會出錯，怎麼組出一台整體仍然可靠的機器。「容錯編碼 (error detection and correcting codes)」研究的是：怎麼把資訊編碼，讓它被抄錯時能被抓出來、甚至自動補回正確的值。「自我複製自動機 (self-replicating automata)」則是數學家 von Neumann 很早就建立的理論（收在他的 Collected Works）——他用純數學問：一台機器要具備哪些零件與指令，才能不靠外力、自己造出一台一模一樣的自己？這正是細胞照著 DNA 複製出下一個細胞每天在做的事。
   這兩套計算理論之所以特別適合借來對付生物，是因為生物的毛病剛好就是它們在處理的問題。生物的零件（蛋白質、基因線路）本來就吵雜、會出錯，對應「用不可靠零件組出可靠機器」的可靠計算；而複製 DNA 時必然會抄錯，對應「把資訊編碼好、讓抄錯能被抓出來補回」的容錯編碼。更關鍵的是，大自然其實早就在做這件事：生物會把「複製時的錯誤偵測與修正」調校到剛好配合自身的適應度 (fitness)。作者引了研究佐證（Carroll 2005），其中 Rutherford 與 Lindquist 發現一種叫 Hsp90 的蛋白質能像「演化電容器」一樣，平時把累積的變異藏住、壓力來時才一次釋放（Nature 1998）。既然天然系統做得到，把它理論化、拿來設計就有了依據。
   為什麼非得補上這套理論不可？因為如果放著不管，一個精心設計又會自己繁殖的生物系統，會自己把你的設計改掉。它每繁殖一代就抄錯一點點，錯誤一代代累積；更糟的是，你額外加進去的功能對細胞來說通常是負擔，於是那些「偷偷把這個功能弄壞」的變異反而長得更快、更省力，被天擇一路放大。結果是你設計的行為在繁殖幾代之後慢慢走樣，最後整個失效。這正是第四個、也是過去工程經驗完全沒碰過的挑戰——演化；少了可複製機器的理論，你對這種漂移束手無策。
   不過作者也坦白，學會設計「可理解的可複製機器」這件事，我們可能根本學不會，所以先備一條退路才穩妥：改採與複製解耦的拋棄式系統。做法是乾脆設計一種不讓它自己繁衍下一代、用完就報廢的生物系統——把系統設計和「直系傳承、而且複製時會帶錯」這件事切開。它能繞過演化靠的是最乾脆的邏輯：演化的麻煩來自「一代傳一代、變異越攢越多」，而拋棄式系統根本不傳代，這個麻煩自然就不存在。這條路之所以在今天變得可行，正是搭上了便宜的 DNA 合成——不必靠生物繁殖來量產，每次要用就重新合成一批全新、沒被變異污染的系統。
4. 工具與材料:
   - **reliable computing with unreliable components (可靠計算)**: 研究怎麼用各自會出錯、不可靠的零件，組出一台整體仍然可靠的機器；對應生物零件吵雜易錯的毛病。
   - **error detection and correcting codes (容錯編碼)**: 把資訊編碼好，讓它被抄錯時能被抓出來、甚至自動補回正確值；對應 DNA 複製必然抄錯的問題。
   - **self-replicating automata (自我複製自動機)**: 數學家 von Neumann 建立的理論，研究一台機器要具備哪些零件與指令才能自己造出自己的副本；正對應細胞照 DNA 複製下一代。
   - **fitness (適應度)**: 生物生存與繁殖的相對優勢；天然系統會把複製時的錯誤偵測與修正調校到配合自身適應度。
   - **Hsp90 (演化電容器)**: Rutherford 與 Lindquist 發現的一種蛋白質，能像電容器一樣平時把累積的變異藏住、壓力來時才一次釋放（Nature 1998），是自然界已在調校複製錯誤的佐證。
   - **disposable biological systems (拋棄式生物系統)**: 退而求其次的設計：做成不繁衍、用完就報廢的系統，把設計和「直系傳承與帶錯複製」解耦，以繞過演化；前提是 DNA 合成夠便宜。
5. 與此篇文章的關係:
   在《Foundations for engineering biology》這篇文章中，作者的大目標是讓生物工程變成可靠的例行工程，而這一節專攻前三大工程理念都繞不過的第四個難題——演化。他主張借入 von Neumann 的自我複製自動機理論，為「如何設計出可理解又可複製的生物機器」這塊完全缺席的基礎補課；可靠計算與容錯編碼則用來對付零件不可靠、複製會抄錯的毛病。萬一這些始終學不會，退路就是改做不繁衍、與複製解耦的拋棄式系統。
