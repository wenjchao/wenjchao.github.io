# N1／N2 亞型的功能分類框架與抗腫瘤讀出指標

1. 引用自哪篇 paper: engineered-neutrophil-therapeutic-strategies
2. Outline (任務主線): N1／N2 亞型的功能分類框架與抗腫瘤讀出指標
3. Method:
   這個子項替中性球在腫瘤裡的角色建立一套分類法，方法很簡單——按「對腫瘤是幫忙還是搗亂」把它們分成兩型：會攻擊腫瘤的叫 N1 型 (抗腫瘤)，反過來幫腫瘤壯大的叫 N2 型 (促腫瘤)。這個二分法是刻意仿照免疫學界早已熟悉的巨噬細胞 M1／M2 分類，讓讀者能一眼套用既有的直覺。
光把細胞分成兩型還不夠，作者更定義了一組「N1 到底有多會打腫瘤」的可量化讀出指標 (Figure 2c)。N1 型的抗腫瘤火力來自幾個具體動作：一是抗體依賴的細胞毒殺 (ADCC)——認出並貼上被抗體標記的腫瘤細胞後把它殺掉；二是釋放一系列武器，包括中性球彈性蛋白酶 (NE，一種能分解蛋白的酵素)、活性氧 (ROS)、各種細胞因子，以及中性球胞外誘捕網 (NETs，中性球撒出的一張黏住目標的網)。這些都是可以實際偵測、計量的功能輸出，而不是抽象形容。
為什麼要特地把這些讀出指標列清楚？因為評估「把促瘤中性球策反成抗瘤」這件事時，最容易犯的錯是只看細胞比例、憑感覺說「好像變抗瘤了」。作者點出目前這類表型調控的轉化效率 (conversion efficiency，被成功策反的比例) 仍不理想，而這個「不理想」本身就得靠客觀指標才量得出來。有了 ADCC、NE／ROS／NETs 釋放這組可打分的功能座標，研究者才能明確回答「一次極化到底成功了幾成」，把表型調控技術成不成熟這件事，從定性描述變成可衡量的缺口。
4. 工具與材料:
   - **N1 型 / N2 型**: 按對腫瘤的抑制/促進作用劃分的中性球亞型，前者抗腫瘤、後者促腫瘤。
   - **M1／M2 類比**: 借用巨噬細胞既有的 M1/M2 二分框架來理解 N1/N2。
   - **ADCC (抗體依賴細胞毒殺)**: N1 認出被抗體標記的腫瘤細胞後將其殺死的效應，是抗腫瘤讀出之一。
   - **中性球彈性蛋白酶 (NE)**: N1 釋放的一種分解蛋白的酵素，屬抗腫瘤功能讀出。
   - **中性球胞外誘捕網 (NETs)**: 中性球撒出、可黏住目標的網狀結構，屬 N1 功能讀出。
   - **轉化效率 (conversion efficiency)**: 衡量促瘤中性球被成功轉成抗瘤型比例的量化指標，目前仍不理想。
5. 與此篇文章的關係:
   在《Engineered neutrophil, an emerging immune therapeutic strategy》這篇綜述中，作者需要一套客觀標準來判斷『把促瘤中性球策反成抗瘤』到底成不成功。為此他們用促瘤／抗瘤的功能二分建立 N1／N2 分類（仿巨噬 M1／M2），並定義 ADCC、NE／ROS／NETs 釋放等可量化讀出。它吃進表型極化實驗的細胞，產出可打分的功能座標，讓轉化效率不再只憑細胞比例定性判斷。
