# 細胞標記、活性與功能性驗證

1. 引用自哪篇 paper: wideband-indium-phosphide-nanolasers
2. Outline (任務主線): 細胞標記、活性與功能性驗證
3. Method:

   作者要證明 PEI-矽殼-InP 粒子在 HeLa 細胞內共培養 72 h 不會殺細胞，用兩種互補實驗。第一是 Cell Counting Kit-8 (CCK-8) 活性 assay：試劑核心 WST-8 是無色四唑鹽，活細胞線粒體裡的脫氫酶 (dehydrogenases) 能把它還原成橙色的「甲月替 (formazan)」；橙色濃度用分光光度計量 450 nm 吸光值 (OD450)——數字越高、活細胞越多。實驗設計是 3000 cells/well 的 HeLa 起始密度、加入 6000 particles/well 的 730 nm 粒子 (batch iii，≈10⁶ particles/mL)，於 24、48、72 h 各讀一次 OD450，與不加粒子的對照組比對；結果三個時間點都沒有顯著差異。第二是 Live/Dead assay——用兩種染劑同時染 (活細胞內的酯酶會把一種切開發綠螢光、破膜死細胞讓另一種進去跟核酸結合發紅螢光)，在顯微鏡下直接看每個粒徑批次的細胞；作者對五個尺寸批次逐一做 72 h Live/Dead 對照，確認即使是最小的 480 nm 粒子也沒有集中殺附近的細胞。之所以用 batch iii 做 CCK-8 定量，是因為它閾值最低、線寬最窄、內化率高，是未來多細胞標記的主力批次；biocompatibility 的關鍵化學其實是 PEI 表面電荷而非尺寸，一個代表性批次已足夠。

   另一件關鍵是「粒子進到細胞裡後長時間發雷射，波長會不會漂」。作者把 100 nm 矽殼包住的 560 nm 粒子塞進 HeLa 細胞質，用 10 kHz 重複率、連續泵浦到累積 10⁶ 次脈衝 (相當於 100 秒不間斷)——實測波長漂移 <0.1 nm。這個門檻是刻意挑的高值：比典型量測所需時間多好幾個數量級，讓潛在的失敗模式如果會發生就一定要在 100 秒內暴露出來。之所以能撐這麼久，是因為單脈衝能量僅 27 pJ、平均功率遠低於 mW 級，泵浦強度全程控制在 InP 材料損傷閾值 (~8 mJ cm⁻²，來自 200 nm 非雷射粒子的 PL 藍移實驗) 以下。若不慎超過此閾值，InP 表面會被高能光子打出缺陷、增益下降、波長漂移可能超過 1 nm，「細胞內波長穩定 < 0.1 nm」就不成立；另一個常見失敗是連續照 100 秒的過程中細胞移動或粒子沉降，粒子跑出 4 µm 光斑收不到訊號，對策是保持自動對焦或間歇檢查影像。

   既然厚殼版粒子的波長對環境不敏感、可當條碼；反過來的「不塗殼版」就能拿來做即時折射率感測。作者用乙醇 (n = 1.36) 對水 (n = 1.33) 的 0.03 折射率差當標準測試液。實驗設計是在玻璃底皿裡裝 100 µL 水、放兩顆不塗殼粒子；等波長穩定後加 20 µL 乙醇、量到第一次波長漂移，再加 20 µL 乙醇量第二次漂移。實測 mean shift 分別為 0.28、0.30 nm (第一次) 與 0.22、0.19 nm (第二次)，跟 FDTD 模擬預測的 0.29／0.22 nm 幾乎完美吻合；20 顆粒子統計後平均 0.27 nm ± 0.05 nm。這條數據把「同一材料同一設備、只靠殼厚就能切換條碼 vs. 感測兩種功能」證得清清楚楚。

   另一個更嚴苛的感測示範是細胞凋亡。作者用強紫外光照射 HeLa 細胞誘導程序化死亡 (apoptosis)——細胞主動啟動蛋白酶把自己拆解掉的過程。他們挑三顆位置各異的粒子同時觀察波長變化：一顆貼在細胞膜外 (作為「沒進細胞質」的對照)，凋亡前後波長沒動、感測到的是水；一顆在細胞質內的破裂區——凋亡時該處蛋白質局部凝集、$n$ 升高 $\Delta n = 0.016$，波長紅移 1.14 nm；一顆在細胞質的突起結構——細胞質往外凸出時局部含水量變多、$n$ 降低 $\Delta n = -0.009$，波長藍移 0.67 nm。三顆粒子紅、藍、不動三種響應同時被抓到，展示 InP 粒子能作為「即時、單細胞、局部」的折射率感測器。

4. 工具與材料:
   - **CCK-8 (Cell Counting Kit-8)**: 以 WST-8 → 橙色 formazan 反應量活細胞代謝活性，讀 OD450；3000 cells/well + 6000 particles/well，24/48/72 h 三時間點。
   - **Live/Dead assay**: 活細胞酯酶切綠螢光 + 死細胞破膜紅螢光核酸染色，五個尺寸批次逐一做 72 h 對照。
   - **HeLa 培養**: DMEM + 10% FBS + 1% antibiotic-antimycotic，37 °C／5% $\mathrm{CO_2}$，購自 ATCC。
   - **GFP-4T1 培養**: RPMI-1640 + 10% FBS + 1% antibiotic-antimycotic，購自 ATCC，用於後續活體實驗。
   - **細胞內光譜穩定性**: 100 nm 矽殼、10 kHz、10⁶ 次脈衝 (100 秒) 下波長漂移 <0.1 nm，證明矽殼把外界折射率屏蔽住。
   - **乙醇折射率感測**: 100 µL 水 + 2×20 µL 乙醇加入，20 顆粒子平均 shift 0.27 nm ± 0.05 nm，符合 FDTD 預測。
   - **UV-induced apoptosis**: 強紫外光誘導 HeLa 凋亡；細胞質破裂區紅移 1.14 nm ($\Delta n = 0.016$)、突起結構藍移 0.67 nm ($\Delta n = -0.009$)，膜外對照無變化。
   - **材料損傷閾值 (~8 mJ cm⁻²)**: 由 200 nm 非雷射粒子的 PL 藍移實驗量到；泵浦強度控制在此值以下才不會把 InP 表面打壞。

5. 與此篇文章的關係:

   在《Wideband Tuning and Deep-Tissue Spectral Detection of Indium Phosphide Nano-Laser Particles》這篇文章中，作者為了證明 PEI-矽殼-InP 粒子能安全、穩定地當細胞內雷射條碼並同時具備折射率感測潛力，用 CCK-8、Live/Dead、10⁶ 脈衝光譜穩定性、乙醇與 UV apoptosis 感測四類實驗做全面驗證；它解決了「新奈米雷射能不能真的在活細胞裡工作、會不會殺細胞、能不能拿去做動態感測」的三重生醫可行性瓶頸，把 batch ii/iii 的粒子直接交給下游的活體小鼠光譜偵測實驗使用。
