# Lumerical FDTD 與 Mie 散射模擬

1. 引用自哪篇 paper: wideband-indium-phosphide-nanolasers
2. Outline (任務主線): Lumerical FDTD 與 Mie 散射模擬
3. Method:

   為了獨立驗證第 3-A 節那組閉合式解析模型有沒有把 WG 模抓對，作者跑了一輪電磁全波模擬——把奈米盤附近的空間切成密密麻麻的小網格，讓電腦依序算每一格在下一個時刻的電場、磁場長什麼樣，等於「把馬克斯威方程一格一格數值時序展開」，這種方法叫做有限差分時域法 (finite-difference time-domain, FDTD)；他們用商用套件 Lumerical 執行。閉合公式只能給近似答案，FDTD 不做近似，能同時吐出 Q 因子、模階、近場影像、遠場輻射花紋與折射率靈敏度，正好逐項驗證公式。

   根據想問的問題，作者用了兩種不同的激發源。要模擬「遠處平面波打進來被粒子彈開」的 Mie 散射題目時，他們從外部丟一束平面波進來，並用一種能自動扣掉入射光只保留散射光的分區設定 (total-field / scattered-field, TFSF)，直接讀到散射能量在哪些波長最強。想看粒子本身內部有哪些模時，作者改把一顆小小的電偶極或磁偶極塞進盤子裡當「內建的發射天線」，凡是能被激起的 WG 模就會共振發亮。得到共振後，作者再把一堆 2D 場感測器像千層蛋糕疊起來組出 3D 近場影像 (例如 Figure 2h 的 m = 7 環形圖)；同時用一個把粒子完整包起來的盒狀感測器 (box monitor) 統計所有出射能量、反推出遠場輻射花紋，再拿去和相機拍到的環狀發射對照 (Figure 2i、2j)。近場證明「模是什麼」，遠場證明「相機看到的花紋確實由這個模發出」。

   Q 因子在頻域看是「共振峰有多窄」，在時域看是「電磁能量衰減得多慢」，數學上等價。低 Q 模（例如 batch i 的 Q ≈ 80）能量掉得快、共振峰又寬又矮，模擬短短跑完就能直接量半高全寬代入 $Q=\omega_{\mathrm{res}}/\Delta\omega_{\mathrm{res}}$。高 Q 模（例如 batch v 的 Q ≈ 360）峰很窄但衰減也慢，模擬時間窗內能量還沒衰完；若這時還硬量半高全寬，時域訊號被截斷會讓頻譜「假性變寬」、Q 被嚴重低估。作者改看時間軸上電場振幅指數往下掉的斜率 $\tau$，代入 $Q=\omega_{\mathrm{res}}\tau/2$ 反推。這條 FDTD 給的 $Q\propto m^3$ 曲線 (Figure 3e) 正好和解析式的參數 $p=3$ 對得上，因為 FDTD 描述的是「無瑕疵理想盤」的 Q 上限，才能純粹用來驗證公式；實驗 Q 會被表面粗糙、盤形不圓拖低，那是製程議題。

   FDTD 也直接餵回矽殼厚度的設計目標。作者掃描不同 SiO₂ 殼厚下 WG 模的波長對周圍折射率靈敏度 $\Delta\lambda/\Delta n$：裸盤時 InP 的高折射率讓 WG 模「摸得到」外界，$n$ 每變 0.1 波長就漂 7.3 nm；加上 20 nm 矽殼後模的能量被拉進殼內、和外界隔開，同樣的 Δn 只剩 0.6 nm 偏移。作者依此挑出 100 nm 厚度作為「條碼穩定版」目標，讓細胞內折射率變化不會污染波長 ID。使用 FDTD 時要注意一個常見偽跡：如果一律用「完美圓盤」建模，實驗真實粒子卻因 H₃PO₄ 非等向蝕刻變成橢圓或類立方，旋轉對稱一破壞 WG 模的邊緣散射損失就變大、Q 會掉，模擬值系統性高於實驗值。這也是為什麼作者強調 FDTD 的 Q 是理論上限，實作值必然打折。

4. 工具與材料:
   - **FDTD (finite-difference time-domain)**: 把馬克斯威方程一格一格數值時序展開的電磁全波模擬法。
   - **Lumerical**: 作者採用的商用 FDTD 軟體套件。
   - **TFSF (total-field / scattered-field)**: 從外部丟平面波、自動扣掉入射光只保留散射光的分區激發源，用於 Mie 散射模擬。
   - **電偶極 / 磁偶極源 (electric / magnetic dipole)**: 塞進粒子內部當「內建發射天線」的激發源，用來找 WG 內部模。
   - **2D field monitor 陣列**: 密密麻麻的 2D 場感測器像千層蛋糕疊起來，組出 3D 近場影像。
   - **Box monitor**: 把粒子完整包起來的盒狀感測器，統計所有出射能量、積分出遠場輻射花紋。
   - **$Q=\omega_{\mathrm{res}}/\Delta\omega_{\mathrm{res}}$**: 低 Q 模用的頻域讀法：直接量共振峰的半高全寬即可算出 Q。
   - **$Q=\omega_{\mathrm{res}}\tau/2$**: 高 Q 模用的時域讀法：由電場振幅指數衰減斜率 $\tau$ 反推 Q，避開模擬時間窗不足造成的頻譜假性變寬。
   - **$\Delta\lambda/\Delta n$**: 環境折射率靈敏度：外界介質折射率變化多少，雷射波長就漂移多少；用來設計矽殼厚度。

5. 與此篇文章的關係:

   在《Wideband Tuning and Deep-Tissue Spectral Detection of Indium Phosphide Nano-Laser Particles》這篇文章中，作者為了驗證他們用閉合公式導出的「粒子越小越藍」規則能否精準預測 InP 奈米盤的模階與 Q 因子，動用了商用 Lumerical FDTD 做電磁全波模擬。它拿實驗量到的粒子尺寸當輸入，吐出理想結構的 Q 上限、近／遠場圖與折射率靈敏度，作為解析模型的獨立校驗；同時也把矽殼厚度掃出 $\Delta\lambda/\Delta n$ 曲線，直接回饋給 Stöber 法決定 100 nm 厚殼。
