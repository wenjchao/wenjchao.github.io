# WG 模階數與可調範圍解析模型

1. 引用自哪篇 paper: wideband-indium-phosphide-nanolasers
2. Outline (任務主線): WG 模階數與可調範圍解析模型
3. Method:

   整組解析式的骨幹是 WG 模的共振條件 (Eq. 1)：$2\pi n R = (m + m_0)\lambda$。物理意義是把 WG 模想成光沿盤緣的環形跑道跑一圈——跑道長度 $2\pi R$、光速 $c/n$；光每繞一圈波峰對波峰、形成穩定共振的條件是「一圈的路徑上剛好塞得下整數個波長」。理想是 $2\pi n R = m \lambda$，$m$ 就是「一圈能塞的整數個波長」，也就是模階數 (mode order)。但 WG 模的光場不是完全鎖在盤緣；實際「重心」的有效半徑略小於物理 $R$，這個誤差用一個相位修正 $m_0$ 吸收，變成 $2\pi n R = (m + m_0) \lambda$；作者對 InP 低階模擬合出 $m_0 \approx \pi/4 < \pi$，代表修正很小。從共振條件對 $m$ 微分得到自由光譜範圍 (free spectral range，FSR)：$\Delta E_{\mathrm{FSR}} = hc/(2\pi n R) = E_p / (m + m_0)$ (Eq. 2)。物理含義是「相鄰兩個模階的共振能量差」——粒子越大 (大 $R$) FSR 越小、相鄰模擠得越近；粒子越小 (低 $m$) FSR 越大、模與模之間距離拉開、能覆蓋的光譜就寬。這正是為什麼作者要把粒子做小到 $m = 4$：低模階 = 大 FSR = 每階內可調範圍寬。

   有了共振條件還不夠——要讓一個模真的變成雷射，還得滿足「起雷條件 (增益 $\geq$ 損耗)」。作者把兩者都寫成 $E_p$ 與 $m$ 的函數。增益方面，塊材半導體的態密度 (density of states，DOS) 在能量高於帶隙 $E_g$ 時正比於 $\sqrt{E_p - E_g}$——這來自導帶底與價帶頂拋物線色散下三維自由電子模型的標準結果。因此最大增益寫成 $g = A\sqrt{E_p - E_g}$，$A$ 是材料相依常數。損耗方面，模態損失可寫成 $\gamma = E_p / Q$；雖然純輻射 Q 隨模階 $m$ 指數上升，但小的 III-V 圓盤 (直徑 <1 μm) 表面粗糙、非等向蝕刻造成的稜角、少量材料吸收會把總 Q 拉到 <1000。作者實測 batch v (900 nm) 的 Q ≈ 360、batch i (480 nm) 的 Q ≈ 80，用一個冪律 $Q \propto m^p$ 近似時 $p = 3$ 給出最好的實驗配對 (Figure 3e 的雙對數斜率就是 3)。損耗因此寫成 $\gamma = B E_p / m^p$。把「起雷臨界」$g = \gamma$ 代入、兩邊平方消掉平方根，就得到 $E_{\min} = E_g + (B/A)^2 E_p^2 / m^{2p}$ (Eq. 3)。這條式子有一個非常直觀的物理讀法：模階 $m$ 越小，$m^{2p}$ 越小、$(B/A)^2 E_p^2 / m^{2p}$ 越大，起雷所需的最低光子能量 $E_{\min}$ 越藍——「越小越藍」的分子解釋就在這裡；而 $E_g$ 是永遠不能低於的下限——低於帶隙就沒增益。

   光有 $E_{\min}$ 還不夠。共振腔的每一階模都對應一個 $E_{\min}$——階數越高、$E_{\min}$ 越接近 $E_g$。所以若 $m$-階和 $m+1$-階同時可能起雷，$m+1$-階的閾值可能更低；$m+1$-階一起雷就把載子耗光、$m$-階被搶走增益 (mode competition)。因此若想讓 $m$-階單獨主宰，它能爬到的最高能量必須在 $E_{\min,m+1}$ 之下、但可以再加上一個 FSR 的間距。這正好是 $E_{\max}(m) = \Delta E_{\mathrm{FSR}} + E_{\min,m+1}$ (Eq. 4)。每階可調範圍 $\Delta E_{\mathrm{tuning}}(m) = E_{\max}(m) - E_{\min}(m)$ (Eq. 5)。從公式讀出來的關鍵結論是「最小可雷射模階 $m_{\min}$」的存在：$E_{\min}$ 隨 $m$ 下降快速上升，$E_{\max}$ 也上升但慢；當 $m$ 小到某個地步時兩條曲線交叉、$\Delta E_{\mathrm{tuning}} < 0$，這階根本不可能起雷。$m_{\min}$ 就是滿足 $\Delta E_{\mathrm{tuning}} > 0$ 的最小整數 $m$。作者用 $n = 2.7$、$E_g = 1.3$ eV、$(B/A)^2 E_g = 500$、$p = 3$、$m_0 = \pi/4$ 這幾個 InP 擬合參數就同時解釋 $E_{\max}$、$E_{\min}$、tuning range 三條曲線 (Figure 3g/h)。實驗上 InP 空氣中量到 $m_{\min} = 4$、細胞內 $m_{\min} = 5$ (細胞質折射率高、Q 相對更低)。ensemble 光譜跨度 $\Delta E_{\mathrm{group}} = E_{\max}(m_{\min}) - E_{\min}(\infty)$ (Eq. 6)——把「最小模階能到最藍」與「最大模階能到最紅」串起來得到總光譜寬度。

   為什麼作者已經有 FDTD 全波模擬還要推這組看起來簡陋的閉合式？兩個原因。(a) 實驗規劃：FDTD 每算一個 $R$、每個模階要幾小時到幾天；閉合式秒算，讓作者能「先算後做」——輸入目標波長、反推需要的粒子直徑、模階與 Q。(b) 物理直覺骨幹：閉合式讓「越小越藍」從 FDTD 曲線上的觀察變成可以從 $E_{\min}$ 隨 $m$ 上升這件事直接解釋的物理律；作者同時用 FDTD 獨立算 Q 因子、用 Fermi–Dirac 半導體增益譜獨立算 $A$、$B$ 的比值，三條互不依賴的推導同時對上 Figure 3g/h/j/k——這就是「解析式 × FDTD × Fermi–Dirac」三向對帳的核心。這組公式的失效邊界也很明確：只在 (1) $Q < 1000$ 的冪律近似區間、(2) 塊材半導體 (bulk) 而非量子井／量子點、(3) $m_0 \approx \pi/4$ 適用的 InP 低階模範圍內站得住。換到大直徑 (Q > 10000) 圓盤、量子井結構、或極高階模就要重新擬合參數。

4. 工具與材料:
   - **共振條件 (Eq. 1)**: $2\pi n R = (m + m_0)\lambda$；環形跑道一圈剛好塞得下整數個波長，$m_0$ 為有效半徑修正。
   - **自由光譜範圍 FSR (Eq. 2)**: $\Delta E_{\mathrm{FSR}} = hc/(2\pi n R) = E_p/(m+m_0)$，相鄰模階能量差；粒子小 → FSR 大 → 可調範圍寬。
   - **塊材增益 $g = A\sqrt{E_p - E_g}$**: 來自三維拋物線色散下 DOS $\propto \sqrt{E - E_g}$，適用 InP bulk。
   - **模態損耗 $\gamma = B E_p / m^p$**: $Q \propto m^p$ 冪律近似；$p = 3$ 由 Figure 3e Q vs. m 雙對數斜率擬合，適用 $Q < 1000$ 小 III-V 圓盤。
   - **雷射下限 $E_{\min}$ (Eq. 3)**: 由 $g = \gamma$ 平方求得 $E_{\min} = E_g + (B/A)^2 E_p^2 / m^{2p}$；解釋「越小越藍」的物理起源。
   - **雷射上限 $E_{\max}$ (Eq. 4)**: $E_{\max}(m) = \Delta E_{\mathrm{FSR}} + E_{\min,m+1}$；上一階不能先起雷的約束。
   - **每階可調範圍 (Eq. 5)**: $\Delta E_{\mathrm{tuning}}(m) = E_{\max}(m) - E_{\min}(m)$；為正才能起雷。
   - **ensemble 光譜跨度 (Eq. 6)**: $\Delta E_{\mathrm{group}} = E_{\max}(m_{\min}) - E_{\min}(\infty)$；最小可雷射模階與最大模階的合成光譜寬度。
   - **InP 擬合參數**: $n = 2.7$, $E_g = 1.3$ eV, $(B/A)^2 E_g = 500$, $p = 3$, $m_0 = \pi/4$；同時擬合 $E_{\max}$、$E_{\min}$、tuning range 三條曲線。
   - **$m_{\min}$ (最小可雷射模階)**: 由 $\Delta E_{\mathrm{tuning}} > 0$ 決定；InP 空氣中量到 $m = 4$、細胞內量到 $m = 5$。

5. 與此篇文章的關係:

   在《Wideband Tuning and Deep-Tissue Spectral Detection of Indium Phosphide Nano-Laser Particles》這篇文章中，作者為了把「粒子越小雷射越藍」從 FDTD 現象變成可預測、可規劃的物理律，推導了一組閉合式，把 WG 模階 $m$、半徑 $R$、折射率 $n$、帶隙 $E_g$ 與可調範圍 $\Delta E_{\mathrm{tuning}}$、最小模階 $m_{\min}$ 直接連起來；它解決了「每個尺寸都要跑一次 FDTD」的規劃效率瓶頸，讓實驗規劃者秒算「這批粒子應該做多大、能發到什麼波長」，並與 FDTD、Fermi–Dirac 增益譜構成三向對帳的理論骨幹。
